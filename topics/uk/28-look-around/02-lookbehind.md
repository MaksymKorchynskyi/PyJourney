# Перегляд назад

**Перегляд назад** (lookbehind) — дзеркальне відображення перегляду вперед: він перевіряє, що стоїть *перед* поточною позицією, не включаючи цей текст у збіг. З його допомогою можна сказати: «знайди `X`, але лише якщо безпосередньо перед ним стоїть `Y`» (або «лише якщо перед ним **немає** `Y`»). У модулі `re` перегляд назад має одне важливе обмеження: шаблон усередині нього повинен мати **фіксовану ширину**.

## Що ви дізнаєтесь

- Позитивний перегляд назад `(?<=Y)X` і негативний `(?<!Y)X`
- Чому негативному перегляду назад часто потрібне `\b`, щоб уникнути часткових збігів
- Чому `re` у Python вимагає перегляду назад фіксованої ширини і що вважається фіксованою шириною
- Обхідні шляхи для змінної ширини: кілька переглядів назад, група захоплення або сторонній модуль `regex`
- Як поєднувати перегляд назад і вперед, щоб знайти текст між маркерами або позицію між символами
- Як перегляд назад поводиться з `re.match()` і аргументом `pos`

## Позитивний перегляд назад: `(?<=Y)X`

Синтаксис такий:

```text
(?<=Y)X
```

Він збігається з `X`, лише якщо безпосередньо перед ним стоїть `Y`. Як і перегляд уперед, це твердження нульової ширини: `Y` перевіряється, але до збігу не входить.

Припустімо, з рядка нижче треба взяти ціну `500`, але не кількість `1`:

```text
1 phone costs $500
```

Шаблон такий:

```text
(?<=\$)\d+
```

- `(?<=\$)` спрацьовує лише на позиції, безпосередньо перед якою стоїть `$`. Знак долара в регулярних виразах — спеціальний символ (якір кінця рядка), тому його екранують: `\$`.
- `\d+` збігається з однією або кількома цифрами.

```python
import re

s = "1 phone costs $500"
pattern = r"(?<=\$)\d+"

for match in re.finditer(pattern, s):
    print(match.group())
```

Результат:

```text
500
```

Збіг — `500`, а не `$500`. Порівняйте зі звичайним шаблоном, який змушений включати знак долара:

```python
import re

s = "1 phone costs $500"

print(re.findall(r"\$\d+", s))
print(re.findall(r"(?<=\$)\d+", s))
```

Результат:

```text
['$500']
['500']
```

Схожий щоденний приклад — хештеги без `#`:

```python
import re

print(re.findall(r"(?<=#)\w+", "Learn #python and #regex with python"))
```

Результат:

```text
['python', 'regex']
```

## Негативний перегляд назад: `(?<!Y)X`

```text
(?<!Y)X
```

Такий шаблон збігається з `X`, лише якщо безпосередньо перед ним **немає** `Y`. Щоб знайти числа, перед якими немає знака `$`:

```python
import re

s = "1 phone costs $500"
pattern = r"\b(?<!\$)\d+\b"

for match in re.finditer(pattern, s):
    print(match.group())
```

Результат:

```text
1
```

- `\b` — межа слова.
- `(?<!\$)` спрацьовує лише там, де попередній символ — не `$`.
- `\d+` збігається з цифрами, а кінцеве `\b` гарантує, що число закінчується на межі слова.

### Навіщо потрібне `\b`

Без меж слова результат несподіваний:

```python
import re

s = "1 phone costs $500"
print(re.findall(r"(?<!\$)\d+", s))
```

Результат:

```text
['1', '00']
```

На цифрі `5` перегляд назад бачить `$` і не спрацьовує. Але рушій просто переходить до наступної позиції — першого `0`. Перед ним стоїть `5`, а не `$`, тож перегляд успішний, і в результат потрапляє `00`. Початкове `\b` не дає збігу початися посеред числа: між `5` і `0` межі слова немає. Це пастка того самого типу, що й повернення назад із негативним переглядом уперед. Інший спосіб виправлення — заборонити перед збігом ще й цифру: `(?<![\d$])\d+`.

## Обмеження фіксованої ширини

Щоб перевірити перегляд назад, рушій відступає від поточної позиції **назад** на фіксовану кількість символів і пробує зіставити там підшаблон. Тому модуль `re` у Python приймає лише такі шаблони перегляду назад, довжина яких відома заздалегідь:

| Можна (фіксована ширина) | Не можна (змінна ширина) |
|---|---|
| `(?<=\$)` | `(?<=\$\s*)` |
| `(?<=\d{3})` | `(?<=\d+)` |
| `(?<=USD \|EUR )` (обидва по 4 символи) | `(?<=\$\|USD )` (1 проти 4 символів) |
| `(?<=[A-Z]\.)` | `(?<=\$\s?)` |

Усе, що містить `*`, `+`, `?`, `{m,n}` (де `m` не дорівнює `n`) або альтернативи різної довжини, відхиляється вже під час компіляції шаблону:

```python
import re

patterns = [r"(?<=USD |EUR )\d+", r"(?<=\$\s*)\d+", r"(?<=\$|USD )\d+", r"(?<=\d+)x"]

for pattern in patterns:
    try:
        re.compile(pattern)
        print(f"{pattern:20} OK")
    except re.PatternError as error:
        print(f"{pattern:20} {error}")
```

Результат:

```text
(?<=USD |EUR )\d+    OK
(?<=\$\s*)\d+        look-behind requires fixed-width pattern
(?<=\$|USD )\d+      look-behind requires fixed-width pattern
(?<=\d+)x            look-behind requires fixed-width pattern
```

Назва `re.PatternError` використовується починаючи з Python 3.13. У старіших версіях перехоплюйте `re.error`, який і далі працює як псевдонім.

> **Зверніть увагу:** перегляд уперед такого обмеження не має. `(?=\s*feet)` — нормальний шаблон, а `(?<=\$\s*)` — ні.

## Як обійти обмеження

### Кілька переглядів назад

Альтернативи різної довжини не можна ставити *всередину* одного перегляду назад, але можна написати кілька переглядів і чергувати *їх*. Кожен із них окремо має фіксовану ширину:

```python
import re

text = "Total: $40, USD 15, EUR 9"
print(re.findall(r"(?:(?<=\$)|(?<=USD ))\d+", text))
```

Результат:

```text
['40', '15']
```

### Група захоплення замість перегляду назад

Часто перегляд назад узагалі не потрібен. Зіставте префікс звичайним способом і захопіть лише потрібну частину:

```python
import re

text = "Total: $40, USD 15, EUR 9, $ 7"
print(re.findall(r"(?:\$|USD)\s*(\d+)", text))
```

Результат:

```text
['40', '15', '7']
```

Тепер префікс входить до повного збігу, але `findall()` повертає лише групу. Так можна обробити будь-яку кількість пробілів, чого перегляд назад у `re` не вміє. Різниця важлива для `re.sub()` і перекривних збігів: перегляд назад не поглинає префікс, а група поглинає.

### Сторонній модуль `regex`

Пакет [`regex`](https://pypi.org/project/regex/) — сумісна заміна `re` з додатковими можливостями, серед яких і перегляд назад змінної ширини. Він не входить до стандартної бібліотеки, тому встановлюйте його у віртуальне середовище:

```bash
python -m pip install regex
```

```python
import regex

print(regex.findall(r"(?<=\$\s*)\d+", "costs $ 500 or $20"))
```

Результат:

```text
['500', '20']
```

> **Зверніть увагу:** деякі інші рушії регулярних виразів підтримують `\K` («забути все, що збіглося досі») як альтернативу перегляду назад. Модуль `re` у Python його не підтримує.

## Поєднання перегляду назад і вперед

Перегляди назад і вперед можуть оточувати шаблон так, що збігається лише «середина». Ось так можна витягти текст у квадратних дужках без самих дужок:

```python
import re

print(re.findall(r"(?<=\[)[^\]]+(?=\])", "Error [E42] in [main.py]"))
```

Результат:

```text
['E42', 'main.py']
```

Перегляд назад і перегляд уперед, між якими нічого немає, збігаються з **позицією** між двома символами. За допомогою `re.sub()` туди можна вставити текст. Цей код перетворює camelCase на snake_case, вставляючи `_` скрізь, де за малою літерою чи цифрою йде велика літера:

```python
import re

for name in ["parseHttpResponse", "userId", "html5Parser", "simple"]:
    snake = re.sub(r"(?<=[a-z0-9])(?=[A-Z])", "_", name).lower()
    print(name, "->", snake)
```

Результат:

```text
parseHttpResponse -> parse_http_response
userId -> user_id
html5Parser -> html5_parser
simple -> simple
```

## Перегляд назад і початкова позиція

Перегляд назад бачить символи, що стоять перед позицією, з якої починається пошук:

```python
import re

pattern = re.compile(r"(?<=\$)\d+")
text = "$500"

print(pattern.match(text))
print(pattern.search(text))
print(pattern.match(text, 1))
print(pattern.match(text[1:]))
```

Результат:

```text
None
<re.Match object; span=(1, 4), match='500'>
<re.Match object; span=(1, 4), match='500'>
None
```

- `match()` пробує лише позицію 0. Перед позицією 0 нічого немає, тому шаблон, що **починається** з позитивного перегляду назад, ніколи не збігається через `re.match()`. Використовуйте `search()`.
- `pattern.match(text, 1)` починає з індексу 1, але бачить увесь рядок, тож перегляд назад знаходить `$` на індексі 0.
- Зріз (`text[1:]`) створює новий рядок без `$`, і перегляду назад нема чого побачити.

## Типові помилки

- **Шаблон змінної ширини.** `(?<=\$\s*)`, `(?<=\d+)` і `(?<=\$|USD )` генерують `re.PatternError: look-behind requires fixed-width pattern`. Використовуйте кілька переглядів назад, групу захоплення або модуль `regex`.
- **Часткові числа через негативний перегляд назад.** `(?<!\$)\d+` повертає `00` із `$500`. Додайте `\b` або забороніть ще й цифри: `(?<![\d$])\d+`.
- **Плутанина в синтаксисі.** Перегляд назад — це `(?<=...)` / `(?<!...)`, із `<`. `(?=...)` / `(?!...)` — перегляд уперед. Перегляд назад пишуть *перед* частиною, яку він перевіряє.
- **Забуте екранування спеціальних символів.** `(?<=$)` означає «після кінця рядка» і ніколи не збігається перед цифрою. Пишіть `(?<=\$)`.
- **`re.match()` із шаблоном, що починається з перегляду назад.** На позиції 0 він ніколи не спрацює. Використовуйте `re.search()` або `re.finditer()`.

## Підсумок

- `(?<=Y)X` збігається з `X`, лише якщо безпосередньо перед ним стоїть `Y`. `(?<!Y)X` збігається з `X`, лише якщо перед ним немає `Y`.
- Перегляд назад має нульову ширину: перевірений текст не входить до збігу.
- Негативний перегляд назад перед шаблоном із квантифікатором може дати збіг посеред лексеми. Захищайтеся за допомогою `\b` або ширшого класу символів.
- У модулі `re` шаблон перегляду назад повинен мати фіксовану ширину. Альтернативи допустимі лише тоді, коли всі вони однакової довжини.
- Обхідні шляхи: кілька переглядів назад, об'єднаних через `|`, група захоплення для потрібної частини або сторонній модуль `regex`, що підтримує перегляд назад змінної ширини.
- Перегляди назад і вперед разом дають змогу витягти текст між маркерами або знайти позицію між символами для `re.sub()`.
- Перегляд назад бачить текст перед аргументом `pos`, але в `re.match()` на позиції 0 позаду нічого немає.

## Практика

### Вправа 1: Ціни в доларах

З рядка `"Coffee $3.50, tea $2, cake 4.00"` витягніть ціни, що стоять після знака `$`, без самого знака. Ціна може мати необов'язкову дробову частину з двох цифр. Очікуваний результат — `['3.50', '2']`.

### Вправа 2: Лише додатні числа

З рядка `"-5, 10, -20, 30"` витягніть числа, які **не** є від'ємними. Очікуваний результат — `['10', '30']`. Спершу спробуйте `(?<!-)\d+` і поясніть, чому він повертає три елементи.

### Вправа 3: camelCase у snake_case

Напишіть функцію `to_snake(name)`, яка перетворює `"getUserName"` на `"get_user_name"`, `"maxValue2Go"` на `"max_value2_go"` і не змінює `"plain"`. Використовуйте в шаблоні лише перегляди, щоб `re.sub()` вставляв підкреслення, не видаляючи жодного символу.

### Вправа 4: Два види валютного префікса

З рядка `"Paid $40, then USD 15, then EUR 9"` витягніть суми, перед якими стоїть `$` або `USD ` (рівно з одним пробілом). Очікуваний результат — `['40', '15']`. Поясніть, чому не можна використати `(?<=\$|USD )\d+`, а потім розв'яжіть задачу за допомогою переглядів назад.

## Розв'язки

### Вправа 1

```python
import re

text = "Coffee $3.50, tea $2, cake 4.00"
print(re.findall(r"(?<=\$)\d+(?:\.\d{2})?", text))
```

Результат:

```text
['3.50', '2']
```

Група без захоплення робить дробову частину необов'язковою і не змінює того, що повертає `findall()`.

### Вправа 2

```python
import re

text = "-5, 10, -20, 30"

print(re.findall(r"(?<!-)\d+", text))
print(re.findall(r"(?<![-\d])\d+", text))
```

Результат:

```text
['10', '0', '30']
['10', '30']
```

У `-20` перегляд назад не дає збігу початися з `2`, але перед `0` стоїть `2`, а не `-`, тож `0` збігається. Якщо заборонити перед збігом ще й цифру (`[-\d]`), число може збігтися лише від своєї першої цифри. `\b(?<!-)\d+` теж працює.

### Вправа 3

```python
import re


def to_snake(name):
    return re.sub(r"(?<=[a-z0-9])(?=[A-Z])", "_", name).lower()


for name in ["getUserName", "maxValue2Go", "plain"]:
    print(to_snake(name))
```

Результат:

```text
get_user_name
max_value2_go
plain
```

Шаблон збігається лише з порожніми позиціями між малою літерою чи цифрою та великою літерою, тож `re.sub()` вставляє туди `_` і зберігає всі початкові символи.

### Вправа 4

```python
import re

text = "Paid $40, then USD 15, then EUR 9"

try:
    re.compile(r"(?<=\$|USD )\d+")
except re.PatternError as error:
    print("error:", error)

print(re.findall(r"(?:(?<=\$)|(?<=USD ))\d+", text))
```

Результат:

```text
error: look-behind requires fixed-width pattern
['40', '15']
```

`\$` має ширину в один символ, а `USD ` — у чотири, тож один перегляд назад не має фіксованої ширини. Два окремі перегляди назад, кожен зі своєю фіксованою шириною, об'єднані через `|` у групі без захоплення, виражають ту саму умову.
