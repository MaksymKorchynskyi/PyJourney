# Регулярні вирази

**Регулярний вираз** (regular expression, regex) — це короткий шаблон, який описує цілу родину рядків: «одна цифра», «чотири цифри поспіль», «слово, що закінчується на `ython`». Python виконує такі шаблони за допомогою вбудованого модуля `re`. Один рядок із регулярним виразом може знайти, перевірити, витягти чи замінити текст там, де звичайним методам рядків знадобилися б цикл і купа `if`.

## Що ви дізнаєтесь

- Що таке регулярний вираз і як модуль `re` його виконує
- Як скомпілювати шаблон в об'єкт `Pattern` і коли це варто робити
- Чим відрізняються `search()`, `match()`, `fullmatch()`, `findall()` та `finditer()`
- Як читати об'єкт `Match` за допомогою `group()`, `start()`, `end()` і `span()`
- Чому кожен шаблон варто записувати як сирий рядок `r"..."`

## Що таке регулярний вираз

Регулярний вираз записують як звичайний рядок Python, але його вміст — це програма окремою мовою. Більшість символів просто збігаються самі із собою: шаблон `cat` знаходить три символи `c`, `a`, `t` саме в такому порядку. Деякі символи та послідовності мають особливе значення, їх називають **метасимволами**. Наприклад, `\d` означає «будь-яка одна цифра»:

```python
r"\d"
```

Модуль `re` — це міст між двома мовами. Він бере шаблон, компілює його у внутрішній механізм пошуку і запускає цей механізм на вашому тексті.

Типові задачі для регулярних виразів:

- **перевірка** введених даних: чи це поштовий індекс, час, номер телефону?
- **видобування** даних: усі числа, дати чи адреси електронної пошти з журналу;
- **заміна** й очищення тексту: прибрати з номера телефону все, крім цифр;
- **розбиття** рядка за роздільниками, складнішими за один символ.

> **Зверніть увагу:** не беріться за регулярний вираз, якщо вистачить методу рядка. `"py" in text`, `text.startswith("http")` і `text.split(",")` простіші, швидші й зрозуміліші для таких простих перевірок.

## Компіляція шаблону: `re.compile()`

Робота з регулярним виразом складається з трьох кроків: імпортувати `re`, скомпілювати шаблон в об'єкт `Pattern` і викликати один із його методів.

```python
import re

pattern = re.compile(r"\d")
s = "Python 3.10 was released on October 04, 2021"

print(pattern.findall(s))
```

Результат:

```text
['3', '1', '0', '0', '4', '2', '0', '2', '1']
```

`findall()` переглядає рядок зліва направо і збирає всі збіги. Кожне `\d` відповідає рівно **одному** символу, тому в результаті маємо список окремих цифр. Крапку, пробіли й літери пропущено, бо вони не цифри.

Об'єкт `Pattern` пам'ятає початковий текст шаблону:

```python
import re

pattern = re.compile(r"\d")

print(type(pattern))
print(pattern)
print(pattern.pattern)
```

Результат:

```text
<class 're.Pattern'>
re.compile('\\d')
\d
```

`repr` показує шаблон як звичайний рядковий літерал, тому зворотна скісна риска відображається подвоєною (`'\\d'`). Сам шаблон складається лише з двох символів, зворотної скісної риски та `d`, що й видно з `print(pattern.pattern)`.

Найважливіші методи `Pattern`:

| Метод | Що робить | Повертає |
|---|---|---|
| `search(string)` | Шукає перший збіг будь-де в рядку | `Match` або `None` |
| `match(string)` | Перевіряє збіг лише на самому початку рядка | `Match` або `None` |
| `fullmatch(string)` | Успішний, лише якщо весь рядок відповідає шаблону | `Match` або `None` |
| `findall(string)` | Знаходить усі збіги, що не перекриваються | список рядків |
| `finditer(string)` | Знаходить усі збіги, що не перекриваються, по одному | ітератор об'єктів `Match` |
| `sub(repl, string)` | Замінює кожен збіг на `repl` | новий рядок |
| `split(string)` | Розбиває рядок у місцях збігів | список рядків |

## Функції модуля та кеш шаблонів

Кожен метод вище має функцію-двійника в модулі `re`, яка приймає шаблон першим аргументом: `re.search(pattern, string)`, `re.findall(pattern, string)` тощо. Компілювати нічого самостійно не потрібно:

```python
import re

s = "Python 3.10 was released on October 04, 2021."
print(re.findall(r"\d", s))
```

Результат:

```text
['3', '1', '0', '0', '4', '2', '0', '2', '1']
```

Під капотом `re.findall(p, s)` робить приблизно те саме, що й `re.compile(p).findall(s)`. Щоб не компілювати той самий шаблон знову і знову, модуль зберігає нещодавно скомпільовані шаблони у внутрішньому **кеші**. Другий виклик із тим самим рядком шаблону бере готовий об'єкт `Pattern` із кешу.

Тож який стиль обрати?

- **Функції модуля** (`re.search(...)`) ідеальні для шаблону, який використовують один раз або зрідка. Код виходить коротшим.
- **`re.compile()`** виправданий, коли той самий шаблон використовують багато разів (у циклі чи у функції, яку часто викликають), коли шаблону хочеться дати змістовну назву або коли прапорці потрібно задати один раз. Скомпільований шаблон також дає змогу обмежити ділянку пошуку аргументами `pos` і `endpos`.

Завдяки кешу різниця у швидкодії зазвичай невелика. Головна причина компілювати — читабельність:

```python
import re

YEAR = re.compile(r"\d{4}")


def find_years(lines):
    return [YEAR.findall(line) for line in lines]


print(find_years(["Python 1991", "No year here", "3.0 in 2008, 3.10 in 2021"]))
```

Результат:

```text
[['1991'], [], ['2008', '2021']]
```

Тут `\d{4}` означає «рівно чотири цифри поспіль». Це **квантифікатор** (quantifier), про нього докладно йдеться в темі «Квантифікатори».

**Прапорці** (flags) змінюють поведінку шаблону. Їх передають у `re.compile()` або в будь-яку функцію модуля. Наприклад, `re.IGNORECASE` (скорочено `re.I`) вимикає чутливість до регістру:

```python
import re

pattern = re.compile(r"python", re.IGNORECASE)
print(pattern.findall("Python, PYTHON and python"))
```

Результат:

```text
['Python', 'PYTHON', 'python']
```

## `search()`: перший збіг будь-де

`search()` пробує шаблон на позиції 0, потім на позиції 1 і так далі, і зупиняється на **першій** позиції, де шаблон збігся. Функція повертає об'єкт `Match` або `None`, якщо збігу немає ніде.

```python
import re

s = "Python 3.10 was released on October 04, 2021."

match = re.search(r"\d{2}", s)
print(type(match))
print(match)

print(re.search(r"\d{5}", s))
```

Результат:

```text
<class 're.Match'>
<re.Match object; span=(9, 11), match='10'>
None
```

Перша цифра в рядку — `3` (індекс 7), але за нею йде крапка, тож двох цифр поспіль там немає. Перше місце, де вони є, — `10` на індексах 9 і 10. П'яти цифр поспіль у рядку немає, тому другий пошук повертає `None`.

Оскільки результат може бути `None`, завжди перевіряйте його перед використанням. Оператор «морж» `:=` (Python 3.8+) робить таку перевірку короткою. Об'єкт `Match` завжди істинний, тож достатньо `if match:`:

```python
import re

text = "Call me at 555-0199"

if match := re.search(r"\d\d\d", text):
    print("Found:", match.group())
else:
    print("No digits")
```

Результат:

```text
Found: 555
```

## Об'єкт `Match`

Об'єкт `Match` описує один успішний збіг:

| Метод | Повертає |
|---|---|
| `group()` | Текст збігу (те саме, що `group(0)` або `m[0]`) |
| `start()` | Індекс, з якого починається збіг |
| `end()` | Індекс одразу **після** останнього символу збігу |
| `span()` | Кортеж `(start(), end())` |

```python
import re

s = "Python 3.10 was released on October 04, 2021."
result = re.search(r"\d", s)

print("Matched string:", result.group())
print("Starting position:", result.start())
print("Ending position:", result.end())
print("Positions:", result.span())
print("Slice:", s[result.start():result.end()])
print("Shortcut:", result[0])
```

Результат:

```text
Matched string: 3
Starting position: 7
Ending position: 8
Positions: (7, 8)
Slice: 3
Shortcut: 3
```

`end()` **не входить** у збіг, так само як кінцевий індекс зрізу. Саме тому `s[m.start():m.end()]` завжди дорівнює `m.group()`. `group()` без аргументів повертає весь збіг. Якщо в шаблоні є групи захоплення (capturing groups, див. тему «Групування»), можна отримувати й частини збігу за номером чи назвою.

## `match()`: лише на початку

`match()` перевіряє шаблон **тільки на позиції 0**. Якщо рядок не починається зі збігу, результат — `None`, навіть коли шаблон трапляється далі в рядку.

```python
import re

names = [
    "Python",
    "CPython is an implementation of Python written in C",
    "Jython is a Java implementation of Python",
    "IronPython is Python on .NET framework",
]

for name in names:
    print(re.match(r"\wython", name))
```

Результат:

```text
<re.Match object; span=(0, 6), match='Python'>
None
<re.Match object; span=(0, 6), match='Jython'>
None
```

`\w` відповідає одному **символу слова** (word character): літері, цифрі або підкресленню. Це не «будь-який символ». Отже, `\wython` означає «один символ слова, а за ним буквальний текст `ython`».

- `"Python"` і `"Jython ..."` починаються з такої послідовності, тому збіг є.
- `"CPython ..."` починається з `C`, який `\w` приймає, але далі йде `Python`, а не `ython`. Інших позицій `match()` не пробує, тож результат — `None`, хоча `Python` трапляється в рядку пізніше. `re.search()` його знайшов би.
- `"IronPython ..."` не підходить із тієї самої причини.

> **Зверніть увагу:** у Python 3 `\w` (як і `\d`, `\s`, `\b`) працює з Unicode, тому кириличні літери теж є «символами слова». Українські тексти можна обробляти тими самими шаблонами без додаткових налаштувань:

```python
>>> import re
>>> re.match(r"\w", "Ґанок")
<re.Match object; span=(0, 1), match='Ґ'>
```

> **Зверніть увагу:** `match()` прив'язує шаблон лише до початку рядка, але не до кінця. `re.match(r"\d", "1abc")` успішно знаходить `'1'`. Якщо рядок має відповідати шаблону повністю, використовуйте `fullmatch()`.

## `fullmatch()`: увесь рядок

`fullmatch()` успішний лише тоді, коли шаблон покриває рядок від першого символу до останнього. Тому це природний інструмент для **перевірки** (валідації):

```python
import re

print(re.fullmatch(r"\d{4}", "2021"))
print(re.fullmatch(r"\d{4}", "Python 3.10 released in 2021"))
print(re.fullmatch(r"\d{4}", "20215"))
```

Результат:

```text
<re.Match object; span=(0, 4), match='2021'>
None
None
```

`2021` усередині довшого речення не годиться, а п'ять цифр — це забагато.

Ось три функції поруч на тому самому шаблоні:

```python
import re

for text in ["2021", "2021 year", "year 2021"]:
    print(
        f"{text!r:12}",
        re.match(r"\d{4}", text) is not None,
        re.search(r"\d{4}", text) is not None,
        re.fullmatch(r"\d{4}", text) is not None,
    )
```

Результат:

```text
'2021'       True True True
'2021 year'  True True False
'year 2021'  False True False
```

Стовпці — це `match()`, `search()` і `fullmatch()`: `search()` найпоблажливіший, `fullmatch()` найсуворіший.

## `findall()` чи `finditer()`

Обидві функції знаходять **усі** збіги, що не перекриваються, рухаючись зліва направо. Різниця в тому, що ви отримуєте:

```python
import re

s = "Room 42, floor 7"

print(re.findall(r"\d", s))

for match in re.finditer(r"\d", s):
    print(match.group(), match.span())
```

Результат:

```text
['4', '2', '7']
4 (5, 6)
2 (6, 7)
7 (15, 16)
```

- `findall()` одразу будує повний **список рядків**. Це зручно, коли потрібен лише текст.
- `finditer()` повертає **ітератор об'єктів `Match`**, які створюються по одному. Використовуйте його, коли потрібні позиції або коли текст великий і не хочеться тримати всі збіги в пам'яті одночасно.

> **Зверніть увагу:** якщо шаблон містить групи захоплення (круглі дужки), `findall()` повертає текст груп, а не весь збіг. Про це йдеться в темі «Групування».

## Заміна й розбиття: `sub()` і `split()`

Ще дві функції трапляються майже в кожній програмі з регулярними виразами. Детально їх розглянуто в розділі про функції `re`, але вони надто корисні, щоб їх пропустити:

```python
import re

print(re.sub(r"\d", "#", "PIN: 1234"))
print(re.split(r"\d", "a1b2c3d"))
```

Результат:

```text
PIN: ####
['a', 'b', 'c', 'd']
```

`sub()` замінює кожен збіг і повертає новий рядок (рядки незмінювані). `split()` розрізає рядок у кожному місці збігу.

## Регулярні вирази та сирі рядки

Шаблон проходить через **два** інтерпретатори, і обидва вважають зворотну скісну риску `\` особливим символом:

1. Спершу **Python** читає рядковий літерал. У звичайному рядку `\n` стає символом нового рядка, `\t` — табуляцією, `\b` — символом backspace, а `\\` — однією зворотною скісною рискою.
2. Потім **рушій регулярних виразів** читає отримані символи. Для нього `\d` означає цифру, `\b` — межу слова, а `\\` — буквальну зворотну скісну риску.

**Сирий рядок** (raw string, префікс `r` або `R`) вимикає крок 1: кожна зворотна скісна риска лишається в рядку як є. Тоді рушій отримує саме те, що ви написали.

### Проблема 1: Python непомітно змінює ваш шаблон

```python
import re

text = "a cat and a category"

print(re.findall("\bcat\b", text))
print(re.findall(r"\bcat\b", text))
print(len("\bcat\b"), len(r"\bcat\b"))
```

Результат:

```text
[]
['cat']
5 7
```

У звичайному рядку Python перетворює `\b` на символ backspace (код 8). Рушій шукає «backspace, c, a, t, backspace» і нічого не знаходить. У сирому рядку `\b` лишається двома символами, і рушій читає його як **межу слова**, тому збігається лише окреме слово `cat`, а не `cat` усередині `category`. Зауважте: ні помилки, ні попередження немає, баг тихий.

### Проблема 2: невідомі послідовності дають попередження

`\d` не належить до керувальних послідовностей, відомих Python, тому у звичайному рядку зворотна скісна риска зберігається і шаблон випадково працює. Але такий код застарілий: починаючи з Python 3.12 компілятор показує `SyntaxWarning` (раніше це був прихований `DeprecationWarning`), а в майбутній версії це стане помилкою.

```python
import re

print(re.findall("\d", "a1b2"))
```

Результат (Python 3.14, шлях до файлу скорочено):

```text
.../example.py:3: SyntaxWarning: "\d" is an invalid escape sequence. Such sequences will not work in the future. Did you mean "\\d"? A raw string is also an option.
  print(re.findall("\d", "a1b2"))
['1', '2']
```

### Проблема 3: пошук буквальної зворотної скісної риски

Щоб знайти одну зворотну скісну риску, рушію потрібен шаблон `\\`. У звичайному рядковому літералі кожну з цих двох рисок треба ще раз подвоїти, тож доводиться писати чотири:

```python
import re

s = r"\section"
print(s, len(s))

pattern_plain = "\\\\section"
pattern_raw = r"\\section"
print(pattern_plain == pattern_raw)

print(re.findall(pattern_raw, s))
```

Результат:

```text
\section 8
True
['\\section']
```

Обидва літерали дають той самий шаблон із 9 символів `\\section`, але сирий варіант читати значно легше. Знайдений рядок — це `\section` із 8 символів. Список показує його як `'\\section'` лише тому, що список виводить `repr` своїх елементів, а `repr` подвоює зворотні скісні риски.

| Що знайти | Шаблон | Звичайний літерал | Сирий літерал |
|---|---|---|---|
| цифру | `\d` | `"\\d"` | `r"\d"` |
| межу слова | `\b` | `"\\b"` | `r"\b"` |
| одну зворотну скісну риску | `\\` | `"\\\\"` | `r"\\"` |

Кілька деталей про сирі рядки:

- Послідовності на зразок `\n` і `\t` працюють і в сирому шаблоні, бо рушій регулярних виразів розуміє їх сам. `re.findall(r"\t", "a\tb")` повертає `['\t']`.
- Сирий рядок не може закінчуватися непарною кількістю зворотних скісних рисок: `r"\"` — це `SyntaxError`. На практиці шаблонам це майже ніколи не потрібно.
- `r` змінює лише те, як читається літерал. Результат — звичайний `str`.

> **Порада:** зробіть `r"..."` звичкою для кожного шаблону, навіть без зворотних скісних рисок. Шаблони мають властивість розростатися, а сирий рядок ніколи не шкодить.

## Типові помилки

- **Виклик `.group()` для `None`.** Якщо збігу немає, `search()`, `match()` і `fullmatch()` повертають `None`:

  ```python
  import re

  match = re.search(r"\d", "no digits here")
  print(match.group())  # AttributeError: 'NoneType' object has no attribute 'group'
  ```

  Спершу перевірте результат: `if match := re.search(...):`.

- **`match()` замість `search()`.** `re.match(r"Python", "CPython")` дає `None`, бо `match()` дивиться лише на початок рядка.
- **Перевірка формату через `search()` чи `match()`.** `re.search(r"\d{4}", "year 2021!")` спрацює, хоча рядок зовсім не є роком. Для умови «весь рядок має виглядати так» використовуйте `fullmatch()`.
- **Пропущений префікс `r`.** `"\b"` непомітно стає символом backspace, а `"\d"` викликає `SyntaxWarning`.
- **Сприймати `end()` як індекс останнього символу.** Він указує на позицію **після** збігу, як кінець зрізу.
- **Регулярний вираз для простої перевірки підрядка.** `"error" in line` зрозуміліше і швидше, ніж `re.search(r"error", line)`.

## Підсумок

- Регулярний вираз — це шаблон окремою невеликою мовою. Python виконує його через модуль `re`.
- `re.compile()` повертає об'єкт `Pattern` для повторного використання. Функції модуля, як-от `re.search()`, компілюють і кешують шаблони самі.
- `search()` шукає перший збіг будь-де, `match()` — лише на початку, а `fullmatch()` успішний, тільки якщо підходить увесь рядок.
- `findall()` повертає список рядків, а `finditer()` видає об'єкти `Match` із позиціями.
- Об'єкт `Match` має `group()`, `start()`, `end()` (не входить у збіг) і `span()`. Невдалий пошук повертає `None`.
- `\w` — це символ слова (літера, цифра чи підкреслення), і в Python 3 до нього належать літери Unicode, зокрема кирилиця.
- Завжди пишіть шаблони як сирі рядки: тоді Python не чіпає зворотні скісні риски, і рушій отримує саме те, що ви написали.

## Розв'язки

### Вправа 1

Результат:

```text
<re.Match object; span=(0, 2), match='42'>
None
<re.Match object; span=(8, 10), match='42'>
None
<re.Match object; span=(0, 2), match='42'>
```

- `match()` спрацьовує на `"42 apples"`, бо рядок починається з двох цифр. Решта рядка його не цікавить.
- `match()` не спрацьовує на `"apples: 42"`, бо цифри стоять не на позиції 0. `search()` знаходить їх на індексі 8.
- `fullmatch()` не спрацьовує на `"42 apples"` через зайвий текст і спрацьовує на `"42"`.

### Вправа 2

import re

s = "Order 7 of 15 shipped"

for match in re.finditer(r"\d", s):

Результат:

### Вправа 3

```python
import re


def is_pin(text):
    return re.fullmatch(r"\d\d\d\d", text) is not None


for candidate in ["1234", "12345", "12a4", " 1234", "1234\n"]:
    print(repr(candidate), is_pin(candidate))
```

Результат:

```text
'1234' True
'12345' False
'12a4' False
' 1234' False
'1234\n' False
```

`fullmatch()` відкидає будь-які зайві символи, зокрема пробіл на початку чи символ нового рядка в кінці. `re.search()` прийняв би `"12345"` і `" 1234"`, а `re.match()` — `"12345"`.

### Вправа 4

```python
import re

path = r"C:\Users\olena\Documents\notes.txt"

raw_pattern = r"\\"
plain_pattern = "\\\\"

print(raw_pattern == plain_pattern)
print(len(raw_pattern))
print(len(re.findall(raw_pattern, path)))

2
4
```

Обидва літерали дають той самий двосимвольний шаблон `\\`, який рушій читає як «одна буквальна зворотна скісна риска». У шляху їх чотири.
