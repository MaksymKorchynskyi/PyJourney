# Якорі

**Якорі** (anchors) — це елементи регулярного виразу, які відповідають **позиції** в рядку, а не символу. Вони прив'язують шаблон до початку чи кінця тексту (або кожного рядка тексту) і перетворюють умову «шаблон трапляється десь» на «рядок починається з нього», «закінчується ним» чи «складається з нього». Без якорів перевірка введених даних регулярними виразами майже завжди зламана.

## Що ви дізнаєтесь

- Що означає «якір відповідає позиції, а не символу»
- Як `^` і `$` знаходять початок і кінець рядка
- Як поєднати їх, щоб перевірити весь рядок, і чому `$` може пропустити символ нового рядка в кінці
- Як `re.MULTILINE` змушує `^` і `$` працювати для кожного рядка тексту
- Як `\A` і `\Z` завжди позначають початок і кінець усього рядка
- Як знайти буквальні символи `$` або `^`

## Позиції, а не символи

Уявіть рядок як символи з **проміжками** між ними. Рядок довжиною 5 має 6 позицій: від 0 (перед першим символом) до 5 (після останнього):

```text
  | 1 | 2 | : | 2 | 0 |
  0   1   2   3   4   5
  ^                   $
```

Якір `^` відповідає позиції 0, а `$` — позиції 5. Якір має **нульову ширину** (zero-width): він перевіряє, де зараз перебуває рушій, але не поглинає жодного символу. Тому збіг одного лише якоря — це порожній рядок:

```python
>>> import re
>>> [m.span() for m in re.finditer(r"^", "abc")]
[(0, 0)]
>>> [m.span() for m in re.finditer(r"$", "abc")]
[(3, 3)]
```

## `^`: початок рядка

Шаблон `\d\d` знаходить обидві пари цифр у рядку з часом:

```python
import re

time = "12:20"

for match in re.finditer(r"\d\d", time):
    print(match.group())
```

Результат:

```text
12
20
```

Якщо додати попереду каретку, дві цифри мусять стояти на самому початку, тож лишається один збіг:

```python
import re

time = "12:20"

for match in re.finditer(r"^\d\d", time):
    print(match.group())
```

Результат:

```text
12
```

## `$`: кінець рядка

Знак долара працює так само, але з іншого кінця. `\d\d$` означає «дві цифри, за якими кінець рядка»:

```python
import re

time = "12:20"

for match in re.finditer(r"\d\d$", time):
    print(match.group())
```

Результат:

```text
20
```

## Поєднання `^` і `$`: увесь рядок

З обома якорями шаблон мусить покрити все від початку до кінця. Так перевіряють, що рядок *є* часом, а не просто *містить* його:

```python
import re

time = "12:20"

for match in re.finditer(r"^\d\d:\d\d$", time):
    print(match.group())
```

Результат:

```text
12:20
```

Перевірмо його ще на кількох рядках:

```python
import re

pattern = r"^\d\d:\d\d$"

for text in ["12:20", "30:99", "at 12:20", "12:205"]:
    print(f"{text!r:10}", re.search(pattern, text) is not None)
```

Результат:

```text
'12:20'    True
'30:99'    True
'at 12:20' False
'12:205'   False
```

Якорі правильно відкидають зайвий текст до чи після часу. Проте `30:99` проходить, бо шаблон перевіряє лише **форму** «дві цифри, двокрапка, дві цифри», а не значення. У 24-годинному форматі коректний час — від `00:00` до `23:59`: години від `00` до `23`, хвилини від `00` до `59`.

Як попередній погляд, ось шаблон, що перевіряє й діапазони. Він використовує набори на зразок `[01]` і `[0-5]` (див. тему «Набори та діапазони») та альтернативу `|` усередині групи (див. тему «Групування»): «`0` або `1`, а за ними будь-яка цифра, **або** `2`, а за ним цифра від `0` до `3`».

```python
import re

pattern = r"^([01]\d|2[0-3]):[0-5]\d$"

for t in ["00:00", "09:45", "23:59", "24:00", "30:99", "7:05"]:
    print(t, bool(re.search(pattern, t)))
```

Результат:

```text
00:00 True
09:45 True
23:59 True
24:00 False
30:99 False
7:05 False
```

## Пастка символу нового рядка: `$` чи `\Z`

`$` має одне несподіване правило: він відповідає кінцю рядка **і ще позиції перед символом нового рядка в самому кінці**. Це зручно, коли ви обробляєте рядки, прочитані з файлу, бо вони зазвичай закінчуються на `\n`. Але під час перевірки даних це означає, що рядок із зайвим `\n` проходить перевірку:

```python
import re

text = "12:20\n"

print(re.search(r"^\d\d:\d\d$", text))
print(re.search(r"\A\d\d:\d\d\Z", text))
print(re.fullmatch(r"\d\d:\d\d", text))
```

Результат:

```text
<re.Match object; span=(0, 5), match='12:20'>
None
None
```

`\A` і `\Z` — суворі якорі: `\A` відповідає лише початку рядка, а `\Z` — лише його абсолютному кінцю. `re.fullmatch()` поводиться так само суворо, і для перевірки даних це зазвичай найзрозуміліший варіант.

Через те саме правило `$` може навіть збігтися двічі в одному рядку:

```python
>>> import re
>>> [m.span() for m in re.finditer(r"$", "abc\n")]
[(3, 3), (4, 4)]
```

> **Зверніть увагу:** у Perl, Java та багатьох інших рушіях регулярних виразів `\Z` поводиться як `$` у Python і пропускає завершальний символ нового рядка, а суворим кінцем там є `\z` (мала літера). Починаючи з **Python 3.14**, модуль `re` теж приймає `\z` як синонім `\Z`, тож суворий якір усюди пишеться однаково. У старіших версіях Python використовуйте `\Z`.

## Багаторядковий режим: `re.MULTILINE`

Типово `^` і `$` стосуються всього рядка, навіть якщо в ньому багато рядків тексту. Прапорець `re.MULTILINE` (скорочено `re.M`) змушує їх відповідати початку й кінцю **кожного рядка**:

```python
import re

log = """ERROR 1 disk full
INFO 2 started
ERROR 3 timeout"""

print(re.findall(r"^ERROR", log))
print(re.findall(r"^ERROR", log, re.MULTILINE))
```

Результат:

```text
['ERROR']
['ERROR', 'ERROR']
```

Без прапорця підходить лише `ERROR` на самому початку тексту. З ним враховується початок кожного рядка. `$` змінюється так само:

```python
import re

text = "a1\nb2\nc3"

print(re.findall(r"\d$", text))
print(re.findall(r"\d$", text, re.MULTILINE))
print(re.findall(r"\A\w", text, re.MULTILINE))
```

Результат:

```text
['3']
['1', '2', '3']
['a']
```

`\A` ігнорує `re.MULTILINE`: він завжди означає початок усього рядка. Те саме стосується `\Z`.

| Якір | Типово | З `re.MULTILINE` |
|---|---|---|
| `^` | початок рядка | початок рядка і позиція одразу після кожного `\n` |
| `$` | кінець рядка або позиція перед завершальним `\n` | кінець рядка і позиція одразу перед кожним `\n` |
| `\A` | початок рядка | початок рядка (без змін) |
| `\Z` | кінець рядка | кінець рядка (без змін) |

## Нульова ширина на практиці: вставлення тексту

Оскільки якір відповідає порожній позиції, заміна якоря **вставляє** текст, нічого не видаляючи. Цей однорядковий код цитує кожен рядок повідомлення, як це роблять поштові клієнти:

```python
import re

text = "first line\nsecond line\nthird line"

print(re.sub(r"^", "> ", text, flags=re.MULTILINE))
```

Результат:

```text
> first line
> second line
> third line
```

Зверніть увагу: `flags=re.MULTILINE` передано **за ключовим словом**. Четвертий позиційний аргумент `re.sub()` — це `count`, а не `flags` (див. «Типові помилки»).

## Якорі та функції `match()` і `fullmatch()`

Функції з попередніх тем тісно пов'язані з якорями:

- `re.match(p, s)` поводиться як `re.search(r"\A(?:" + p + ")", s)`: збіг мусить починатися з позиції 0.
- `re.fullmatch(p, s)` поводиться як `re.search(r"\A(?:" + p + r")\Z", s)`: збіг мусить покривати весь рядок.

Для перевірки всього рядка `fullmatch()` — найчитабельніший варіант. Якорі незамінні в інших випадках: усередині `findall()`, `finditer()` і `sub()`, для обробки тексту рядок за рядком із `re.MULTILINE` та коли важливий лише один кінець рядка.

## Буквальні `$` і `^`

Щоб знайти самі символи, екрануйте їх: `\$` і `\^`. Неекранований `$` посеред шаблону означає «кінець рядка», тож після нього нічого не може йти, і шаблон ніколи не спрацює:

```python
import re

prices = "Total: $45, tax $5"

print(re.findall(r"\$\d\d", prices))
print(re.findall(r"$\d\d", prices))
```

Результат:

```text
['$45']
[]
```

Усередині квадратних дужок каретка має іншу роль: `[^0-9]` означає «будь-який символ, крім цифри». Про це йдеться в темі «Набори та діапазони».

## Типові помилки

- **Перевірка без якорів.** `re.search(r"\d\d:\d\d", "abc12:20xyz")` спрацьовує. Додайте якорі або використайте `fullmatch()`.
- **Покладатися на `$` під час суворої перевірки.** `^\d\d:\d\d$` приймає `"12:20\n"`. Використовуйте `\A...\Z` або `fullmatch()`.
- **Забутий `re.MULTILINE`.** Без нього `^` і `$` дивляться лише на початок і кінець усього тексту, а не кожного рядка.
- **Позиційна передача прапорців у `re.sub()` чи `re.split()`.** Їхній четвертий позиційний параметр — `count` / `maxsplit`. `re.MULTILINE` — це просто число 8, тож воно непомітно перетворюється на «замінити щонайбільше 8 разів», а прапорець не застосовується. Починаючи з Python 3.13 це ще й викликає `DeprecationWarning`:

  ```python
  import re

  text = "first line\nsecond line\nthird line"

  print(re.sub(r"^", "> ", text, re.MULTILINE))
  ```

  Результат (шлях до файлу скорочено):

  ```text
  .../example.py:5: DeprecationWarning: 'count' is passed as positional argument
    print(re.sub(r"^", "> ", text, re.MULTILINE))
  > first line
  second line
  third line
  ```

  Завжди пишіть `flags=re.MULTILINE`.

- **Неекранований `$` у цінах.** `r"$\d\d"` не спрацює ніколи. Пишіть `r"\$\d\d"`.
- **Сприймати `^` усередині `[...]` як якір.** У `[^abc]` це заперечення, а не «початок рядка».

## Підсумок

- Якорі відповідають позиціям, а не символам. Вони мають нульову ширину й нічого не поглинають.
- `^` відповідає початку рядка, `$` — кінцю.
- `^...$` разом перевіряють, що шаблон покриває весь рядок, але `$` спрацьовує ще й перед завершальним символом нового рядка.
- `\A` і `\Z` завжди означають абсолютні початок і кінець рядка. Python 3.14 приймає також `\z` як синонім `\Z`.
- `re.MULTILINE` змушує `^` і `$` відповідати початку й кінцю кожного рядка тексту. На `\A` і `\Z` прапорець не впливає.
- Для перевірки всього рядка зазвичай найзрозуміліший інструмент — `re.fullmatch()`.
- Передавайте прапорці в `re.sub()` і `re.split()` за ключовим словом, а `$` і `^` екрануйте, коли потрібні самі символи.

## Розв'язки

### Вправа 1

```python
import re


def is_year(text):
    return re.search(r"\A\d\d\d\d\Z", text) is not None


for candidate in ["2024", "2024\n", "12024", "year 2024"]:
    print(repr(candidate), is_year(candidate))
```

Результат:

```text
'2024' True
'2024\n' False
'12024' False
'year 2024' False
```

Із `^...$` рядок `"2024\n"` було б прийнято.

### Вправа 2

```python
import re

config = """# database settings
database:
  host: localhost
# cache settings
cache:
  enabled: yes"""

comments = re.findall(r"^#", config, re.MULTILINE)
sections = re.findall(r":$", config, re.MULTILINE)

print(len(comments), len(sections))
```

Результат:

```text
2 2
```

Без `re.MULTILINE` вийшло б `1` (перевіряється лише перший рядок) і `0` (текст закінчується на `yes`, а не на `:`).

### Вправа 3

```python
import re


def is_valid_time(text):
    if not re.fullmatch(r"\d\d:\d\d", text):
        return False
    hours, minutes = int(text[:2]), int(text[3:])
    return hours <= 23 and minutes <= 59


for candidate in ["00:00", "23:59", "24:00", "12:60", "7:05", "12:30\n"]:
    print(repr(candidate), is_valid_time(candidate))
```

Результат:

```text
'00:00' True
'23:59' True
'24:00' False
'12:60' False
'7:05' False
'12:30\n' False
```

Розподіл роботи між регулярним виразом (форма) і звичайним Python (діапазони) часто дає код, який читати легше, ніж один величезний шаблон.

### Вправа 4

```python
import re

reply = "Hi Olena,\nthanks for the update.\nSee you!"

print(re.sub(r"^", "> ", reply, flags=re.MULTILINE))
```

Результат:

```text
> Hi Olena,
> thanks for the update.
> See you!
```
