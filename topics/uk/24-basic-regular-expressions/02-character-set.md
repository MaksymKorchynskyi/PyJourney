# Класи символів

**Клас символів** (character set, або character class) — це елемент регулярного виразу, що позначає цілу групу символів: усі цифри, усі «символи слова», усі види пробільних символів. Класи символів — базові цеглинки майже кожного шаблону, тож точне розуміння того, що кожен із них знаходить (і чого не знаходить), рятує від багатьох прихованих помилок.

## Що ви дізнаєтесь

- Що таке клас символів і чому кожен клас відповідає рівно **одному** символу
- Як використовувати `\d`, `\w` і `\s` та їхні обернені класи `\D`, `\W` і `\S`
- Як працює крапка `.` і як її поведінку змінює `re.DOTALL`
- Як Unicode впливає на ці класи в Python 3 і як `re.ASCII` їх обмежує
- Як знайти буквальну крапку

## Що таке клас символів

Клас символів описує групу символів і щоразу відповідає **рівно одному символу** з цієї групи. Щоб знайти дві цифри, потрібні два класи цифр поспіль (або квантифікатор, про нього згодом). У модулі `re` є кілька вбудованих скорочених класів:

| Клас | Відповідає одному... | Обернений клас |
|---|---|---|
| `\d` | цифровому символу | `\D` |
| `\w` | символу слова: літері, цифрі або підкресленню | `\W` |
| `\s` | пробільному символу | `\S` |
| `.` | будь-якому символу, крім символу нового рядка | (немає) |

Також можна створювати власні класи у квадратних дужках, наприклад `[aeiou]` чи `[0-9]`. Цьому присвячено тему «Набори та діапазони».

## `\d`: цифри

`\d` відповідає одній цифрі. У прикладі `finditer()` перелічує всі цифри в рядку:

```python
import re

s = "Python 3.0 was released in 2008"

for match in re.finditer(r"\d", s):
    print(match.group())
```

Результат:

```text
3
0
2
0
0
8
```

Щоб знайти дві цифри поспіль, поставте два класи один за одним:

```python
import re

s = "Python 3.0 was released in 2008"

for match in re.finditer(r"\d\d", s):
    print(match.group(), match.span())
```

Результат:

```text
20 (27, 29)
08 (29, 31)
```

Тут варто помітити дві речі:

- `3.0` не підходить, бо між цифрами стоїть крапка.
- `2008` дає `20` і `08`, але не `00`. Збіги ніколи не перекриваються: знайшовши `20`, рушій продовжує пошук одразу після нього.

Чотири цифри поспіль працюють так само:

```python
import re

s = "Python 3.0 was released in 2008"

for match in re.finditer(r"\d\d\d\d", s):
    print(match.group())
```

Результат:

```text
2008
```

Писати `\d\d\d\d` швидко набридає. У темі «Квантифікатори» ви побачите коротший запис `\d{4}`.

### `\d` і цифри Unicode

У Python 3 шаблони типу `str` працюють у **режимі Unicode**. Тоді `\d` відповідає будь-якій десятковій цифрі Unicode, а не лише `0`–`9`. Наприклад, арабсько-індійські цифри теж підходять:

```python
import re

text = "Price: ٣٤ or 34"

print(re.findall(r"\d", text))
print(re.findall(r"\d", text, flags=re.ASCII))
print(re.findall(r"[0-9]", text))
```

Результат:

```text
['٣', '٤', '3', '4']
['3', '4']
['3', '4']
```

Коли ви перевіряєте дані, що мають містити лише ASCII-цифри `0`–`9` (номери карток, PIN-коди, ідентифікатори для інших систем), використовуйте `[0-9]` або прапорець `re.ASCII`.

## `\w`: символи слова

`\w` відповідає одному **символу слова** (word character): літері, цифрі або підкресленню `_`.

```python
import re

s = "Python 3.0"

for match in re.finditer(r"\w", s):
    print(match.group())
```

Результат:

```text
P
y
t
h
o
n
3
0
```

Пробіл і крапка не є символами слова, тому їх пропущено.

У багатьох посібниках пишуть, що `\w` знаходить лише ASCII-літери. Для шаблонів `str` у Python 3 це **неправда**. У режимі Unicode `\w` приймає літери будь-якої абетки. Прапорець `re.ASCII` обмежує його до `[a-zA-Z0-9_]`:

```python
import re

print(re.findall(r"\w", "café_2 є"))
print(re.findall(r"\w", "café_2 є", re.ASCII))
```

Результат:

```text
['c', 'a', 'f', 'é', '_', '2', 'є']
['c', 'a', 'f', '_', '2']
```

> **Зверніть увагу:** кирилиця обробляється так само, як латиниця. Українські літери, зокрема `є`, `і`, `ї` та `ґ`, — повноцінні символи слова для `\w`, тож і `\W`, і межа слова `\b` поводяться з українським текстом правильно без жодних прапорців:

```python
>>> import re
>>> re.findall(r"\w", "Київ!")
['К', 'и', 'ї', 'в']
```

Не менш важливо, чого `\w` **не** включає: дефіс, крапка, машинописний апостроф `'` і типографський апостроф `’` не є символами слова. Тому українські слова з апострофом розпадаються на дві частини, якщо тільки текст не використовує літеру-апостроф `ʼ` (U+02BC), яку Unicode зараховує до літер:

```python
>>> import re
>>> re.findall(r"\w", "a-b.c!d e'f")
['a', 'b', 'c', 'd', 'e', 'f']
>>> re.findall(r"\w", "п'ять")
['п', 'я', 'т', 'ь']
>>> re.findall(r"\w\w\w\w\w", "пʼять")
['пʼять']
```

## `\s`: пробільні символи

`\s` відповідає одному пробільному символу (whitespace):

```python
import re

s = "Python 3.0"

for match in re.finditer(r"\s", s):
    print(match)
```

Результат:

```text
<re.Match object; span=(6, 7), match=' '>
```

До цього класу належить не лише пробіл, а й табуляція `\t`, символ нового рядка `\n`, повернення каретки `\r`, розрив сторінки `\f` і вертикальна табуляція `\v`. У режимі Unicode сюди входять і інші пробіли Unicode, наприклад нерозривний пробіл `\xa0`, який часто потрапляє в текст із вебсторінок і текстових редакторів:

```python
import re

text = "a b\tc\nd\re\x0bf\x0cg\xa0h"

print(re.findall(r"\s", text))
print(re.findall(r"\s", text, re.ASCII))
```

Результат:

```text
[' ', '\t', '\n', '\r', '\x0b', '\x0c', '\xa0']
[' ', '\t', '\n', '\r', '\x0b', '\x0c']
```

`\s` зручний для нормалізації тексту. Тут кожен пробільний символ замінюється на підкреслення:

```python
import re

print(re.sub(r"\s", "_", "one two\tthree\nfour"))
```

Результат:

```text
one_two_three_four
```

## Обернені класи: `\D`, `\W`, `\S`

Кожен скорочений клас має обернений, що записується тією самою літерою у верхньому регістрі. Обернений клас відповідає одному символу, який **не** належить до початкового класу:

| Клас | Обернений | Обернений клас відповідає символу, який... |
|---|---|---|
| `\d` | `\D` | не є цифрою |
| `\w` | `\W` | не є символом слова (пробіл, розділові знаки, інші символи) |
| `\s` | `\S` | не є пробільним |

`\D` знаходить у номері телефону все, крім цифр:

```python
import re

phone_no = "+1-(650)-513-0514"

for match in re.finditer(r"\D", phone_no):
    print(match.group())
```

Результат:

```text
+
-
(
)
-
-
```

У парі з `re.sub()` це прибирає все форматування одним викликом. Кожен символ, що відповідає `\D`, замінюється порожнім рядком:

```python
import re

phone_no = re.sub(r"\D", "", "+1-(650)-513-0514")
print(phone_no)
```

Результат:

```text
16505130514
```

`\W` вибирає пробіли й розділові знаки, а `\S` — усе, крім пробільних символів:

```python
import re

print(re.findall(r"\W", "Hi, Bob! It's 5:00."))
print(re.findall(r"\S", " a \t b\n"))
```

Результат:

```text
[',', ' ', '!', ' ', "'", ' ', ':', '.']
['a', 'b']
```

> **Зверніть увагу:** клас і обернений до нього разом охоплюють усі можливі символи: кожен символ або цифра, або ні. Тому `[\d\D]` чи `[\s\S]` іноді використовують як «будь-який символ, включно із символом нового рядка».

## Крапка `.`

Крапка відповідає **будь-якому одному символу, крім символу нового рядка** `\n`:

```python
import re

version = "Python\n4"

for match in re.finditer(r".", version):
    print(match.group())
```

Результат:

```text
P
y
t
h
o
n
4
```

Символ нового рядка пропущено. Крапка зупиняється на межах рядків навмисно: інакше шаблони з багатьма крапками поспіль «перетікали» б через кілька рядків журналу чи файлу. Якщо ж потрібно, щоб крапка знаходила й символи нового рядка, передайте прапорець `re.DOTALL` (скорочено `re.S`):

```python
import re

version = "Python\n4"

print(re.findall(r".", version))
print(re.findall(r".", version, re.DOTALL))
```

Результат:

```text
['P', 'y', 't', 'h', 'o', 'n', '4']
['P', 'y', 't', 'h', 'o', 'n', '\n', '4']
```

### Як знайти буквальну крапку

Крапка — метасимвол, тому шаблон `3.0` означає «3, будь-який символ, 0». Щоб знайти справжню крапку, екрануйте її зворотною скісною рискою: `\.`.

```python
import re

text = "3.0 and 330 and 3a0"

print(re.findall(r"3.0", text))
print(re.findall(r"3\.0", text))
```

Результат:

```text
['3.0', '330', '3a0']
['3.0']
```

Те саме правило стосується інших метасимволів: `\+`, `\*`, `\?`, `\(`, `\$` тощо.

## Режим Unicode чи `re.ASCII`

| Клас | Типовий режим (Unicode) | З `re.ASCII` |
|---|---|---|
| `\d` | будь-яка десяткова цифра Unicode | `[0-9]` |
| `\w` | літери будь-якої абетки, цифри, `_` | `[a-zA-Z0-9_]` |
| `\s` | усі пробільні символи Unicode | `[ \t\n\r\f\v]` |

Обернені класи змінюються відповідно, як і межа слова `\b`, що визначається через `\w`. Шаблони типу `bytes` (`rb"\w"`) завжди працюють лише з ASCII.

## Типові помилки

- **Неекранована крапка.** `r"\d.\d"` охоче знаходить `"3x0"` і `"3 0"`. Для справжньої крапки пишіть `r"\d\.\d"`.
- **Вважати, що `\w` — це `[a-zA-Z0-9_]`.** У Python 3 він знаходить також `é`, `ї`, `ß` та інші літери. Якщо потрібен лише ASCII, використовуйте `re.ASCII` або явний набір.
- **Очікувати, що `\w` охоплює дефіси й апострофи.** І `"well-known"`, і `"п'ять"` розпадаються на дві частини.
- **Вважати, що `\d` — це лише `0`–`9`.** Він приймає й цифри інших писемностей. Для суворої перевірки беріть `[0-9]` або `re.ASCII`.
- **Очікувати, що `.` знайде символ нового рядка.** Без `re.DOTALL` не знайде.
- **Думати, що один клас відповідає кільком символам.** `\d` — це рівно один символ. Для `"42"` потрібно `\d\d` або квантифікатор, як-от `\d+`.

## Підсумок

- Клас символів відповідає рівно одному символу з групи.
- `\d` — цифра, `\w` — символ слова (літера, цифра або `_`), `\s` — пробільний символ.
- `\D`, `\W` і `\S` — обернені класи: вони відповідають будь-якому символу, що не входить у початковий клас.
- `.` відповідає будь-якому символу, крім символу нового рядка. З `re.DOTALL` — і йому теж.
- Буквальну крапку треба екранувати: `\.`.
- У Python 3 шаблони `str` враховують Unicode: `\w` приймає кирилицю та літери з діакритикою, а `\d` — цифри інших писемностей. `re.ASCII` обмежує класи до ASCII.

## Практика

### Вправа 1: Очистіть номер телефону

Перетворіть `"+38 (067) 123-45-67"` на `"380671234567"` одним викликом `re.sub()`.

### Вправа 2: Статистика пробільних символів

Для `text = "Line one\n\tLine two  end\n"` порахуйте пробільні символи за допомогою `\s` і непробільні — за допомогою `\S`. Перевірте, що сума дорівнює `len(text)`.

### Вправа 3: Номери версій

У рядку `"Python 2.7, 3.9 and 3x0"` знайдіть усі послідовності «цифра, крапка, цифра». Виконайте пошук із `r"\d.\d"` і з `r"\d\.\d"` та поясніть різницю.

### Вправа 4: Unicode чи ASCII

Для рядка `"naïve café — Київ"` порахуйте символи слова з `re.ASCII` і без нього. Виведіть символи, які лишаються з `re.ASCII`.

## Розв'язки

### Вправа 1

```python
import re

print(re.sub(r"\D", "", "+38 (067) 123-45-67"))
```

Результат:

```text
380671234567
```

### Вправа 2

```python
import re

text = "Line one\n\tLine two  end\n"

spaces = len(re.findall(r"\s", text))
others = len(re.findall(r"\S", text))

print(spaces, others)
print(spaces + others == len(text))
```

Результат:

```text
7 17
True
```

У рядку чотири пробіли, два символи нового рядка й одна табуляція. Кожен символ або пробільний, або ні, тому сума завжди дорівнює довжині рядка.

### Вправа 3

```python
import re

s = "Python 2.7, 3.9 and 3x0"

print(re.findall(r"\d.\d", s))
print(re.findall(r"\d\.\d", s))
```

Результат:

```text
['2.7', '3.9', '3x0']
['2.7', '3.9']
```

Неекранована крапка приймає будь-який символ, тож `3x0` проходить. Екранована `\.` приймає лише справжню крапку.

### Вправа 4

```python
import re

text = "naïve café — Київ"

unicode_chars = re.findall(r"\w", text)
ascii_chars = re.findall(r"\w", text, re.ASCII)

print(len(unicode_chars), len(ascii_chars))
print(ascii_chars)
```

Результат:

```text
13 7
['n', 'a', 'v', 'e', 'c', 'a', 'f']
```

У режимі Unicode враховуються всі 13 літер, зокрема `ï`, `é` і чотири кириличні літери. З `re.ASCII` лишаються тільки 7 звичайних латинських літер.
