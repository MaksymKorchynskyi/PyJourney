# Зрізи докладно

У темі «Послідовності в Python» ви познайомилися з базовим зрізом `s[i:j]`. Тут ми зазирнемо глибше: як Python тлумачить `start`, `stop` і `step` (зокрема від'ємні значення й значення поза межами), що таке об'єкт `slice`, як *присвоювати* й *видаляти* зрізи списку і що при цьому копіюється, а що спільне. Ці деталі пояснюють багато однорядкових ідіом, як-от `s[::-1]`, `s[:] = ...` і `del s[::2]`.

## Що ви дізнаєтесь

- Як тлумачаться `start`, `stop` і `step`, зокрема значення за замовчуванням, від'ємні значення й межі поза послідовністю
- Як працює від'ємний крок і чому `s[3:-1:-1]` порожній
- Що таке об'єкт `slice`, як іменувати й повторно використовувати зрізи і що отримує `__getitem__`
- Як `slice.indices()` перетворює будь-який зріз на конкретні аргументи для `range()`
- Як замінювати, вставляти й видаляти елементи через присвоєння зрізу та `del`
- Що зріз — це поверхнева копія і що використовувати для ітераторів і для перегляду без копіювання

## Отримання та присвоєння

Для будь-якої послідовності зріз **отримує** її частину. Для змінюваних послідовностей, як-от списків, можна також **присвоїти** значення зрізу й замінити цю частину:

```python
colors = ["red", "green", "blue", "orange"]

# отримати дані
print(colors[1:3])

# присвоїти дані
colors[1:3] = ["pink", "black"]
print(colors)
```

Результат:

```text
['green', 'blue']
['red', 'pink', 'black', 'orange']
```

Незмінювані послідовності, як-от рядки, кортежі та bytes, підтримують лише отримання:

```python
topic = "Python Slicing"

# отримати дані
print(topic[0:6])
print(topic[7:])
```

Результат:

```text
Python
Slicing
```

Присвоєння зрізу незмінюваної послідовності завершується помилкою:

```python
topic = "Python Slicing"
topic[0:6] = "Java"
```

Результат (останній рядок трасування):

```text
TypeError: 'str' object does not support item assignment
```

Щоб «змінити» рядок, створіть новий: `"Java" + topic[6:]`.

## Початок і кінець

`seq[start:stop]` вибирає всі елементи, індекс `n` яких задовольняє умову:

```text
start <= n < stop
```

Елемент з індексом `stop` **не** входить у результат. Найпростіше міркувати так: індекси стоять **між** елементами, як поділки на лінійці. Зріз бере все, що лежить між двома поділками:

```text
         +-------+---------+--------+----------+
         | "red" | "green" | "blue" | "orange" |
         +-------+---------+--------+----------+
додатні   0       1         2        3          4
від'ємні -4      -3        -2       -1
```

`colors[1:3]` — це все між поділкою `1` і поділкою `3`: `"green"` і `"blue"`.

### Значення за замовчуванням і межі поза послідовністю

Обидві межі необов'язкові: `start` за замовчуванням означає початок, а `stop` — кінець. Межі, що виходять за послідовність, **обрізаються** до неї, тож зріз ніколи не генерує `IndexError`:

```python
colors = ["red", "green", "blue", "orange"]

print(colors[0:100])
print(colors[10:])
print(colors[-100:2])
print(colors[3:1])
```

Результат:

```text
['red', 'green', 'blue', 'orange']
[]
['red', 'green']
[]
```

- `stop=100` лежить за кінцем, тому Python використовує `len(colors)`.
- `start=10` теж обрізається до `len(colors)`, і вибирати вже нічого.
- `start=-100` обрізається до початку.
- Коли `start` стоїть у `stop` або після нього (за додатного кроку), результат просто порожній.

Така поблажливість зручна (`s[:3]` працює, навіть якщо в `s` менше трьох елементів), але вона й ховає помилки: одрук в індексі дає порожній чи закороткий результат замість винятку. Звертання до одного елемента, `colors[10]`, генерує `IndexError`.

### Від'ємні межі

Від'ємна межа відраховується від кінця: Python додає до неї `len(seq)`. Для чотирьох елементів `-4` означає `0`, а `-2` означає `2`. Від'ємні й додатні межі можна поєднувати:

```python
colors = ["red", "green", "blue", "orange"]

print(colors[-4:-2])
print(colors[-2:4])
print(colors[-2:])
print(colors[:-1])
```

Результат:

```text
['red', 'green']
['blue', 'orange']
['blue', 'orange']
['red', 'green', 'blue']
```

`s[-n:]` («останні `n` елементів») і `s[:-n]` («усе, крім останніх `n`») — найуживаніші ідіоми.

### Дві корисні властивості

Оскільки `stop` не включається, зрізи стикуються без пропусків і перекриттів:

```python
letters = "abcdefgh"

print(all(letters[:k] + letters[k:] == letters for k in range(len(letters) + 1)))
print(len(letters[2:5]), 5 - 2)
```

Результат:

```text
True
3 3
```

`s[:k] + s[k:]` завжди відтворює `s`, а для меж усередині послідовності `len(s[i:j])` дорівнює просто `j - i`. Саме тому Python використовує індекси з нуля та невключний кінець.

## Крок

Необов'язкове третє значення, **крок** (step), вибирає кожен `step`-й елемент. За замовчуванням він дорівнює `1`:

```python
colors = ["red", "green", "blue", "orange"]

print(colors[0:4:2])
print(colors[::2])
print(colors[1::2])

digits = list(range(10))
print(digits[1:8:3])
```

Результат:

```text
['red', 'blue']
['red', 'blue']
['green', 'orange']
[1, 4, 7]
```

`s[::2]` бере елементи на парних позиціях, а `s[1::2]` — на непарних. `digits[1:8:3]` починає з індексу `1` і додає `3`, доки індекс менший за `8`: `1, 4, 7`.

Нульовий крок ніколи не зрушив би з місця, тому його заборонено:

```python
colors = ["red", "green", "blue", "orange"]
print(colors[::0])
```

Результат (останній рядок трасування):

```text
ValueError: slice step cannot be zero
```

### Від'ємний крок

Від'ємний крок рухається **назад**. Тепер `start` має бути більшим індексом, а значення за замовчуванням міняються місцями: пропущений `start` означає «останній елемент», а пропущений `stop` — «за першим елементом»:

```python
colors = ["red", "green", "blue", "orange"]

print(colors[::-1])
print(colors[3:0:-1])
print(colors[::-2])
print("stressed"[::-1])
```

Результат:

```text
['orange', 'blue', 'green', 'red']
['orange', 'blue', 'green']
['orange', 'green']
desserts
```

`colors[3:0:-1]` іде від індексу `3` униз до індексу `0`, не включаючи його, тож `"red"` випадає. Як записати кінець так, щоб включити індекс `0`? Тільки не через `-1`:

```python
colors = ["red", "green", "blue", "orange"]

print(colors[3:-1:-1])      # -1 означає «останній елемент», а не «перед початком»
print(colors[3:None:-1])    # None означає «до самого кінця»
print(colors[-1:-5:-1])
```

Результат:

```text
[]
['orange', 'blue', 'green', 'red']
['orange', 'blue', 'green', 'red']
```

`-1` перетворюється на `3` (останній індекс), тож `colors[3:-1:-1]` означає «від 3 униз до 3, не включаючи», а це порожньо. Щоб дійти до самого початку, використовуйте `None` (або пропустіть кінець) чи від'ємний кінець, що лежить перед першим елементом, наприклад `-len(colors) - 1`.

> **Порада:** `s[::-1]` створює перевернуту копію. Якщо потрібно лише пройти послідовність у зворотному порядку, `reversed(s)` дешевший: він повертає ітератор і нічого не копіює.

## Об'єкт slice

Запис через двокрапку — це скорочення для об'єкта `slice`. `seq[start:stop:step]` — те саме, що `seq[slice(start, stop, step)]`:

```python
s = slice(1, 3)

print(type(s))
print(s.start, s.stop, s.step)
print(slice(3))
```

Результат:

```text
<class 'slice'>
1 3 None
slice(None, 3, None)
```

Пропущені частини зберігаються як `None`. З одним аргументом `slice(3)` задає лише `stop`, так само як `range(3)`. Об'єкт зрізу можна передати у квадратних дужках усюди, де дозволено зріз:

```python
colors = ["red", "green", "blue", "orange"]
s = slice(1, 3)

print(colors[s])
print("abcdef"[s])
```

Результат:

```text
['green', 'blue']
bc
```

### Що отримує `__getitem__`

Коли ви пишете `obj[...]`, Python викликає `obj.__getitem__(key)`. Ключ — це ціле число для індексації, об'єкт `slice` для зрізу й кортеж, якщо всередині є коми:

```python
class Probe:
    def __getitem__(self, key):
        return key


p = Probe()
print(p[2])
print(p[1:3])
print(p[::2])
print(p[:])
print(p[1:5, ::-1])
```

Результат:

```text
2
slice(1, 3, None)
slice(None, None, 2)
slice(None, None, None)
(slice(1, 5, None), slice(None, None, -1))
```

Вбудовані послідовності не приймають кортежів зрізів, але бібліотеки на кшталт NumPy використовують їх для багатовимірних зрізів (`matrix[1:3, ::2]`). Щоб підтримати зрізи у власному класі послідовності, перевіряйте в `__getitem__` умову `isinstance(key, slice)`. Повні приклади є в темах «Послідовності в Python» і «Послідовність Фібоначчі».

### Іменовані зрізи

Об'єкти зрізів дають змогу назвати фіксовані позиції, і код, що розбирає текст із полями фіксованої ширини, стає значно зрозумілішим:

```python
line = "2026-11-25 ORD-1042   149.90"
#       0123456789012345678901234567

DATE = slice(0, 10)
ORDER = slice(11, 19)
AMOUNT = slice(19, None)

print(line[DATE])
print(line[ORDER])
print(float(line[AMOUNT]))
```

Результат:

```text
2026-11-25
ORD-1042
149.9
```

`line[AMOUNT]` значно зрозуміліше, ніж `line[19:]`, а коли формат зміниться, позиції доведеться оновити лише в одному місці.

Починаючи з Python 3.12, об'єкти зрізів **хешовані**, тож можуть бути ключами словника чи елементами множини:

```python
cache = {slice(0, 10): "first page"}      # зрізи хешовані, починаючи з 3.12
print(cache[slice(0, 10)])
```

Результат:

```text
first page
```

## slice.indices(): нормалізація зрізу

Сам об'єкт зрізу не знає довжини послідовності, тож його `start` і `stop` можуть бути `None`, від'ємними чи поза межами. Метод `indices(length)` розв'язує все це для послідовності заданої довжини й повертає кортеж `(start, stop, step)` із конкретних цілих чисел, готових для `range()`:

```python
colors = ["red", "green", "blue", "orange"]

s = slice(0, 4, 2)
t = s.indices(len(colors))
print(t)

for index in range(*t):
    print(colors[index])
```

Результат:

```text
(0, 4, 2)
red
blue
```

`range(*t)` розпаковує кортеж у `range(0, 4, 2)`, і той видає саме ті індекси, які вибирає зріз. Метод застосовує значення за замовчуванням, перетворення від'ємних індексів і обрізання, описані вище:

```python
length = 4
print(slice(None, None, -1).indices(length))
print(slice(-100, 100).indices(length))
print(slice(-3, None, 2).indices(length))
print(list(range(*slice(None, None, -1).indices(length))))
```

Результат:

```text
(3, -1, -1)
(0, 4, 1)
(1, 4, 2)
[3, 2, 1, 0]
```

Зверніть увагу на перший рядок: нормалізований кінець дорівнює `-1`. Для `range()` це звичайне число, що означає «зупинитися, не дійшовши до -1», тож `range(3, -1, -1)` дає `3, 2, 1, 0`. Якби ви знову підставили `(3, -1, -1)` у зріз, `-1` означало б «останній елемент», і результат був би порожнім. Результат `indices()` призначений для `range()`, а не для повторного зрізу.

## Присвоєння зрізам

Для списків та інших змінюваних послідовностей присвоєння зрізу замінює вибрану частину елементами будь-якого ітерованого об'єкта. Для простого зрізу (без кроку) нова частина **може мати іншу довжину**, тож список росте або скорочується:

```python
nums = [1, 2, 3, 4, 5]

nums[1:2] = [20, 30, 40]     # замінити один елемент трьома
print(nums)

nums[1:4] = []               # замінити три елементи нічим
print(nums)

nums[2:2] = [7, 8]           # порожній зріз: чиста вставка
print(nums)

nums[:0] = [0]               # додати на початок
nums[len(nums):] = [99]      # додати в кінець
print(nums)
```

Результат:

```text
[1, 20, 30, 40, 3, 4, 5]
[1, 3, 4, 5]
[1, 3, 7, 8, 4, 5]
[0, 1, 3, 7, 8, 4, 5, 99]
```

Порожній зріз, як-от `nums[2:2]`, нічого не вибирає, тож присвоєння йому вставляє елементи в цю позицію, нічого не видаляючи.

Права частина перебирається поелементно, і для рядків це важливо:

```python
letters = ["a", "b", "c"]
letters[0:1] = "xyz"         # підходить будь-який ітерований об'єкт, рядок дає символи
print(letters)

letters[0:3] = ["xyz"]       # загорніть у список, щоб вставити один елемент
print(letters)
```

Результат:

```text
['x', 'y', 'z', 'b', 'c']
['xyz', 'b', 'c']
```

Присвоєння неітерованого значення, як-от `nums[0:1] = 5`, генерує `TypeError: must assign iterable to extended slice`.

### Розширеним зрізам потрібна та сама довжина

Коли зріз має крок (**розширений зріз**, extended slice), вибрані позиції розкидані, тож Python не може вставляти чи видаляти елементи. Права частина має містити рівно стільки елементів, скільки вибирає зріз:

```python
nums = [1, 2, 3, 4, 5, 6]
nums[::2] = [0, 0, 0]
print(nums)

nums[::2] = [9, 9]
```

Результат (друге присвоєння завершується помилкою, показано останній рядок трасування):

```text
[0, 2, 0, 4, 0, 6]
ValueError: attempt to assign sequence of size 2 to extended slice of size 3
```

### Заміна всього вмісту на місці

`s[:] = ...` замінює **весь** вміст наявного списку. Об'єкт лишається тим самим, тож будь-яке інше посилання на нього бачить новий вміст. Звичайне присвоєння лише перев'язує ім'я (див. тему «Посилання» в розділі про змінні):

```python
scores = [70, 85, 90]
alias = scores

scores[:] = [100, 100]       # змінює наявний список
print(alias, alias is scores)

scores = [50]                # лише перев'язує ім'я
print(alias, alias is scores)
```

Результат:

```text
[100, 100] True
[100, 100] False
```

Це важливо, коли список спільний: наприклад, коли функція має оновити список викликача або коли об'єкт видає посилання на свій внутрішній список.

## Видалення зрізів

`del` теж працює зі зрізами, зокрема й розширеними:

```python
nums = list(range(10))

del nums[1:3]
print(nums)

del nums[::2]
print(nums)

del nums[:]
print(nums)
```

Результат:

```text
[0, 3, 4, 5, 6, 7, 8, 9]
[3, 5, 7, 9]
[]
```

`del nums[:]` очищує список на місці, так само як `nums.clear()`.

## Зрізи — це поверхневі копії

Зріз списку створює **новий список**, але самі елементи не копіюються. Обидва списки посилаються на ті самі об'єкти-елементи:

```python
matrix = [[1, 2], [3, 4]]
copy = matrix[:]

print(copy == matrix, copy is matrix)

copy.append([5, 6])        # зовнішні списки незалежні
copy[0][0] = 100           # але внутрішні списки спільні
print(matrix)
print(copy)
```

Результат:

```text
True False
[[100, 2], [3, 4]]
[[100, 2], [3, 4], [5, 6]]
```

`matrix[:]` (а також `list(matrix)` чи `matrix.copy()`) — це **поверхнева копія** (shallow copy). Для вкладених змінюваних даних використовуйте `copy.deepcopy()`.

Тип результату відповідає послідовності: зріз рядка дає рядок, кортежу — кортеж, а `range` — новий `range` без побудови жодного списку. Для незмінюваних послідовностей CPython навіть пропускає копіювання, коли ви берете зріз усієї послідовності, бо відрізнити копію однаково неможливо:

```python
word = "python"
point = (1, 2, 3)
print(word[:] is word, point[:] is point)

print(range(0, 20)[::3])
print(range(10)[::-1])
print(b"hello"[1:3])
```

Результат:

```text
True True
range(0, 20, 3)
range(9, -1, -1)
b'el'
```

> **Зверніть увагу:** те, що `word[:] is word` дорівнює `True`, — оптимізація CPython, а не гарантія мови. Ніколи на це не покладайтеся.

### Зрізи без копіювання через memoryview

Зазвичай копіювання не проблема, але для великих двійкових даних воно коштує часу й пам'яті. `memoryview` над об'єктом на кшталт `bytes` можна зрізати **без копіювання**: результат — це «вікно» в початковий буфер. Запис через таке вікно змінюваного буфера змінює оригінал:

```python
data = bytearray(b"hello world")
view = memoryview(data)[6:]     # без копіювання: вікно в data
view[0] = ord("W")
print(data)

part = data[6:]                 # звичайний зріз — це копія
part[0] = ord("w")
print(data, part)
```

Результат:

```text
bytearray(b'hello World')
bytearray(b'hello World') bytearray(b'world')
```

## Що можна зрізати

Зрізи працюють з усіма вбудованими послідовностями: `list`, `tuple`, `str`, `range`, `bytes`, `bytearray`, `memoryview` і `array.array`. Вони не працюють із:

- **множинами й словниками**, бо в них немає позицій. Відколи зрізи стали хешованими (Python 3.12), `d[0:2]` для словника генерує `KeyError: slice(0, 2, None)` (шукає такий ключ), а не `TypeError`;
- **`collections.deque`**, який підтримує індексацію, але не зрізи;
- **ітераторами й генераторами**, які взагалі не мають індексів.

Для двох останніх випадків `itertools.islice()` ліниво видає вибрані елементи один за одним:

```python
from collections import deque
from itertools import islice

squares = (n * n for n in range(10))
print(list(islice(squares, 2, 6)))

queue = deque([1, 2, 3, 4])
print(list(islice(queue, 1, 3)))
print(queue[1:3])
```

Результат (останній рядок завершується помилкою, показано останній рядок трасування):

```text
[4, 9, 16, 25]
[2, 3]
TypeError: sequence index must be integer, not 'slice'
```

`islice()` не підтримує від'ємних значень, бо ітератор не знає, де його кінець.

## Типові помилки

- **Очікувати помилки для зрізу поза межами.** `s[10:20]` для короткого списку — це просто `[]`. Якщо дані мають бути повними, перевіряйте довжину явно.
- **Забувати, що `stop` не включається.** `s[2:5]` містить три елементи: з індексами 2, 3 і 4.
- **Писати `-1` як кінець зворотного зрізу.** `s[3:-1:-1]` порожній. Використовуйте `s[3::-1]` або `s[3:None:-1]`.
- **Присвоювати зрізу рядок.** `items[0:1] = "abc"` вставляє три символи. Пишіть `items[0:1] = ["abc"]`.
- **Змінювати довжину через розширений зріз.** `s[::2] = ...` потребує рівно стількох елементів, скільки вибирає зріз.
- **Вважати зріз «вікном» в оригінал.** Зріз списку — це копія: її зміна не змінює початковий список (масиви NumPy і `memoryview` поводяться інакше).
- **Вважати зріз глибокою копією.** Вкладені змінювані елементи спільні для оригіналу та зрізу.
- **Підставляти результат `slice.indices()` назад у зріз.** Він призначений для `range()`. Кінець `-1` там означає «перед індексом 0».

## Підсумок

- `s[start:stop:step]` вибирає індекси від `start` до `stop` (не включаючи його) з кроком `step`. Усі три частини необов'язкові.
- Від'ємні межі відраховуються від кінця. Межі поза послідовністю обрізаються, тож зріз ніколи не генерує `IndexError`.
- Від'ємний крок рухається назад і міняє значення за замовчуванням. `s[::-1]` — перевернута копія, а «до самого початку» означає `None`, а не `-1`.
- Запис із двокрапкою створює об'єкт `slice`. Іменовані зрізи роблять розбір полів фіксованої ширини зрозумілим, а `__getitem__` отримує сам об'єкт зрізу.
- `slice.indices(length)` повертає конкретні значення `(start, stop, step)` для `range()`.
- Змінювані послідовності підтримують присвоєння зрізам і `del`. Прості зрізи можуть змінювати довжину, розширені — ні. `s[:] = ...` замінює вміст на місці.
- Зріз повертає поверхневу копію того самого типу. Для ітераторів використовуйте `itertools.islice()`, а для перегляду двійкових даних без копіювання — `memoryview`.

### Вправа 1


- `s[1:4]` бере індекси 1, 2 і 3.
- `s[-3:]` — останні три символи, а `s[:-3]` — усе перед ними.
- `s[::2]` бере індекси 0, 2 і 4: `P`, `t`, `o`.
- `s[::-2]` починає з останнього індексу (5) і бере 5, 3, 1: `n`, `h`, `y`.
- `s[4:1:-1]` іде від 4 униз до 2: `o`, `h`, `t`.
- `-10` лежить перед початком, тому обрізається, і зріз іде від 4 униз до 0 включно.
- `s[10:20]` повністю поза межами, тож це порожній рядок, а не помилка.

### Вправа 2

```python
from itertools import batched


def chunks(seq, size):
    if size < 1:
        raise ValueError("size must be at least 1")
    return [seq[i:i + size] for i in range(0, len(seq), size)]


print(chunks([1, 2, 3, 4, 5, 6, 7], 3))
print(chunks("abcdefgh", 3))
print(chunks(range(10), 4))
print(chunks([], 3))
print(list(batched("abcdefgh", 3)))
```

Результат:

```text
[[1, 2, 3], [4, 5, 6], [7]]
['abc', 'def', 'gh']
[range(0, 4), range(4, 8), range(8, 10)]
[]
[('a', 'b', 'c'), ('d', 'e', 'f'), ('g', 'h')]
```

`range(0, len(seq), size)` видає початок кожної частини. Останній зріз `seq[6:9]` виходить за кінець і обрізається, тож для короткої останньої частини не потрібен окремий випадок. Оскільки зріз зберігає тип, рядки лишаються рядками, а діапазони — діапазонами. `itertools.batched()` працює з будь-яким ітерованим об'єктом, але завжди повертає кортежі.

### Вправа 3

```python
report = """\
ID   NAME        QTY  PRICE
001  Notebook      3   2.35
002  Pen          10   0.99
003  Backpack      1  24.90"""

ID = slice(0, 3)

QTY = slice(17, 21)
PRICE = slice(21, None)

rows = []
for line in report.splitlines()[1:]:
    rows.append({

        "name": line[NAME].strip(),
        "qty": int(line[QTY]),
```

### Вправа 4

```python
def reverse_middle(items):
    items[1:-1] = items[-2:0:-1]


def drop_every(items, k):
    del items[k - 1::k]


def insert_after(items, index, new_items):
    items[index + 1:index + 1] = new_items


data = [1, 2, 3, 4, 5, 6, 7, 8]
original_id = id(data)

reverse_middle(data)
print(data)

drop_every(data, 3)
print(data)

insert_after(data, 0, ["a", "b"])
print(data)

print(id(data) == original_id)
```

Результат:

```text
[1, 7, 6, 5, 4, 3, 2, 8]
[1, 7, 5, 4, 2, 8]
[1, 'a', 'b', 7, 5, 4, 2, 8]
True
```

- `items[-2:0:-1]` іде назад від передостаннього елемента до індексу 1 (кінець `0` не включається), а присвоєння цього зрізу `items[1:-1]` записує перевернуту середину на місце.
- `items[k - 1::k]` вибирає позиції `k - 1, 2k - 1, ...`, тобто `k`-й, `2k`-й, ... елементи, якщо рахувати з одиниці.
- `items[index + 1:index + 1]` — порожній зріз, тож присвоєння йому вставляє елементи, нічого не видаляючи.

Усі три операції змінюють сам список, тому `id(data)` не змінюється.
