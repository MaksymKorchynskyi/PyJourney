# Квантифікатори

**Квантифікатор** (quantifier) визначає, скільки разів може повторюватися елемент перед ним: «одна або більше цифр», «необов'язкова `u`», «рівно чотири цифри». Без квантифікаторів для року довелося б писати `\d\d\d\d`, а «число будь-якої довжини» не вдалося б описати взагалі. З ними короткі шаблони описують числа, слова, дати й номери телефонів змінної довжини.

## Що ви дізнаєтесь

- Квантифікатори `*`, `+`, `?`, `{n}`, `{n,}`, `{,m}` і `{n,m}`
- До якої частини шаблону застосовується квантифікатор і як повторити послідовність
- Чому `*` може давати порожні збіги
- Як поєднувати квантифікатори з якорями та межами слова для точних збігів
- Правила й помилки, пов'язані з фігурними дужками
- Що квантифікатори типово жадібні

## Квантифікатори одним поглядом

| Квантифікатор | Попередній елемент повторюється | Те саме, що |
|---|---|---|
| `*` | нуль або більше разів | `{0,}` |
| `+` | один або більше разів | `{1,}` |
| `?` | нуль разів або один раз (необов'язковий) | `{0,1}` |
| `{n}` | рівно `n` разів | |
| `{n,}` | щонайменше `n` разів | |
| `{,m}` | від нуля до `m` разів | `{0,m}` |
| `{n,m}` | від `n` до `m` разів (включно) | |

## До чого застосовується квантифікатор

Квантифікатор повторює лише **один елемент безпосередньо перед ним**. Цим елементом може бути:

- один буквальний символ: `a+`;
- послідовність на зразок `\d+` чи `\w*`;
- крапка: `.+`;
- набір у квадратних дужках: `[aeiou]+` (див. тему «Набори та діапазони»);
- група в круглих дужках: `(?:ha)+` (див. розділ «Групування»).

Отже, `ha+` означає «`h`, а потім одна або більше `a`», а не «одне або більше `ha`». Щоб повторити послідовність символів, обгорніть її групою:

```python
import re

text = "haaa hahaha"

print(re.findall(r"ha+", text))
print(re.findall(r"(?:ha)+", text))
```

Результат:

```text
['haaa', 'ha', 'ha', 'ha']
['ha', 'hahaha']
```

`(?:...)` — це **незахоплювальна група** (non-capturing group). Вона лише групує. Звичайна `(...)` захоплювала б текст, і тоді `findall()` повертав би захоплену частину замість усього збігу. Різницю пояснено в розділі «Групування».

## `*`: нуль або більше разів

`*` дозволяє попередньому елементу з'являтися будь-яку кількість разів, зокрема жодного. `\w*Python` означає «нуль або більше символів слова, а за ними `Python`»:

```python
import re

s = """CPython, IronPython, and JPython
       are major Python's implementation"""

for match in re.finditer(r"\w*Python", s):
    print(match)
```

Результат:

```text
<re.Match object; span=(0, 7), match='CPython'>
<re.Match object; span=(9, 19), match='IronPython'>
<re.Match object; span=(25, 32), match='JPython'>
<re.Match object; span=(50, 56), match='Python'>
```

У перших трьох словах `\w*` забирає `C`, `Iron` і `J`, а перед окремим `Python` — нічого. Нуль повторень — цілком коректний збіг.

Правило «нуль теж годиться» має побічний ефект. Шаблон, що складається лише з `x*`, збігається **всюди**, навіть там, де збігатися нічому, і дає порожні рядки:

```python
import re

print(re.findall(r"\d*", "a12b"))
print(re.findall(r"\d+", "a12b"))
```

Результат:

```text
['', '12', '', '']
['12']
```

На `a` рушій знаходить «нуль цифр», тобто порожній збіг. Потім знаходить `12`, далі нуль цифр на `b` і, нарешті, нуль цифр у кінці рядка. Якщо потрібен хоча б один символ, використовуйте `+`.

## `+`: один або більше разів

`+` вимагає принаймні одного входження. `\d+` відповідає цілому числу будь-якої довжини:

```python
import re

s = "Python 3.10 was released in 2021"

for match in re.finditer(r"\d+", s):
    print(match)
```

Результат:

```text
<re.Match object; span=(7, 8), match='3'>
<re.Match object; span=(9, 11), match='10'>
<re.Match object; span=(28, 32), match='2021'>
```

`findall()` повертає рядки. Якщо потрібні числа, перетворіть їх:

```python
>>> import re
>>> [int(n) for n in re.findall(r"\d+", "Python 3.10 was released in 2021")]
[3, 10, 2021]
```

## `?`: необов'язковий елемент

`?` робить попередній елемент необов'язковим: він може з'явитися один раз або не з'явитися зовсім. Класичний приклад — британський і американський правопис:

```python
import re

s = "What color / colour do you like?"

for match in re.finditer(r"colou?r", s):
    print(match)
```

Результат:

```text
<re.Match object; span=(5, 10), match='color'>
<re.Match object; span=(13, 19), match='colour'>
```

`u?` відповідає нулю або одній `u`, тому підходять обидва варіанти. Так само `https?` відповідає і `http`, і `https`.

> **Зверніть увагу:** знак питання має й інші ролі. Одразу після іншого квантифікатора він робить його лінивим (`+?`, `*?`, див. тему «Нежадібні квантифікатори»), а одразу після відкривної дужки починає спеціальну групу, наприклад `(?:...)`.

## `{n}`: рівно `n` разів

`{n}` повторює попередній елемент рівно `n` разів. Ось час у форматі `hh:mm`:

```python
import re

s = "It was 11:05 AM"

for match in re.finditer(r"\d{2}:\d{2}", s):
    print(match)
```

Результат:

```text
<re.Match object; span=(7, 12), match='11:05'>
```

«Рівно дві» стосується лише цієї частини збігу й не забороняє інших цифр поруч. Без меж слова `\d{2}:\d{2}` охоче знаходить `11:05` усередині `111:055`:

```python
import re

text = "It was 111:055 and 11:05"

print(re.findall(r"\d{2}:\d{2}", text))
print(re.findall(r"\b\d{2}:\d{2}\b", text))
```

Результат:

```text
['11:05', '11:05']
['11:05']
```

Перше `11:05` узято зсередини `111:055`. Межі слова (або якорі) роблять «рівно» справді точним.

## `{n,}`: щонайменше `n` разів

`{n,}` задає лише нижню межу. Шаблон нижче знаходить дати у форматі `d-m-yyyy` або `dd-mm-yyyy`, де день і місяць мають одну чи більше цифр:

```python
import re

s = "5-5-2021 or 05-05-2021 or 5/5/2021"

for match in re.finditer(r"\d{1,}-\d{1,}-\d{4}", s):
    print(match)
```

Результат:

```text
<re.Match object; span=(0, 8), match='5-5-2021'>
<re.Match object; span=(12, 22), match='05-05-2021'>
```

`5/5/2021` записано через скісні риски, тому він не підходить. Зауважте, що `\d{1,}` — це просто довший запис `\d+`.

## `{n,m}`: від `n` до `m` разів

`{n,m}` задає обидві межі, включно. День чи місяць має одну або дві цифри, тож `\d{1,2}` описує їх точніше, ніж `\d{1,}`:

```python
import re

s = "5-5-2021 or 05-05-2021 or 5/5/2021"

for match in re.finditer(r"\d{1,2}-\d{1,2}-\d{4}", s):
    print(match)
```

Результат:

```text
<re.Match object; span=(0, 8), match='5-5-2021'>
<re.Match object; span=(12, 22), match='05-05-2021'>
```

Два застереження щодо цього шаблону:

- Без меж слова він знаходить частини довших рядків: у `"123-45-20210"` він знайде `23-45-2021`. Використовуйте `\b...\b` або `fullmatch()`.
- Квантифікатори рахують символи, а не перевіряють значення. `45-99-2021` відповідає шаблону, хоча 99-го місяця не існує. Перевіряйте значення в Python через `int()` або використовуйте набори й альтернативу для суворих діапазонів.

Нижню межу можна пропустити: `{,m}` означає «від нуля до `m` разів». Як і `*`, він допускає порожні збіги:

```python
>>> import re
>>> re.findall(r"\d{,2}", "12345")
['12', '34', '5', '']
```

## Правила для фігурних дужок

- **Жодних пробілів усередині дужок.** `\d{1, 3}` — не квантифікатор. Python сприймає дужки як буквальний текст і шукає символи `{1, 3}`:

  ```python
  import re

  print(re.findall(r"\d{1, 3}", "1{1, 3} 123"))
  ```

  Результат:

  ```text
  ['1{1, 3}']
  ```

- **Дужки, що не утворюють коректного квантифікатора, — звичайний текст.** `re.findall(r"x{a}", "x{a}")` повертає `['x{a}']`.
- **`n` не може бути більшим за `m`.** Інакше компіляція завершиться помилкою.
- **Квантифікаторові потрібно щось повторювати.** Квантифікатор на самому початку шаблону або два квантифікатори поспіль — це помилка:

```python
import re

for pattern in [r"*abc", r"a**", r"a{3,1}"]:
    try:
        re.compile(pattern)
    except re.error as e:
        print(f"{pattern!r}: {type(e).__name__}: {e}")
```

Результат:

```text
'*abc': PatternError: nothing to repeat at position 0
'a**': PatternError: multiple repeat at position 2
'a{3,1}': PatternError: min repeat greater than max repeat at position 2
```

Починаючи з Python 3.13, клас винятку називається `re.PatternError`. Стара назва `re.error` лишилася як синонім, тож `except re.error` працює в усіх версіях.

Деякі поєднання двох символів дозволені, бо означають інше: `a*?` — це лінивий квантифікатор, а `a*+` — присвійний (possessive) квантифікатор (Python 3.11+, див. тему «Жадібні квантифікатори»).

## Квантифікатори разом з якорями та межами слова

Квантифікатори описують, **скільки**, а якорі й межі слова — **де**. Разом вони дають точні шаблони. Ось український мобільний номер у форматі `+380 67 123 45 67`:

```python
>>> import re
>>> re.fullmatch(r"\+380 \d{2} \d{3} \d{2} \d{2}", "+380 67 123 45 67")
<re.Match object; span=(0, 17), match='+380 67 123 45 67'>
```

Плюс екрановано як `\+`, бо голий `+` — це квантифікатор. Шаблон, що починається з `+`, навіть не скомпілюється.

Межі слова не дають обмеженню довжини порізати довгі слова на шматки:

```python
import re

print(re.findall(r"\w{3,5}", "programming"))
print(re.findall(r"\b\w{3,5}\b", "I am in the garden with my cat and a puppy"))
print(re.findall(r"\b\w{3,5}\b", "Я в саду з котом і цуценям, разом гуляємо"))
```

Результат:

```text
['progr', 'ammin']
['the', 'with', 'cat', 'and', 'puppy']
['саду', 'котом', 'разом']
```

Без меж слово `programming` розрізається на шматки по п'ять літер. З межами лишаються тільки цілі слова з трьох–п'яти літер. Оскільки `\w` враховує Unicode, той самий шаблон працює й для українського речення: кирилиця для `\w` і `\b` — такі самі літери, як латиниця.

## Квантифікатори жадібні

Типово кожен квантифікатор бере **якомога більше** повторень, поки решта шаблону ще може збігтися. Тому `\d+` на `"2021"` повертає `2021`, а не `2`. Зазвичай саме це й потрібно, але іноді квантифікатор захоплює забагато. Наступні дві теми, «Жадібні квантифікатори» та «Нежадібні квантифікатори», пояснюють, як це працює і як це змінити.

## Типові помилки

- **Забувати, що квантифікатор повторює лише один елемент.** `ha+` не повторює `ha`. Використовуйте `(?:ha)+`.
- **`*` там, де потрібен хоча б один символ.** `\d*` дає порожні збіги. Використовуйте `\d+`.
- **Пробіли всередині фігурних дужок.** `{1, 3}` — звичайний текст, а не квантифікатор.
- **Забуті межі слова чи якорі.** `\d{4}` знаходить `1234` усередині `ID 123456`. Використовуйте `\b\d{4}\b` або `fullmatch()`.
- **Неекрановані `+`, `*` чи `?`, коли потрібен сам символ.** `r"+380"` викликає `PatternError: nothing to repeat`. Пишіть `r"\+380"`.
- **Очікувати, що квантифікатори перевіряють значення.** `\d{1,2}` приймає `99` як місяць.

## Підсумок

- Квантифікатор повторює один елемент безпосередньо перед ним: символ, клас, набір або групу.
- `*` означає нуль або більше, `+` — один або більше, `?` — нуль або один.
- `{n}` — рівно `n`, `{n,}` — щонайменше `n`, `{,m}` — щонайбільше `m`, `{n,m}` — від `n` до `m`.
- `*`, `?` і `{,m}` допускають нуль повторень, тому шаблони лише з них можуть давати порожні збіги.
- Жодних пробілів у фігурних дужках. Некоректні дужки сприймаються як звичайний текст.
- Поєднуйте квантифікатори з `\b`, якорями чи `fullmatch()`, щоб «рівно `n`» справді означало рівно `n`.
- Квантифікатори типово жадібні.

## Практика

### Вправа 1: Сума чисел

Витягніть усі цілі числа з `"Order 66 shipped 3 items for 1250 UAH"` і виведіть їхній список і суму.

### Вправа 2: Вебпосилання

Знайдіть усі посилання, що починаються з `http://` або `https://`, у рядку `"See http://a.com and https://b.org/x or ftp://c.net"`. Посилання триває до наступного пробільного символу. Посилання `ftp` не повинне потрапити в результат.

### Вправа 3: Перевірка номера телефону

Напишіть `is_ua_phone(text)`, яка приймає лише номери у форматі `+380 67 123 45 67` (плюс, `380`, а далі групи з 2, 3, 2 і 2 цифр через один пробіл). Перевірте її на `"+380 67 123 45 67"`, `"+380 67 1234 5 67"`, `"380 67 123 45 67"` і `"+380 67 123 45 678"`.

### Вправа 4: Короткі слова

Знайдіть усі слова з трьох–п'яти літер у `"I am in the garden with my cat and a puppy"` та в `"Я в саду з котом і цуценям, разом гуляємо"`. Потім поясніть, що піде не так, якщо прибрати межі слова.

## Розв'язки

### Вправа 1

```python
import re

text = "Order 66 shipped 3 items for 1250 UAH"

numbers = re.findall(r"\d+", text)
print(numbers)
print(sum(int(n) for n in numbers))
```

Результат:

```text
['66', '3', '1250']
1319
```

### Вправа 2

```python
import re

text = "See http://a.com and https://b.org/x or ftp://c.net"

print(re.findall(r"https?://\S+", text))
```

Результат:

```text
['http://a.com', 'https://b.org/x']
```

`s?` робить `s` необов'язковою, а `\S+` бере один або більше непробільних символів. Майте на увазі: `\S+` захопив би й розділовий знак після посилання, наприклад кому. Для справжніх URL потрібен суворіший шаблон.

### Вправа 3

```python
import re


def is_ua_phone(text):
    return re.fullmatch(r"\+380 \d{2} \d{3} \d{2} \d{2}", text) is not None


for candidate in ["+380 67 123 45 67", "+380 67 1234 5 67", "380 67 123 45 67", "+380 67 123 45 678"]:
    print(f"{candidate!r:22} {is_ua_phone(candidate)}")
```

Результат:

```text
'+380 67 123 45 67'    True
'+380 67 1234 5 67'    False
'380 67 123 45 67'     False
'+380 67 123 45 678'   False
```

### Вправа 4

```python
import re

english = "I am in the garden with my cat and a puppy"
ukrainian = "Я в саду з котом і цуценям, разом гуляємо"

print(re.findall(r"\b\w{3,5}\b", english))
print(re.findall(r"\b\w{3,5}\b", ukrainian))
print(re.findall(r"\w{3,5}", ukrainian))
```

Результат:

```text
['the', 'with', 'cat', 'and', 'puppy']
['саду', 'котом', 'разом']
['саду', 'котом', 'цуцен', 'разом', 'гуляє']
```

Без меж слова рушій бере перші п'ять літер довших слів `цуценям` і `гуляємо` й повертає ці шматки. Решта, `ям` і `мо`, закороткі, щоб збігтися самостійно.
