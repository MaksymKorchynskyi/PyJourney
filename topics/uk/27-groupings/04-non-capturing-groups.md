# Групи без захоплення

Дужки в регулярному виразі водночас **групують** і **захоплюють**. Часто потрібне лише групування, наприклад щоб застосувати квантифікатор до кількох символів або обмежити альтернацію, а захоплення тільки заважає. **Група без захоплення** (non-capturing group) `(?:...)` групує, нічого не захоплюючи. Завдяки цьому номери груп лишаються впорядкованими, а функції на кшталт `findall()` і `split()` не повертають того, про що ви не просили.

## Що ви дізнаєтесь

- Синтаксис групи без захоплення `(?:X)` і чим вона відрізняється від `(X)`
- Справжні причини її використовувати: квантифікатори, альтернація, `findall()`, `split()` і стабільні номери груп
- Як поєднувати в одному шаблоні групи захоплення, іменовані групи та групи без захоплення
- Як застосувати прапорці лише до частини шаблону за допомогою `(?i:...)`
- Сімейство конструкцій `(?...)` і де про кожну з них ідеться

## Два види груп

У регулярних виразах є два види груп:

- **групи захоплення** `(X)`: групують `X` і запам'ятовують знайдений текст, щоб його можна було прочитати через `group()` або повторно використати у зворотному посиланні;
- **групи без захоплення** `(?:X)`: групують `X`, але нічого не запам'ятовують.

Саме `?:` одразу після відкривної дужки вимикає захоплення. Для рушія обидві групи збігаються з тим самим текстом. Уся різниця в тому, чи з'являється в об'єкті `Match` пронумерована комірка для групи.

## Перший приклад

Цей шаблон захоплює старшу та молодшу частини версії Python:

```python
import re

s = "Python 3.10"
match = re.search(r"(\d+)\.(\d+)", s)

# показати весь збіг
print(match.group())

# показати групи
for group in match.groups():
    print(group)
```

Результат:

```text
3.10
3
10
```

У шаблоні дві групи захоплення: одна перед буквальною крапкою (екранованою як `\.`), друга — після неї. Якщо старша версія не потрібна, зробіть першу групу групою без захоплення:

```python
import re

s = "Python 3.10"
match = re.search(r"(?:\d+)\.(\d+)", s)

print(match.group())
print(match.groups())
```

Результат:

```text
3.10
('10',)
```

Увесь збіг не змінився, але тепер група лише одна, і молодша версія — це група 1.

Саме в цьому випадку дужки взагалі не потрібні, бо `\d+` і так є єдиним цілим. `r"\d+\.(\d+)"` поводиться точнісінько так само:

```python
import re

match = re.search(r"\d+\.(\d+)", "Python 3.10")
print(match.group(), match.groups())
```

Результат:

```text
3.10 ('10',)
```

Тож *коли* група без захоплення справді потрібна? Щоразу, коли дужки потрібні для **структури**, а не для **видобування** даних.

## Навіщо потрібні групи без захоплення

### 1. Щоб застосувати квантифікатор до кількох символів

Квантифікатор діє лише на один елемент безпосередньо перед ним. `ab+` означає «`a`, а потім одна або кілька `b`». Щоб повторити послідовність `ab`, її треба згрупувати:

```python
import re

print(re.fullmatch(r"ab+", "ababab"))
print(re.fullmatch(r"(?:ab)+", "ababab"))
```

Результат:

```text
None
<re.Match object; span=(0, 6), match='ababab'>
```

### 2. Щоб обмежити альтернацію

`|` розділяє весь шаблон, якщо не стоїть усередині групи (див. тему про альтернацію). Група без захоплення обмежує альтернативи й не додає нової групи:

```python
import re

css = "width: 100px; margin: 2em; height: 50%; z: 3"

print(re.findall(r"\d+(px|em|%)", css))
print(re.findall(r"\d+(?:px|em|%)", css))
```

Результат:

```text
['px', 'em', '%']
['100px', '2em', '50%']
```

### 3. Щоб `findall()` повертав повні збіги

Як видно з другого прикладу, `re.findall()` повертає захоплені групи, щойно вони є в шаблоні. Група, додана лише для структури, непомітно змінює результат. Класичний приклад — адреса IPv4:

```python
import re

log = "from 192.168.1.10 to 10.0.0.255"

print(re.findall(r"(\d{1,3}\.){3}\d{1,3}", log))
print(re.findall(r"(?:\d{1,3}\.){3}\d{1,3}", log))
```

Результат:

```text
['1.', '0.']
['192.168.1.10', '10.0.0.255']
```

З групою захоплення `findall()` повертає лише останнє повторення групи (`'1.'` і `'0.'`). З `(?:...)` — повні адреси.

### 4. Щоб роздільники не потрапляли в результат `re.split()`

Якщо шаблон роздільника в `re.split()` містить групи захоплення, захоплені роздільники вставляються в список-результат:

```python
import re

print(re.split(r"(,|;)", "a,b;c"))
print(re.split(r"(?:,|;)", "a,b;c"))
```

Результат:

```text
['a', ',', 'b', ';', 'c']
['a', 'b', 'c']
```

Іноді зберегти роздільники — саме те, що треба. Коли ж ні, використовуйте `(?:...)` (або клас символів `[,;]` для окремих символів).

### 5. Щоб номери груп лишалися змістовними

Кожна група захоплення отримує номер, тож структурні групи відсувають цікаві групи далі. Якщо для даних використовувати іменовані групи, а для структури — групи без захоплення, шаблон лишається читабельним:

```python
import re

pattern = r"(?:(?P<scheme>https?)://)?(?P<host>[\w.-]+)"

for url in ["https://example.com/path", "example.com/path"]:
    match = re.search(pattern, url)
    print(match.groups(), match.groupdict())
```

Результат:

```text
('https', 'example.com') {'scheme': 'https', 'host': 'example.com'}
(None, 'example.com') {'scheme': None, 'host': 'example.com'}
```

Необов'язкова частина `scheme://` потребує групи для `?`, але даними є лише сама схема. У шаблоні рівно дві групи, і обидві іменовані.

### А як щодо швидкості й пам'яті?

Група без захоплення звільняє рушій від потреби записувати, де група почалася й закінчилася, тому вона може бути трохи швидшою. На практиці різниця невелика (кілька відсотків на типових шаблонах) і рідко буває вагомою причиною сама по собі. Обирайте `(?:...)` насамперед тому, що цей запис прямо каже, що ви маєте на увазі: «згрупувати, але не захоплювати».

## Прапорці для частини шаблону: `(?i:...)`

Синтаксис `?:` може містити вбудовані прапорці (inline flags), що діють лише всередині групи. `(?i:...)` робить нечутливою до регістру тільки цю частину:

```python
import re

text = "HELLO world HELLO WORLD hello world"
print(re.findall(r"(?i:hello) world", text))
```

Результат:

```text
['HELLO world', 'hello world']
```

`hello` може бути в будь-якому регістрі, а `world` — лише в нижньому. Найкорисніші тут літери — `i` (ігнорувати регістр), `m` (багаторядковий режим), `s` (крапка збігається з символом нового рядка) і `x` (докладний режим, verbose), а знак мінус вимикає прапорець усередині групи: у `(?i)HELLO (?-i:world)` усе нечутливе до регістру, крім `world`.

## Сімейство `(?...)`

`(?:...)` — один із членів сімейства конструкцій, що починаються з `(?`. Пронумеровану групу створює лише іменована група:

| Запис | Значення | Захоплює? |
|---|---|---|
| `(?:...)` | група без захоплення | ні |
| `(?P<name>...)` | іменована група захоплення | так |
| `(?P=name)` | зворотне посилання на іменовану групу | ні |
| `(?i:...)` | група з вбудованими прапорцями | ні |
| `(?=...)`, `(?!...)` | перегляд уперед, негативний перегляд уперед | ні |
| `(?<=...)`, `(?<!...)` | перегляд назад, негативний перегляд назад | ні |
| `(?>...)` | атомарна група (Python 3.11+) | ні |
| `(?#...)` | коментар, ігнорується | ні |

Перегляду вперед і назад присвячено наступні теми.

## Типові помилки

- **Використовувати групи захоплення «просто для групування», а потім викликати `findall()` чи `split()`.** Ви отримаєте групи або роздільники замість очікуваного результату. Використовуйте `(?:...)`.
- **Очікувати, що групу без захоплення можна прочитати.** `(?:\d+)` не має номера. `re.search(r"(?:\d+)", "42").group(1)` згенерує `IndexError: no such group`.
- **Писати `(:?...)` замість `(?:...)`.** `(:?\d+)` — це група *захоплення*, що починається з необов'язкової двокрапки. Знак `?` має стояти першим.
- **Додавати дужки там, де вони не потрібні.** `(?:\d+)\.(\d+)` і `\d+\.(\d+)` — те саме. Групуйте лише тоді, коли цього потребує квантифікатор, альтернація чи прапорець.
- **Обирати `(?:...)` лише заради швидкості.** Виграш невеликий. Справжні переваги — зрозумілість і правильні результати `findall()` та `split()`.

## Підсумок

- `(X)` групує і захоплює, `(?:X)` лише групує. Обидві збігаються з тим самим текстом.
- Групи без захоплення не отримують номера й не з'являються в результатах `groups()`, `groupdict()`, `findall()` чи `split()`.
- Використовуйте їх, щоб застосувати квантифікатор до послідовності (`(?:ab)+`) і щоб обмежити альтернацію (`\d+(?:px|em)`).
- Використовуйте `(?:...)` для структури, а (іменовані) групи захоплення — для даних. Так номери груп лишаються змістовними.
- `(?i:...)` та подібні форми застосовують прапорці лише до частини шаблону.
- Виграш у швидкості невеликий. Головна перевага — зрозумілість.

## Розв'язки

### Вправа 1

```python
import re

log = "Blocked 203.0.113.5, allowed 198.51.100.23 and 192.0.2.1"
print(re.findall(r"(?:\d{1,3}\.){3}\d{1,3}", log))
```

Результат:

```text
['203.0.113.5', '198.51.100.23', '192.0.2.1']
```

Початковий код виводив `['113.', '100.', '2.']` — останнє повторення групи захоплення для кожної адреси.

### Вправа 2

```python
import re

text = "Haha, that was funny. hahaha! ha"

print(re.findall(r"(?:ha)+", text, flags=re.IGNORECASE))
print(re.findall(r"\b(?:ha)+\b", text, flags=re.IGNORECASE))
```

Результат:

```text
['Haha', 'ha', 'hahaha', 'ha']
['Haha', 'hahaha', 'ha']
```

Без меж слова знаходиться ще й `ha` усередині `that`. З групою захоплення `(ha)+` функція `findall()` повернула б `['ha', 'ha', 'ha']` — останній склад кожного сміху.

### Вправа 3

```python
import re


def parse_version(text):
    match = re.search(r"(\d+)\.(\d+)(?:\.(\d+))?", text)
    if match is None:
        return None
    return tuple(int(part) for part in match.groups(default="0"))


print(parse_version("Python 3.12.1"))
print(parse_version("Python 3.10"))
print(parse_version("no version here"))
```

Результат:

```text
(3, 12, 1)
(3, 10, 0)
None
```

Необов'язковій частині `.patch` потрібна група для `?`, але крапка — не дані, тому зовнішня група без захоплення, а захоплюється лише число всередині неї. `groups(default="0")` підставляє відсутній patch.

### Вправа 4

```python
import re

items = re.split(r"\s*(?:,|;|\band\b)\s*", "apples, pears; plums and cherries")
print(items)
```

Результат:

```text
['apples', 'pears', 'plums', 'cherries']
```

З групою захоплення `(,|;|\band\b)` роздільники `','`, `';'` і `'and'` з'явилися б у списку між елементами.
