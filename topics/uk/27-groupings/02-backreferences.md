# Зворотні посилання

**Зворотне посилання** (backreference) дає змогу шаблону послатися на текст, який раніше вже знайшла група захоплення. Воно відповідає на запитання, яких звичайний шаблон виразити не може: «чи повторюється це слово?» або «чи закривна лапка така сама, як відкривна?». Та сама ідея працює й у рядках заміни: за допомогою `re.sub()` захоплені фрагменти можна переставляти місцями.

## Що ви дізнаєтесь

- Як `\1`, `\2`, ... повторно використовують захоплену групу всередині шаблону
- Як записати іменоване зворотне посилання через `(?P=name)`
- Як використовувати групи в рядках заміни: `\1`, `\g<1>`, `\g<name>` і `\g<0>`
- Навіщо потрібен запис `\g<N>` і чому він працює лише в рядках заміни
- Типові застосування: повторені слова, парні лапки, подвоєні літери, перестановка частин тексту
- Підводні камені: сирі рядки, відсутні межі слова, групи, що не збіглися

## Як працює зворотне посилання

Усередині шаблону `\N` (де `N` — номер групи від 1 до 99) збігається **рівно з тим самим текстом**, який група `N` захопила раніше в поточному збігу. Повторюється захоплений *текст*, а не підшаблон.

```python
import re

text = "11 12 77 90"

print(re.findall(r"\d\d", text))
print([m.group() for m in re.finditer(r"(\d)\1", text)])
```

Результат:

```text
['11', '12', '77', '90']
['11', '77']
```

`\d\d` приймає будь-які дві цифри. У `(\d)\1` перша цифра захоплюється, а `\1` вимагає, щоб наступний символ був **тією самою** цифрою, тому `12` і `90` відкидаються.

Кілька правил:

- Група має бути визначена **до** зворотного посилання і вже закрита. `\1(a)` згенерує `re.PatternError: invalid group reference 1`, а `(a\1)` — `cannot refer to an open group`.
- `\0` і тризначні послідовності на кшталт `\101` — це вісімкові коди символів, а не зворотні посилання. Для всього збігу використовуйте `group(0)` або `\g<0>` (у рядках заміни).
- Зворотне посилання на групу, яка не брала участі у збігу, у Python **не збігається** ні з чим. Наприклад, `(a)?b\1` не знаходить збігу в `"b"`.

## Видалення повтореного слова

Візьмімо речення з випадковим повтором:

```text
Python Python is awesome
```

Побудуймо шаблон крок за кроком:

1. `\w+\s+` знаходить слово і пробільні символи після нього.
2. `(\w+)\s+` захоплює лише слово.
3. `(\w+)\s+\1` вимагає, щоб після пробілів ішло те саме слово.

Тепер замінімо кожен збіг лише першою групою. У рядку заміни `\1` означає «текст групи 1»:

```python
import re

pattern = r"(\w+)\s+\1"

print(re.sub(pattern, r"\1", "Python Python is awesome"))
print(re.sub(pattern, r"\1", "This is it"))
```

Результат:

```text
Python is awesome
This it
```

Перший результат правильний, а друге речення зіпсоване: `is` зникло, хоча нічого не повторювалося. Рушій захопив `is` у кінці слова `This`, а після пробілу знову знайшов `is`. Зворотне посилання порівнює символи, а не слова. Виправляють це межі слова:

```python
import re

pattern = r"\b(\w+)\s+\1\b"

print(re.sub(pattern, r"\1", "Python Python is awesome"))
print(re.sub(pattern, r"\1", "This is it"))
print(re.sub(pattern, r"\1", "The the cat sat sat down", flags=re.IGNORECASE))
```

Результат:

```text
Python is awesome
This is it
The cat sat down
```

Початкове `\b` не дає групі почати збіг усередині слова, а кінцеве `\b` не дає `\1` збігтися лише з початком довшого слова (як у `the theory`). З прапорцем `re.IGNORECASE` зворотне посилання теж ігнорує регістр, тому `The the` вважається повтором.

## Іменовані зворотні посилання: `(?P=name)`

Якщо група має ім'я, на неї можна послатися за іменем: `(?P=name)`. Так шаблон читається краще, ніж із номером, і не ламається, коли в нього додають нові групи:

```python
import re

pattern = r"\b(?P<word>\w+)\s+(?P=word)\b"
match = re.search(pattern, "I think think so")

print(match.group())
print(match.group("word"))
```

Результат:

```text
think think
think
```

## Зворотні посилання в рядках заміни

У рядок заміни, який передають у `re.sub()`, можна вставити текст будь-якої групи:

| Запис | Значення |
|---|---|
| `\1` ... `\99` | текст групи 1 ... 99 |
| `\g<1>` | текст групи 1, записаний однозначно |
| `\g<name>` | текст іменованої групи `name` |
| `\g<0>` | увесь збіг |

```python
import re

text = "Deadline: 2024-10-07, review: 2024-11-15"

print(re.sub(r"(\d{4})-(\d{2})-(\d{2})", r"\3.\2.\1", text))
print(re.sub(r"(?P<y>\d{4})-(?P<m>\d{2})-(?P<d>\d{2})", r"\g<d>.\g<m>.\g<y>", text))
print(re.sub(r"\d+", r"[\g<0>]", "5 apples and 12 pears"))
```

Результат:

```text
Deadline: 07.10.2024, review: 15.11.2024
Deadline: 07.10.2024, review: 15.11.2024
[5] apples and [12] pears
```

> **Зверніть увагу:** форми `\g<...>` працюють **лише в рядках заміни**. Усередині шаблону `\g<1>` згенерує `re.PatternError: bad escape \g`. У шаблоні пишіть `\1` або `(?P=name)`.

### Навіщо потрібен `\g<1>`

Припустімо, до кожного числа треба дописати `0`. `\10` схоже на «група 1, а потім `0`», але Python читає це як «група 10»:

```python
import re

try:
    re.sub(r"(\d+)", r"\10", "price 5")
except re.PatternError as error:
    print("error:", error)

print(re.sub(r"(\d+)", r"\g<1>0", "price 5"))
```

Результат:

```text
error: invalid group reference 10 at position 1
price 50
```

`\g<1>0` усуває неоднозначність: номер групи закінчується на `>`.

### Групи, що не збіглися

У рядку заміни група, яка не брала участі у збігу, замінюється порожнім рядком (починаючи з Python 3.5; старіші версії генерували помилку):

```python
import re

print(re.sub(r"(\d+)(px)?", r"\1:\2;", "10px 7"))
```

Результат:

```text
10:px; 7:;
```

Коли для заміни потрібна справжня логіка (арифметика, пошук у словнику, умови), передайте замість рядка функцію. Вона отримує кожен об'єкт `Match` і повертає текст заміни:

```python
import re

print(re.sub(r"\d+", lambda m: str(int(m.group()) * 2), "3 apples, 10 pears"))
```

Результат:

```text
6 apples, 20 pears
```

## Більше прикладів

### Текст у парних лапках

Завдання — витягти текст, узятий або в подвійні, або в одинарні лапки, але не текст, що відкривається лапкою одного виду, а закривається іншою. Перша спроба використовує клас символів з обох боків:

```python
import re

s = '"Python\'s awesome". She said'
pattern = r'[\'"].*?[\'"]'

match = re.search(pattern, s)
print(match.group())
```

Результат:

```text
"Python'
```

Збіг починається з `"` і зупиняється на апострофі в `Python's`, бо закривний клас приймає *будь-яку* лапку. Зворотне посилання змушує закривну лапку бути тим самим символом, що й відкривна:

```python
import re

s = '"Python\'s awesome". She said'
pattern = r'([\'"])(.*?)\1'

match = re.search(pattern, s)
print(match.group())
print(match.group(2))
```

Результат:

```text
"Python's awesome"
Python's awesome
```

Група 1 захоплює відкривну лапку, `(.*?)` ліниво захоплює вміст, а `\1` приймає лише ту лапку, яку захопила група 1. Проте регулярний вираз однаково не здатен відрізнити апостроф від закривної одинарної лапки, тож у `'it's ok'` збіг закінчиться на `'it'`. Для справжніх форматів із лапками (CSV, JSON, вихідний код) використовуйте відповідний парсер.

### Слова з подвоєною літерою

`(\w)\1` знаходить два однакові символи поспіль. Щоб знайти цілі слова з такою парою, оточіть її `\w*` і межами слова:

```python
import re

words = ["apple", "orange", "strawberry", "kiwi", "coffee"]
pattern = r"\b\w*(\w)\1\w*\b"

print([w for w in words if re.search(pattern, w)])
```

Результат:

```text
['apple', 'strawberry', 'coffee']
```

Коли кожен елемент уже є окремим словом, досить `re.search(r"(\w)\1", w)`. Довший шаблон потрібен для пошуку в реченні, де збігом має бути ціле слово.

## Типові помилки

- **Рядок заміни без `r`.** У `'\1'` Python перетворює `\1` на керівний символ із кодом 1 ще до того, як рядок потрапить у `re`:

  ```python
  import re

  print(repr(re.sub(r"(\w+)", "\1", "hello")))
  print(repr(re.sub(r"(\w+)", r"\1", "hello")))
  ```

  Результат:

  ```text
  '\x01'
  'hello'
  ```

- **Забуті межі слова.** `(\w+)\s+\1` збігається й із частинами слів (`This is` перетворюється на `This`). Пишіть `\b(\w+)\s+\1\b`.
- **`\g<1>` усередині шаблону.** Цей запис працює лише в рядках заміни. У шаблонах пишіть `\1` або `(?P=name)`.
- **Очікувати, що `\1` повторює підшаблон.** `(\d)\1` збігається з `77`, але не з `12`. Щоб повторити саме *шаблон*, використовуйте квантифікатор: `\d{2}` або `(\d){2}`.
- **Отримувати від `findall()` лише групу.** `re.findall(r"\b\w*(\w)\1\w*\b", text)` повертає подвоєні літери, а не слова. Використовуйте `finditer()` і `group()` або огорніть усе слово окремою групою.
- **Писати `\10`, маючи на увазі «група 1, а потім 0».** Пишіть `\g<1>0`.

## Підсумок

- `\N` у шаблоні збігається з точно тим текстом, який група `N` захопила раніше в тому самому збігу.
- `(?P=name)` — іменована форма зворотного посилання всередині шаблону.
- У рядках заміни використовуйте `\N`, `\g<N>`, `\g<name>`, а для всього збігу — `\g<0>`. Усередині шаблону `\g<...>` недопустимий.
- Завжди записуйте і шаблон, і рядок заміни як сирі рядки.
- Додавайте `\b` навколо слів зі зворотними посиланнями, інакше збіги можуть починатися чи закінчуватися всередині слів.
- З `re.IGNORECASE` зворотні посилання теж ігнорують регістр.
- Зворотне посилання на групу, що не збіглася, у шаблоні не дає збігу, а в рядку заміни перетворюється на порожній рядок.

## Практика

### Вправа 1: Подвоєні літери в реченні

Виведіть кожне слово, яке містить дві однакові літери поспіль, із речення:

```text
The committee will meet at noon to discuss the book
```

### Вправа 2: Згорніть повтори слів

Напишіть функцію `dedupe(text)`, яка згортає будь-яку кількість послідовних повторів слова без урахування регістру й зберігає перше написання. `"This is is is a test test. Go go now"` має перетворитися на `"This is a test. Go now"`.

### Вправа 3: Американські дати у формат ISO

Перетворіть дати у форматі `MM/DD/YYYY` на `YYYY-MM-DD` за допомогою іменованих груп і `\g<name>` у рядку заміни. Перевірте на `"Due 12/31/2024 and 01/05/2025"`.

### Вправа 4: Правильно закриті теги

З рядка нижче витягніть пари `(тег, вміст)` лише для тегів, у яких закривний тег збігається з відкривним. Очікуваний результат — `[('b', 'bold'), ('code', 'x')]`.

```text
<b>bold</b> <i>italic</b> <code>x</code>
```

## Розв'язки

### Вправа 1

```python
import re

text = "The committee will meet at noon to discuss the book"
words = [m.group() for m in re.finditer(r"\b\w*(\w)\1\w*\b", text)]
print(words)
```

Результат:

```text
['committee', 'will', 'meet', 'noon', 'discuss', 'book']
```

`findall()` повернув би лише групу 1 (подвоєну літеру), тому розв'язок бере `group()` з кожного збігу.

### Вправа 2

```python
import re


def dedupe(text):
    return re.sub(r"\b(\w+)(\s+\1\b)+", r"\1", text, flags=re.IGNORECASE)


print(dedupe("This is is is a test test. Go go now"))
print(dedupe("This is it"))
```

Результат:

```text
This is a test. Go now
This is it
```

`(\s+\1\b)+` поглинає один або кілька повторів за один збіг, тож три копії `is` згортаються одразу. Заміна `\1` зберігає перше написання (`Go`, а не `go`).

### Вправа 3

```python
import re

text = "Due 12/31/2024 and 01/05/2025"
pattern = r"(?P<month>\d{2})/(?P<day>\d{2})/(?P<year>\d{4})"

print(re.sub(pattern, r"\g<year>-\g<month>-\g<day>", text))
```

Результат:

```text
Due 2024-12-31 and 2025-01-05
```

### Вправа 4

```python
import re

text = "<b>bold</b> <i>italic</b> <code>x</code>"
print(re.findall(r"<(\w+)>(.*?)</\1>", text))
```

Результат:

```text
[('b', 'bold'), ('code', 'x')]
```

Для `<i>` рушій шукає закривний `</i>`, якого в рядку немає, тож ця спроба зазнає невдачі, і пошук рухається далі. Такий підхід годиться лише для простої пласкої розмітки. Для справжнього HTML потрібен HTML-парсер, наприклад `html.parser`.
