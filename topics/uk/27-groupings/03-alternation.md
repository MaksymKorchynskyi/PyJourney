# Альтернація

**Альтернація** (alternation) — це «АБО» регулярних виразів. Символ вертикальної риски `|` розділяє альтернативи, і вираз збігається, якщо збігається *будь-яка* з них. Так один шаблон може приймати кілька різних слів чи форматів, але тут є дві пастки, про які варто знати: `|` має найнижчий пріоритет серед усіх операторів регулярних виразів, а Python перебирає альтернативи строго зліва направо.

## Що ви дізнаєтесь

- Як `X|Y` збігається або з `X`, або з `Y`
- Чому `|` розділяє *весь* шаблон, якщо не обмежити його групою
- Як обмежити альтернацію частиною шаблону за допомогою дужок
- Чому порядок альтернатив має значення (перемагає перша, а не найдовша)
- Коли клас символів кращий за альтернацію
- Як дізнатися, яка альтернатива збіглася, і як безпечно побудувати альтернацію зі списку

## Оператор `|`

Оператор `|` збігається з виразом ліворуч від нього **або** з виразом праворуч. Він працює приблизно як оператор `or` у Python:

```text
simple|complex
```

Цей шаблон знаходить буквальний текст `simple` або буквальний текст `complex`:

```python
import re

s = "simple is better than complex"
matches = re.findall(r"simple|complex", s)
print(matches)
```

Результат:

```text
['simple', 'complex']
```

Альтернатив може бути скільки завгодно: `cat|dog|bird`. На кожній позиції рядка рушій пробує альтернативи по черзі, і перша, що підходить, дає збіг.

## Пріоритет: `|` розділяє все

Альтернація має **найнижчий пріоритет** у регулярному виразі. Усе, що ліворуч від `|` аж до початку шаблону (або охопної групи), — це одна альтернатива, а все праворуч — інша. Послідовність символів зв'язується сильніше.

Тож `^cat|dog$` означає не «весь рядок — це `cat` або `dog`», а «`cat` на початку **або** `dog` у кінці»:

```python
import re

print(re.findall(r"^cat|dog$", "cat and dog"))
print(re.findall(r"^cat|dog$", "dog and cat"))
print(re.findall(r"^(cat|dog)$", "dog"))
```

Результат:

```text
['cat', 'dog']
[]
['dog']
```

Дужки обмежують альтернацію тією частиною, що всередині них. В останньому шаблоні якорі стосуються обох альтернатив.

### Приклад: час у форматі `hh:mm`

Перша спроба для часу на кшталт `09:30` — дві цифри, двокрапка і ще дві цифри:

```text
\d{2}:\d{2}
```

Але так проходять і безглузді значення, як-от `99:99`. Альтернація дає змогу точно описати допустимі діапазони.

Допустимі години — від `00` до `23`:

```text
[01]\d|2[0-3]
```

- `[01]\d` збігається з `00`–`19`: `0` або `1`, а за ними будь-яка цифра.
- `2[0-3]` збігається з `20`, `21`, `22` і `23`.

Допустимі хвилини — від `00` до `59`, і тут альтернація не потрібна:

```text
[0-5]\d
```

Тепер наївно з'єднаймо обидві частини:

```python
import re

s = "09:30 30:61 22:30 25:99"
pattern = r"[01]\d|2[0-3]:[0-5]\d"

for match in re.finditer(pattern, s):
    print(match.group())
```

Результат:

```text
09
22:30
```

Перший результат — лише `09`. Оскільки `|` має найнижчий пріоритет, рушій читає шаблон як дві альтернативи:

```text
[01]\d              <- альтернатива 1: лише година
2[0-3]:[0-5]\d      <- альтернатива 2: година від 20 до 23, двокрапка і хвилини
```

Щоб альтернація стосувалася лише години, візьміть цю частину в дужки:

```python
import re

s = "09:30 30:61 22:30 25:99"
pattern = r"([01]\d|2[0-3]):[0-5]\d"

for match in re.finditer(pattern, s):
    print(match.group())
```

Результат:

```text
09:30
22:30
```

Тепер шаблон означає «(`[01]\d` або `2[0-3]`), потім `:`, потім `[0-5]\d`», і `30:61` та `25:99` правильно відкидаються.

> **Зверніть увагу:** ці дужки ще й *захоплюють*. Для `finditer()` і `group()` це неважливо, але `re.findall()` повертає групу замість усього збігу: `re.findall(r"([01]\d|2[0-3]):[0-5]\d", s)` дає `['09', '22']`. Коли потрібне лише групування, використовуйте групу без захоплення `(?:[01]\d|2[0-3])` — про неї йдеться в наступній темі.

## Порядок важливий: перемагає перша альтернатива

Рушій `re` у Python **не** шукає найдовшу альтернативу. На кожній позиції він пробує альтернативи зліва направо й бере першу, з якою решта шаблону теж може збігтися:

```python
import re

text = "I like JavaScript"

print(re.search(r"Java|JavaScript", text).group())
print(re.search(r"JavaScript|Java", text).group())
print(re.search(r"\b(Java|JavaScript)\b", text).group())
```

Результат:

```text
Java
JavaScript
JavaScript
```

- У `Java|JavaScript` першою збігається коротша альтернатива, і рушій на ній зупиняється.
- Ставте довші альтернативи першими, **або**
- додайте після альтернації щось, що змусить рушій переглянути вибір. У третьому шаблоні після `Java` іде `S`, тому кінцеве `\b` не спрацьовує, рушій повертається назад (backtracking) і пробує `JavaScript`.

## Альтернація чи клас символів?

Коли кожна альтернатива — один символ, клас символів коротший, зрозуміліший і швидший:

| Мета | Альтернація | Краще |
|---|---|---|
| одна голосна | `a\|e\|i\|o\|u` | `[aeiou]` |
| `gray` або `grey` | `gr(a\|e)y` | `gr[ae]y` |
| необов'язкова `u` | `col(o\|ou)r` | `colou?r` |
| різні слова | `cat\|dog` | `cat\|dog` (тут альтернація — саме те, що треба) |

Не плутайте ці два інструменти: у квадратних дужках `|` — звичайний символ. `[cat|dog]` — це клас окремих символів `c`, `a`, `t`, `|`, `d`, `o` і `g`:

```python
import re

print(re.findall(r"[cat|dog]", "a|b"))
```

Результат:

```text
['a', '|']
```

## Яка альтернатива збіглася?

Якщо дати кожній альтернативі власну іменовану групу, `match.lastgroup` повідомить, яка з них збіглася. На цьому побудовано чимало простих токенізаторів:

```python
import re

token = re.compile(r"(?P<number>\d+)|(?P<word>[a-z]+)|(?P<space>\s+)")

for match in token.finditer("route 66 to rome"):
    if match.lastgroup != "space":
        print(match.lastgroup, repr(match.group()))
```

Результат:

```text
word 'route'
number '66'
word 'to'
word 'rome'
```

Одночасно може збігтися лише одна альтернатива, тож значення має рівно одна група, і `lastgroup` — її ім'я.

## Побудова альтернації зі списку

Коли альтернативи беруться з даних, легко припуститися двох помилок:

1. Спеціальні символи в словах (`+`, `.`, `?`, `(`...) сприймаються як синтаксис регулярних виразів. Екрануйте кожне слово через `re.escape()`.
2. Коротке слово, що є префіксом довшого, перемагає (`C` раніше за `C++`). Сортуйте за довжиною, від найдовшого.

```python
import re

languages = ["C", "C++", "C#", "Python"]
text = "I use C++, C# and C. Python too."

naive = "|".join(languages)
print(re.findall(naive, text))

safe = "|".join(re.escape(w) for w in sorted(languages, key=len, reverse=True))
print(safe)
print(re.findall(safe, text))
```

Результат:

```text
['C', 'C', 'C', 'Python']
Python|C\+\+|C\#|C
['C++', 'C#', 'C', 'Python']
```

Наївна версія навіть не генерує помилки: починаючи з Python 3.11, `C++` — допустимий синтаксис (`C+`, а за ним присвійний (possessive) квантифікатор `+`), тож помилка минає непомітно, і кожне `C...` збігається як просто `C`.

## Читабельна альтернація з `re.VERBOSE`

Довгі альтернації швидко стають нечитабельними. З прапорцем `re.VERBOSE` пробіли в шаблоні ігноруються, а `#` починає коментар, тож шаблон можна розкласти на кілька рядків:

```python
import re

TIME = re.compile(r"""
    \b
    ([01]\d | 2[0-3])   # години 00-23
    :
    [0-5]\d             # хвилини 00-59
    \b
""", re.VERBOSE)

for match in TIME.finditer("09:30 30:61 22:30 25:99 123:456 00:00"):
    print(match.group())
```

Результат:

```text
09:30
22:30
00:00
```

Якорі `\b` ще й не дають шаблону знайти `23:45` усередині `123:456`.

## Типові помилки

- **Забувати, що `|` розділяє весь шаблон.** `^cat|dog$` і `[01]\d|2[0-3]:[0-5]\d` означають не те, на що схожі. Беріть альтернацію в групу.
- **Ставити коротку альтернативу перед довшою з тим самим префіксом.** `Java|JavaScript` сам собою ніколи не знайде повне `JavaScript`. Упорядкуйте від найдовшої або додайте межу після групи.
- **Писати `|` у класі символів.** `[a|b]` збігається ще й із буквальним `|`. Пишіть `[ab]` або `a|b`.
- **Отримувати від `findall()` лише групу.** Якщо згрупувати альтернацію через `(...)`, `findall()` поверне групу. Використовуйте `(?:...)`, коли захоплене значення не потрібне.
- **Будувати альтернацію із сирих даних користувача.** Без `re.escape()` символи на кшталт `+`, `.` чи `(` змінюють зміст шаблону або спричиняють `re.PatternError`.
- **Залишати порожню альтернативу.** Кінцева `|` (як у `a|`) додає альтернативу, що збігається з порожнім рядком, і шаблон збігається будь-де: `re.findall(r"a|", "abc")` повертає `['a', '', '', '']`.

## Підсумок

- `X|Y` збігається з `X` або `Y`. Альтернатив може бути скільки завгодно.
- `|` має найнижчий пріоритет: він розділяє на альтернативи весь шаблон (або всю охопну групу).
- Дужки обмежують альтернацію частиною шаблону: `([01]\d|2[0-3]):[0-5]\d`.
- Альтернативи перебираються зліва направо, і перемагає перша, що веде до загального збігу, а не найдовша.
- Для окремих символів краще клас символів: `[ae]` замість `a|e`.
- Іменовані групи разом із `match.lastgroup` показують, яка альтернатива збіглася.
- Будуйте альтернацію з даних через `re.escape()` і сортуйте слова від найдовшого.

Перевірте її на `"cat.PNG"`, `"notes.txt"`, `"photo.jpeg"` і `"anim.gif.bak"`.

### Вправа 2: Перевірка дат

Напишіть шаблон для `fullmatch()`, що приймає дати у форматі `YYYY-MM-DD`, де місяць від `01` до `12`, а день від `01` до `31` (кількість днів у конкретному місяці перевіряти не треба). Перевірте його на `"2024-02-29"`, `"2024-13-01"`, `"2024-00-10"`, `"2024-12-31"` і `"2024-12-32"`.

### Вправа 3: Передбачте результат

Передбачте, що виведе кожен рядок, а потім перевірте себе.

```python
import re

text = "one two"
print(re.findall(r"one|one two|two", text))
print(re.findall(r"one two|one|two", text))
```

### Вправа 4: Цілі слова зі списку

Напишіть функцію `find_words(words, text)`, яка знаходить входження будь-якого з поданих слів як цілих слів. Виклик `find_words(["cat", "category", "dog"], "A category of cat and dog food")` має повернути `['category', 'cat', 'dog']`.

## Розв'язки

### Вправа 1

```python
import re


def image_extension(filename):
    match = re.search(r"\.(png|jpe?g|gif)$", filename, flags=re.IGNORECASE)
    return match.group(1).lower() if match else None


for name in ["cat.PNG", "notes.txt", "photo.jpeg", "anim.gif.bak"]:
    print(name, image_extension(name))
```

Результат:

```text
cat.PNG png
notes.txt None
photo.jpeg jpeg
anim.gif.bak None
```

`jpe?g` охоплює і `jpg`, і `jpeg` однією альтернативою. `$` після групи стосується кожної альтернативи, бо група обмежує альтернацію.

### Вправа 2

```python
import re

DATE = re.compile(r"\d{4}-(0[1-9]|1[0-2])-(0[1-9]|[12]\d|3[01])")

for value in ["2024-02-29", "2024-13-01", "2024-00-10", "2024-12-31", "2024-12-32"]:
    print(value, bool(DATE.fullmatch(value)))
```

Результат:

```text
2024-02-29 True
2024-13-01 False
2024-00-10 False
2024-12-31 True
2024-12-32 False
```

- Місяць: `0[1-9]` дає `01`–`09`, `1[0-2]` дає `10`–`12`.
- День: `0[1-9]` дає `01`–`09`, `[12]\d` дає `10`–`29`, `3[01]` дає `30` і `31`.

### Вправа 3

Результат:

```text
['one', 'two']
['one two']
```

У першому шаблоні першою стоїть `one`, вона збігається на позиції 0, тож до `one two` справа не доходить. Далі пошук продовжується після `one` і знаходить `two`. У другому шаблоні першою пробується довша альтернатива, і вона поглинає весь текст.

### Вправа 4

```python
import re


def find_words(words, text):
    ordered = sorted(words, key=len, reverse=True)
    alternatives = "|".join(re.escape(word) for word in ordered)
    return [m.group() for m in re.finditer(rf"\b({alternatives})\b", text)]


print(find_words(["cat", "category", "dog"], "A category of cat and dog food"))
print(find_words(["cat"], "concatenate the cat"))
```

Результат:

```text
['category', 'cat', 'dog']
['cat']
```

`\b` з обох боків гарантує, що збігаються лише цілі слова (`cat` усередині `concatenate` пропускається), а сортування за довжиною робить шаблон правильним навіть без меж слова. `rf"..."` — це сирий f-рядок: зворотні скісні риски лишаються недоторканими, а замість `{alternatives}` підставляється значення.
