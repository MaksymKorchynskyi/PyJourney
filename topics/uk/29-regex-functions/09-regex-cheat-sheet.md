# Шпаргалка з регулярних виразів

Ця сторінка зводить усе, що розглянуто в темах про регулярні вирази, у компактні таблиці, які зручно переглядати під час написання шаблону: класи символів, набори, якорі, квантифікатори, групи, перегляд уперед і назад, функції модуля `re`, об'єкт `Match` і прапорці. Кожна таблиця пов'язує синтаксис із його значенням у Python 3, зокрема з деталями, у яких часто помиляються інші шпаргалки. Чому все працює саме так, докладно пояснюють самі теми.

## Що ви дізнаєтесь

- Увесь синтаксис регулярних виразів модуля `re`, упорядкований у короткі довідкові таблиці
- Яку функцію `re` використовувати для якої задачі і що кожна з них повертає
- Найкорисніші методи `Match`, екранування в рядку заміни та прапорці
- Пастки, що стоять за найпоширенішими помилками в регулярних виразах
- Як усі частини працюють разом у повних перевірених прикладах

## Як записувати шаблони в Python

Завжди записуйте шаблони як **сирі рядки** (raw strings, `r"..."`). У звичайному рядку Python спершу сам обробляє екранування зворотною скісною рискою, тож `"\b"` перетворюється на символ backspace ще до того, як його побачить рушій регулярних виразів:

```python
import re

print(len("\b"), len(r"\b"))
print(re.findall("\bcat\b", "cat concat"))
print(re.findall(r"\bcat\b", "cat concat"))

user_input = "1+1=2?"
print(re.escape(user_input))
print(re.findall(re.escape(user_input), "Is 1+1=2? Yes, 1+1=2?"))
```

Результат:

```text
1 2
[]
['cat']
1\+1=2\?
['1+1=2?', '1+1=2?']
```

**Метасимволи** — це `. ^ $ * + ? { } [ ] \ | ( )`. Щоб знайти їх буквально, екрануйте їх зворотною скісною рискою (`\.`, `\$`, `\(`), а текст від користувачів чи з файлів пропускайте через `re.escape()`.

## Класи символів

Кожен клас відповідає **рівно одному** символу. Див. тему «Класи символів».

| Шаблон | Відповідає одному... | Протилежний |
|---|---|---|
| `.` | символу, крім символу нового рядка (будь-якому з `re.DOTALL`) | |
| `\d` | десятковій цифрі | `\D` |
| `\w` | символу слова: літері, цифрі або `_` | `\W` |
| `\s` | пробільному символу: пробіл, `\t`, `\n`, `\r`, `\f`, `\v` і пробіли Unicode | `\S` |
| `\.` `\\` `\$` | буквальній крапці, зворотній скісній рисці, знаку долара (будь-якому метасимволу) | |
| `\n` `\t` | символу нового рядка, табуляції | |

У Python 3 шаблони типу `str` **враховують Unicode**: `\w` відповідає `é`, `ї` і `Ж`, а `\d` — цифрам інших писемностей, як-от `٣`. З `re.ASCII` класи звужуються: `\d` = `[0-9]`, `\w` = `[a-zA-Z0-9_]`, `\s` = `[ \t\n\r\f\v]`.

## Набори та діапазони

Набір у квадратних дужках теж відповідає **одному** символу. Див. тему «Набори та діапазони».

| Шаблон | Відповідає одному... |
|---|---|
| `[abc]` | `a`, `b` або `c` |
| `[a-z]` | символу з діапазону від `a` до `z` (за кодовими точками) |
| `[a-zA-Z0-9_]` | символу з кількох діапазонів і окремих символів |
| `[^abc]` | символу, що **не** є `a`, `b` чи `c` (зокрема `\n`) |
| `[\d\s]` | цифрі або пробільному символу (класи всередині набору дозволені) |
| `[.?!*]` | буквальним `.`, `?`, `!` або `*` (більшість метасимволів у наборі буквальні) |
| `[-a]`, `[a-]`, `[a\-z]` | буквальному дефісу (першим, останнім або екранованим) |
| `[\]\\^]` | буквальним `]`, `\` або `^` (екрануйте їх) |
| `[^\W\d_]` | літері будь-якої абетки |

Знак `^` заперечує лише одразу після `[`. `^[abc]` — зовсім інше: якір, а за ним набір.

## Якорі та межі

Якорі відповідають **позиціям** і не забирають жодного символу. Див. теми «Якорі» та «Межа слова».

| Шаблон | Відповідає | Примітки |
|---|---|---|
| `^` | початку рядка | початку кожного рядка тексту з `re.MULTILINE` |
| `$` | кінцю рядка **або позиції перед завершальним `\n`** | кінцю кожного рядка тексту з `re.MULTILINE` |
| `\A` | самому початку рядка | `re.MULTILINE` на нього не впливає |
| `\Z` | самому кінцю рядка | `\z` — його псевдонім, починаючи з Python 3.14 |
| `\b` | межі слова: з одного боку `\w`, з іншого `\W` або край рядка | |
| `\B` | будь-якій позиції, що не є межею слова | |

Для перевірки всього рядка краще використовувати `re.fullmatch()`, ніж `^...$`.

## Квантифікатори

Квантифікатор повторює один елемент перед ним: символ, клас, набір або групу. Див. теми «Квантифікатори», «Жадібні квантифікатори» і «Нежадібні квантифікатори».

| Жадібний | Лінивий | Присвійний (3.11+) | Повторень |
|---|---|---|---|
| `*` | `*?` | `*+` | 0 або більше |
| `+` | `+?` | `++` | 1 або більше |
| `?` | `??` | `?+` | 0 або 1 |
| `{n}` | `{n}?` | `{n}+` | рівно `n` |
| `{n,}` | `{n,}?` | `{n,}+` | щонайменше `n` |
| `{,m}` | `{,m}?` | `{,m}+` | від 0 до `m` |
| `{n,m}` | `{n,m}?` | `{n,m}+` | від `n` до `m` |

- **Жадібний** (за замовчуванням) бере якнайбільше й віддає символи назад, поки решта шаблону не збігається.
- **Лінивий** бере якнайменше й додає символи, поки решта шаблону не збігається.
- **Присвійний** бере якнайбільше й ніколи нічого не віддає.
- Жодних пробілів у фігурних дужках: `{2,3}`, а не `{2, 3}`.
- Щоб повторити послідовність, згрупуйте її: `(?:ab)+`, а не `ab+`.

## Групи та зворотні посилання

Див. теми «Групи захоплення», «Групи без захоплення» і «Зворотні посилання».

| Шаблон | Значення |
|---|---|
| `(X)` | група захоплення, нумерується за відкривною дужкою, починаючи з 1 |
| `(?P<name>X)` | іменована група захоплення |
| `(?:X)` | група без захоплення (для квантифікаторів і альтернації) |
| `(?>X)` | атомарна група: рушій ніколи не повертається всередину `X` (3.11+) |
| `(?i:X)`, `(?-i:X)` | увімкнути чи вимкнути прапорець лише всередині `X` |

Зворотні посилання записуються по-різному в шаблоні та в рядку заміни:

| Де | За номером | За назвою | Увесь збіг |
|---|---|---|---|
| усередині шаблону | `\1` | `(?P=name)` | (недоступно) |
| у `repl` функції `sub()` | `\1` або `\g<1>` | `\g<name>` | `\g<0>` |

`\g<...>` можна писати **лише** в рядку заміни. У шаблоні це спричиняє `re.PatternError: bad escape \g`.

## Альтернація

Див. тему «Альтернація».

| Шаблон | Значення |
|---|---|
| `X\|Y` | `X` або `Y` |
| `^(?:cat\|dog)$` | увесь рядок — це `cat` або `dog` |
| `^cat\|dog$` | `cat` на початку **або** `dog` у кінці (`\|` має найнижчий пріоритет) |
| `gr[ae]y` | для окремих символів набір кращий за `gr(?:a\|e)y` |

Альтернативи перебираються зліва направо, і перемагає перша, що веде до збігу всього шаблону, а не найдовша. Пробіли навколо `|` буквальні: `cat | dog` означає `"cat "` або `" dog"`.

## Перегляд уперед і назад

Ці перевірки дивляться на текст навколо позиції, не забираючи його. Див. теми «Перегляд уперед» і «Перегляд назад».

| Шаблон | `X` збігається, лише якщо... |
|---|---|
| `X(?=Y)` | далі йде `Y` (позитивний перегляд уперед) |
| `X(?!Y)` | далі не йде `Y` (негативний перегляд уперед) |
| `(?<=Y)X` | перед ним стоїть `Y` (позитивний перегляд назад) |
| `(?<!Y)X` | перед ним не стоїть `Y` (негативний перегляд назад) |

- Текст, що збігся з `Y`, не входить у збіг.
- У `re` перегляд назад мусить мати **фіксовану довжину**: `(?<=\d+)` спричиняє `look-behind requires fixed-width pattern`.
- Кілька переглядів уперед в одній позиції діють як «І»: `(?=.*\d)(?=.*[A-Z])`.

## Функції модуля `re`

| Функція | Повертає | Для чого |
|---|---|---|
| `re.search(p, s)` | перший `Match` будь-де або `None` | з'ясувати, чи і де трапляється шаблон |
| `re.match(p, s)` | `Match` на початку `s` або `None` | розібрати префікс |
| `re.fullmatch(p, s)` | `Match`, якщо підходить увесь `s`, або `None` | перевірити введені дані |
| `re.findall(p, s)` | список рядків або кортежів (`[]`, якщо нічого немає, ніколи не `None`) | зібрати всі збіги |
| `re.finditer(p, s)` | ітератор об'єктів `Match` | усі збіги з позиціями та групами |
| `re.sub(p, repl, s, count=0)` | новий рядок | замінити (`repl` може бути функцією) |
| `re.subn(p, repl, s, count=0)` | `(новий_рядок, кількість_замін)` | замінити й порахувати |
| `re.split(p, s, maxsplit=0)` | список рядків | розбити за шаблоном |
| `re.compile(p, flags)` | об'єкт `Pattern` з тими самими методами | використовувати шаблон повторно, шукати з `pos`/`endpos` |
| `re.escape(text)` | рядок з екранованими метасимволами | вставити буквальний текст у шаблон |

Форма результату `findall()` залежить від груп: без груп — цілі збіги, з однією групою — текст цієї групи, з кількома — кортежі. `split()` із групою захоплення залишає роздільники в результаті. Передавайте `count`, `maxsplit` і `flags` **як іменовані аргументи**: позиційна передача застаріла, починаючи з Python 3.13.

Один рядок, усі функції:

```python
import re

text = "Order 66 shipped on 2024-05-17, order 7 pending"

print(re.search(r"\d+", text))
print(re.match(r"\d+", text))
print(re.fullmatch(r"[\w\s,-]+", text) is not None)
print(re.findall(r"\d+", text))
print([m.span() for m in re.finditer(r"\d+", text)])
print(re.sub(r"\d", "#", text, count=2))
print(re.subn(r"\d", "#", text))
print(re.split(r",\s*", text))
```

Результат:

```text
<re.Match object; span=(6, 8), match='66'>
None
True
['66', '2024', '05', '17', '7']
[(6, 8), (20, 24), (25, 27), (28, 30), (38, 39)]
Order ## shipped on 2024-05-17, order 7 pending
('Order ## shipped on ####-##-##, order # pending', 11)
['Order 66 shipped on 2024-05-17', 'order 7 pending']
```

## Об'єкт `Match`

| Вираз | Дає |
|---|---|
| `m.group()`, `m.group(0)`, `m[0]` | увесь збіг |
| `m.group(1)`, `m[1]`, `m["name"]` | одну групу (`None`, якщо вона не брала участі) |
| `m.group(1, 2)` | кортеж із кількох груп |
| `m.groups()` | кортеж усіх груп |
| `m.groupdict()` | словник усіх іменованих груп |
| `m.start()`, `m.end()`, `m.span()` | позиції збігу (`end` не включно); передайте групу, щоб отримати її позиції |
| `m.lastgroup` | назва останньої групи, що збіглася (зручно для токенізаторів) |

Невдалий пошук повертає `None`, тож перевіряйте результат, перш ніж ним користуватися:

```python
import re

m = re.search(r"(?P<year>\d{4})-(?P<month>\d\d)-(?P<day>\d\d)", "Released on 2024-05-17.")

if m:
    print(m.group())
    print(m.group(1), m["month"], m.group("day"))
    print(m.groups())
    print(m.groupdict())
    print(m.start(), m.end(), m.span("month"))
```

Результат:

```text
2024-05-17
2024 05 17
('2024', '05', '17')
{'year': '2024', 'month': '05', 'day': '17'}
12 22 (17, 19)
```

## Прапорці

Усі подробиці — у темі «Прапорці регулярних виразів».

| Прапорець | Коротко | Вбудований | Дія |
|---|---|---|---|
| `re.IGNORECASE` | `re.I` | `(?i)` | ігнорувати регістр літер |
| `re.MULTILINE` | `re.M` | `(?m)` | `^` і `$` діють для кожного рядка тексту |
| `re.DOTALL` | `re.S` | `(?s)` | `.` відповідає й `\n` |
| `re.VERBOSE` | `re.X` | `(?x)` | ігнорувати пробіли в шаблоні, дозволити коментарі `#` |
| `re.ASCII` | `re.A` | `(?a)` | `\w`, `\d`, `\s`, `\b` і протилежні їм відповідають лише ASCII (для шаблонів `str`) |
| `re.LOCALE` | `re.L` | `(?L)` | пошук залежить від локалі, лише для шаблонів `bytes`, не рекомендується |
| `re.UNICODE` | `re.U` | `(?u)` | пошук з урахуванням Unicode, для `str` це вже за замовчуванням |
| `re.DEBUG` | | | вивести розібраний шаблон |
| `re.NOFLAG` | | | значення `0`, «без прапорців» (3.11+) |

- Поєднуйте прапорці через `|`: `re.I | re.M`.
- Глобальні вбудовані прапорці на кшталт `(?im)` мають стояти на самому початку шаблону. Деінде вони спричиняють `global flags not at the start of the expression`.
- Прапорці з областю дії `(?i:...)` діють лише всередині своєї групи.

## Усе разом

### Розбір журналу з `re.VERBOSE` та іменованими групами

```python
import re

LOG_LINE = re.compile(r"""
    (?P<date>\d{4}-\d\d-\d\d)  # 2024-05-17
    \s+
    (?P<level>[A-Z]+)          # INFO, ERROR, ...
    \s+
    \[(?P<module>\w+)\]        # [db]
    \s+
    (?P<message>.+)            # решта рядка
""", re.VERBOSE)

log = """2024-05-17 INFO [web] Server started
garbage line
2024-05-17 ERROR [db] Connection lost"""

for line in log.splitlines():
    m = LOG_LINE.fullmatch(line)
    if m:
        print(m.groupdict())
```

Результат:

```text
{'date': '2024-05-17', 'level': 'INFO', 'module': 'web', 'message': 'Server started'}
{'date': '2024-05-17', 'level': 'ERROR', 'module': 'db', 'message': 'Connection lost'}
```

### Правила для пароля з переглядом уперед

Щонайменше 8 непробільних символів, серед яких є мала літера, велика літера й цифра:

```python
import re

STRONG = re.compile(r"(?=.*[a-z])(?=.*[A-Z])(?=.*\d)\S{8,}")

for password in ["secret", "Secret123", "secret123", "Secret 123"]:
    print(password, bool(STRONG.fullmatch(password)))
```

Результат:

```text
secret False
Secret123 True
secret123 False
Secret 123 False
```

### Зміна формату дат через `sub()` і зворотні посилання

```python
import re

text = "Due 17.05.2024, paid 03.06.2024, ref 117.05.20245"

print(re.sub(r"\b(\d\d)\.(\d\d)\.(\d{4})\b", r"\3-\2-\1", text))
```

Результат:

```text
Due 2024-05-17, paid 2024-06-03, ref 117.05.20245
```

Межі слова `\b` не дають шаблону збігтися всередині довшого числа `117.05.20245`.

## Типові помилки

- **Забувати префікс `r`.** `"\bword\b"` містить символи backspace і мовчки нічого не знаходить.
- **Неекрановані метасимволи.** `3.14` збігається й з `3x14`. Пишіть `3\.14` або використовуйте `re.escape()` для буквального тексту.
- **`^[abc]` замість `[^abc]`.** Перше — це «a, b чи c на початку», друге — «один символ, відмінний від a, b, c».
- **Діапазони як числа.** `[1-31]` — це набір символів `1`, `2`, `3`.
- **Пробіли навколо `|`.** `cat | dog` містить буквальні пробіли.
- **`\g<1>` у шаблоні.** Усередині шаблону використовуйте `\1` або `(?P=name)`. `\g<...>` — для рядків заміни.
- **Очікувати від `findall()` значення `None`.** Вона повертає `[]`. `None` повертають лише `search()`, `match()` і `fullmatch()`.
- **Групи, що змінюють результат `findall()`.** Додавши групу, ви отримаєте замість цілих збігів тексти груп. Використовуйте `(?:...)` або `finditer()`.
- **`^...$` для валідації.** `$` збігається й перед завершальним символом нового рядка. Використовуйте `fullmatch()`.
- **Жадібний `.*` між роздільниками.** `".*"` доходить до останньої лапки. Використовуйте `"[^"]*"` або `".*?"`.
- **Перегляд назад змінної довжини.** `(?<=\d+)` у `re` — помилка. Використовуйте фіксовану довжину або групу.
- **Позиційні `count`/`flags`.** `re.sub(p, r, s, re.I)` передає `re.I` як `count`. Завжди пишіть `flags=re.I`.

## Підсумок

- Записуйте шаблони як сирі рядки й екрануйте метасимволи або використовуйте `re.escape()` для буквального тексту.
- Класи (`\d`, `\w`, `\s`, `.`) і набори (`[...]`, `[^...]`) відповідають одному символу. У Python 3 класи враховують Unicode.
- Якорі (`^`, `$`, `\A`, `\Z`, `\b`, `\B`) і перегляди (`(?=)`, `(?!)`, `(?<=)`, `(?<!)`) відповідають позиціям.
- Квантифікатори за замовчуванням жадібні, з `?` — ліниві, з `+` — присвійні (3.11+).
- `(X)` захоплює, `(?P<name>X)` дає назву, `(?:X)` лише групує. Зворотні посилання — це `\1`/`(?P=name)` у шаблонах і `\1`/`\g<name>`/`\g<0>` у рядках заміни.
- `search()` шукає, `match()` перевіряє початок, `fullmatch()` валідує, `findall()`/`finditer()` збирають, `sub()` замінює, `split()` розбиває.
- Прапорці: `I`, `M`, `S`, `X`, `A`. Поєднуйте через `|`, передавайте як іменовані аргументи, вбудовуйте на початку шаблону або обмежуйте групою `(?i:...)`.

## Розв'язки

### Вправа 1

Результат зламаного коду:

```text
[]
None
PatternError: bad escape \g at position 4
```

```python
import re

print(re.findall(r"[^0-9]", "a1b2"))
print(re.fullmatch(r"cat|dog", "dog"))
print(re.findall(r"(\w)\1", "bookkeeper"))
print([m.group() for m in re.finditer(r"(\w)\1", "bookkeeper")])
```

Результат:

```text
['a', 'b']
<re.Match object; span=(0, 3), match='dog'>
['o', 'k', 'e']
['oo', 'kk', 'ee']
```

1. `^[0-9]` означає «цифра на початку рядка». Знак заперечення має стояти **всередині** дужок: `[^0-9]`.
2. Пробіли навколо `|` входять в альтернативи, тож шаблон приймає лише `"cat "` або `" dog"`.
3. `\g<1>` — синтаксис рядка заміни. У шаблоні зворотне посилання записується як `\1`. Оскільки в шаблоні є група, `findall()` повертає лише текст групи, тож щоб отримати подвоєні літери повністю, скористайтеся `finditer()`.

### Вправа 2

```python
import re

print(bool(re.search(r"@", "write to admin@example.com")))
print(bool(re.fullmatch(r"(?:[01]\d|2[0-3]):[0-5]\d", "23:59")))
print(bool(re.fullmatch(r"(?:[01]\d|2[0-3]):[0-5]\d", "24:00")))
print(re.findall(r"#\w+", "Learning #Python and #regex_101 today #"))
print(re.split(r"\s*[,;]\s*", "red, green;blue ;  white"))
```

Результат:

```text
True
True
False
['#Python', '#regex_101']
['red', 'green', 'blue', 'white']
```

- «Чи містить» — задача для `search()`. Для одного фіксованого символу ще простіше написати `"@" in text`.
- Перевірка всього рядка — задача для `fullmatch()`. Для годин потрібна альтернація, бо друга цифра залежить від першої.
- `findall()` без груп повертає цілі збіги. Самотній `#` у кінці пропускається, бо `\w+` потребує щонайменше одного символу.
- `\s*` з обох боків набору поглинає пробіли навколо кожного роздільника.

### Вправа 3

```python
import re

report = "Kyiv: +3°C, Lviv: -1°C, Odesa: +7°C, Rivne: n/a"

pattern = re.compile(r"(?P<city>[^\W\d_]+):\s*(?P<temp>[+-]?\d+)°C")
temps = {m["city"]: int(m["temp"]) for m in pattern.finditer(report)}

print(temps)
```

Результат:

```text
{'Kyiv': 3, 'Lviv': -1, 'Odesa': 7}
```

`[^\W\d_]+` відповідає літерам будь-якої абетки, тож і `Київ` спрацював би. `[+-]?` робить знак необов'язковим, а `int()` приймає і `+3`, і `-1`. У `Rivne: n/a` немає цифр, тож шаблон там просто не збігається.

### Вправа 4

```python
import re

prices = "Total: 1250 UAH, discount 50 UAH, code UAH100, 99 USD"

print(re.findall(r"\b\d+(?= UAH\b)", prices))
print(re.sub(r"\b(\d+) UAH\b", r"₴\1", prices))
```

Результат:

```text
['1250', '50']
Total: ₴1250, discount ₴50, code UAH100, 99 USD
```

Перегляд уперед `(?= UAH\b)` перевіряє валюту, не забираючи її, тож повертаються лише цифри. У заміні група `(\d+)` зберігає число, а `\1` вставляє його назад після знака гривні. `UAH100` не збігається, бо перед `UAH` там немає числа.
