# findall()

`re.findall()` проходить рядком і збирає **всі** збіги шаблону в список. Це найшвидший спосіб витягти дані з тексту: всі числа зі звіту, всі хештеги з допису, всі пари `key=value` з рядка конфігурації. Єдина несподіванка полягає в тому, що *форма* результату залежить від груп захоплення в шаблоні, тож саме це й треба добре засвоїти.

## Що ви дізнаєтесь

- Сигнатуру `re.findall()` і те, як функція проходить рядок
- Чому збіги ніколи не перекриваються і як усе ж отримати збіги, що перекриваються
- Як 0, 1 або кілька груп захоплення змінюють вміст списку
- Як незахоплювальні групи `(?:...)` зберігають у результаті повний збіг
- Що відбувається, коли збігів немає, і коли шаблон може збігатися з порожнім рядком
- Коли замість `findall()` краще взяти `finditer()`

## Сигнатура

```python
re.findall(pattern, string, flags=0)
```

- `pattern` — регулярний вираз, записаний як сирий рядок (raw string, `r'...'`), або скомпільований об'єкт `Pattern`.
- `string` — текст, у якому шукаємо.
- `flags` — необов'язковий прапорець (flag), наприклад `re.IGNORECASE`, або кілька прапорців, об'єднаних через `|`.

`findall()` завжди повертає **список**. Рушій регулярних виразів починає з позиції 0 і пробує знайти збіг. Якщо це вдається, він запам'ятовує збіг і продовжує **одразу після його кінця**. Якщо ні, зсувається на один символ уперед і пробує знову. Так триває до кінця рядка.

```python
import re

s = "black, blue and brown"
matches = re.findall(r"bl\w+", s)

print(matches)
```

Результат:

```text
['black', 'blue']
```

Шаблон `bl\w+` означає «літери `bl`, за якими йде один або більше символів слова». `brown` починається з `br`, тому до списку не потрапляє.

### Збіги не перекриваються

Оскільки пошук продовжується *після* кожного збігу, один символ може належати лише одному збігу:

```python
import re

print(re.findall(r"\d\d", "12345"))  # ['12', '34']
print(re.findall(r"aa", "aaaa"))  # ['aa', 'aa']
```

`12` поглинає перший збіг, тому рушій навіть не розглядає `23`. Останній символ `5` лишається без пари й пропускається.

Якщо збіги, що перекриваються, справді потрібні, помістіть групу захоплення всередину **перегляду вперед** (lookahead). Перегляд уперед перевіряє текст, але не поглинає його, тож рушій може знову спробувати вже з наступного символу:

```python
import re

print(re.findall(r"(?=(\d\d))", "12345"))  # ['12', '23', '34', '45']
```

## Результат залежить від груп захоплення

Це найважливіше правило `findall()`:

| Груп захоплення в шаблоні | Кожен елемент списку — це |
|---|---|
| жодної | текст усього збігу (`str`) |
| рівно одна | текст, захоплений цією групою (`str`) |
| дві або більше | `tuple` з текстом кожної групи |

Логіка проста: групи позначають «ту частину, яка мені справді потрібна». Якщо ви просите частини, `findall()` повертає частини, а решту відкидає.

### Без груп: повні збіги

Це перший приклад вище: у `bl\w+` немає дужок, тож ви отримуєте цілі слова.

### Одна група: лише вона

```python
import re

s = "black, blue and brown"
matches = re.findall(r"bl(\w+)", s)

print(matches)
```

Результат:

```text
['ack', 'ue']
```

Рушій і далі повністю знаходить `black` і `blue`, але до списку потрапляє лише текст групи `(\w+)`.

### Кілька груп: кортежі

```python
import re

s = "black, blue and brown"
matches = re.findall(r"(bl(\w+))", s)

print(matches)
```

Результат:

```text
[('black', 'ack'), ('blue', 'ue')]
```

Групи нумеруються за **відкривною** дужкою зліва направо. Зовнішня група `(bl(\w+))` має номер 1 і захоплює все слово. Внутрішня `(\w+)` — група 2. У кожному кортежі групи йдуть саме в такому порядку.

Кортежі зручні, коли треба витягти структуровані дані. Дві групи на збіг природно перетворюються на словник:

```python
import re

line = "width=800 height=600 depth=12"
pairs = re.findall(r"(\w+)=(\d+)", line)

print(pairs)
print(dict(pairs))
```

Результат:

```text
[('width', '800'), ('height', '600'), ('depth', '12')]
{'width': '800', 'height': '600', 'depth': '12'}
```

### Групи, які не взяли участі у збігу

Якщо група необов'язкова і не збіглася, `findall()` ставить на її місце **порожній рядок**. (Об'єкт `Match` для такої групи повернув би `None`.)

```python
import re

print(re.findall(r"(\d+)(px)?", "10px 20 30px"))
```

Результат:

```text
[('10', 'px'), ('20', ''), ('30', 'px')]
```

## Незахоплювальні групи зберігають повний збіг

Інколи дужки потрібні лише для групування, наприклад щоб застосувати альтернацію до частини шаблону. Звичайна група змінює форму результату, і це класична пастка:

```python
import re

s = "black, blue and brown"

print(re.findall(r"(bl|br)\w+", s))
print(re.findall(r"(?:bl|br)\w+", s))
```

Результат:

```text
['bl', 'bl', 'br']
['black', 'blue', 'brown']
```

Перший шаблон містить групу захоплення, тому `findall()` для кожного збігу повертає лише `bl` чи `br`. Незахоплювальна група `(?:...)` групує альтернативи, нічого не захоплюючи, тож результат знову складається з повних збігів.

> **Порада:** працюючи з `findall()`, для кожної пари дужок запитуйте себе: «Чи потрібна мені ця частина в результаті?» Якщо ні, пишіть `(?:...)`.

## Прапорці

Третій аргумент приймає прапорці регулярних виразів. З `re.IGNORECASE` шаблон `bl` збігається також із `Bl` і `BL`:

```python
import re

s = "Black, blue and brown"
matches = re.findall(r"(bl(\w+))", s, re.IGNORECASE)

print(matches)
```

Результат:

```text
[('Black', 'ack'), ('blue', 'ue')]
```

Кілька прапорців об'єднують через `|`, наприклад `re.IGNORECASE | re.MULTILINE`. На відміну від `re.sub()` і `re.split()`, у `findall()` перед `flags` немає інших необов'язкових параметрів, тому передавати прапорці третім позиційним аргументом тут безпечно. Проте звичка писати `flags=re.IGNORECASE` все одно корисна.

## Немає збігів: порожній список, а не `None`

Коли збігів немає, `findall()` повертає `[]`. Він ніколи не повертає `None`, тож результат можна перевіряти напряму:

```python
import re

numbers = re.findall(r"\d+", "no digits here")
print(numbers)

if not numbers:
    print("Nothing found")
```

Результат:

```text
[]
Nothing found
```

## Шаблони, що можуть збігатися з порожнім рядком

Квантифікатори `*` чи `?` дозволяють шаблону збігтися з **нулем** символів. Тоді `findall()` повертає й такі порожні збіги:

```python
import re

print(re.findall(r"\d*", "a1b22"))
print(re.findall(r"\d+", "a1b22"))
```

Результат:

```text
['', '1', '', '22', '']
['1', '22']
```

З `\d*` рушій знаходить порожній збіг перед `a`, збіг `1`, порожній збіг перед `b`, збіг `22` і ще один порожній збіг у самому кінці рядка. Майже в кожній реальній задачі вам потрібен `+` («щонайменше один»).

## Скомпільовані шаблони: `Pattern.findall()`

Якщо шаблон використовується повторно, скомпілюйте його один раз через `re.compile()`. Скомпільований об'єкт має власний метод `findall()`, який додатково приймає `pos` і `endpos`, щоб обмежити пошук частиною рядка:

```python
import re

number = re.compile(r"\d+")
text = "10 20 30 40"

print(number.findall(text))
print(number.findall(text, 3, 8))
```

Результат:

```text
['10', '20', '30', '40']
['20', '30']
```

Другий виклик переглядає лише `text[3:8]`, тобто `"20 30"`.

> **Зверніть увагу:** функції рівня модуля (`re.findall()`, `re.search()` та інші) кешують нещодавно скомпільовані шаблони, тому в невеликих скриптах компіляція для швидкості не обов'язкова. Компілюйте, коли це робить код зрозумілішим, коли потрібні `pos`/`endpos` або коли один шаблон використовується в багатьох місцях.

## `findall()` чи `finditer()`

Обидві функції знаходять усі збіги, що не перекриваються. Відрізняються вони тим, що повертають:

| | `findall()` | `finditer()` |
|---|---|---|
| Повертає | `list` | ітератор |
| Елементи | рядки або кортежі рядків | об'єкти `Match` |
| Вплив груп | змінює тип елементів | жодного, завжди повний `Match` |
| Позиції збігів | недоступні | `start()`, `end()`, `span()` |
| Пам'ять | будує весь список одразу | видає по одному збігу |

```python
import re

s = "black, blue and brown"

print(re.findall(r"bl(\w+)", s))
for m in re.finditer(r"bl(\w+)", s):
    print(m.group(0), m.group(1), m.span())
```

Результат:

```text
['ack', 'ue']
black ack (0, 5)
blue ue (7, 11)
```

Обирайте `findall()`, коли потрібен лише знайдений текст. Обирайте `finditer()`, коли потрібні позиції, іменовані групи або коли вхідні дані дуже великі.

## Типові помилки

- **Група «лише для групування».** `(bl|br)\w+` повертає `['bl', 'bl', 'br']`, а не слова. Пишіть `(?:bl|br)\w+`.
- **Забутий сирий рядок.** У звичайному рядку `'\b'` — це символ *backspace*, а не межа слова, тож шаблон мовчки нічого не знаходить:

  ```python
  import re

  print(re.findall("\bcat\b", "cat"))  # []
  print(re.findall(r"\bcat\b", "cat"))  # ['cat']
  ```

  Інші послідовності, як-от `"\d"`, випадково працюють, але з Python 3.12 викликають `SyntaxWarning`. Завжди записуйте шаблони сирими рядками.
- **Очікувати `None`, коли збігів немає.** `findall()` повертає порожній список. Код на кшталт `if result is None:` ніколи не виконається.
- **`*` там, де мався на увазі `+`.** Шаблони, що можуть збігатися з порожнім рядком, заповнюють список елементами `''`.
- **Очікувати збігів, що перекриваються.** `findall()` ніколи не використовує символи повторно. Беріть перегляд уперед із групою, як показано вище.
- **Забути про кортежі.** Якщо груп дві або більше, кожен елемент — кортеж. Розпаковуйте його (`for key, value in pairs:`), а не працюйте з ним як із рядком.

## Підсумок

- `re.findall(pattern, string, flags=0)` повертає список усіх збігів, що не перекриваються, проходячи рядок зліва направо.
- Без груп — список повних збігів. Одна група — список її текстів. Кілька груп — список кортежів.
- Необов'язкові групи, що не збіглися, потрапляють у результат як `''`.
- Незахоплювальні групи `(?:...)` групують, не змінюючи форму результату.
- Якщо збігів немає, результат — `[]`, а не `None`.
- Шаблони, що можуть збігатися з порожнім рядком, дають порожні елементи. Коли потрібен реальний вміст, віддавайте перевагу `+`, а не `*`.
- Беріть `finditer()`, коли потрібні позиції або об'єкти `Match`, і `Pattern.findall(string, pos, endpos)`, щоб шукати в частині рядка.

## Практика

### Вправа 1: Витягніть хештеги

Маючи `post = "Loving #Python and #regex! #100DaysOfCode"`, одним викликом `findall()` отримайте назви хештегів **без** знака `#`: `['Python', 'regex', '100DaysOfCode']`.

### Вправа 2: Ціни у словник

Перетворіть `"apple=1.25, pear=0.8, kiwi=2"` на словник `{'apple': 1.25, 'pear': 0.8, 'kiwi': 2.0}`. Використайте шаблон із двома групами й перетворіть ціни на `float`.

### Вправа 3: Порахуйте слово

Порахуйте, скільки разів у тексті нижче трапляється **слово** "the" без урахування регістру. "There" та "other" рахувати не можна.

```python
text = "The cat saw the dog. There was the other cat. THE END."
```

### Вправа 4: Входження, що перекриваються

`re.findall(r"ana", "bananarama")` повертає один збіг, хоча "ana" насправді трапляється двічі (з індексу 1 і з індексу 3). Напишіть шаблон, який знаходить **обидва** входження, і виведіть їхню кількість. Потім змініть розв'язок так, щоб він виводив початковий індекс кожного входження.

## Розв'язки

### Вправа 1

```python
import re

post = "Loving #Python and #regex! #100DaysOfCode"
tags = re.findall(r"#(\w+)", post)
print(tags)
```

Результат:

```text
['Python', 'regex', '100DaysOfCode']
```

`#` має бути частиною збігу, щоб знаходилися лише хештеги, але він лишається поза групою, тож у результат не потрапляє.

### Вправа 2

```python
import re

data = "apple=1.25, pear=0.8, kiwi=2"
prices = {name: float(price) for name, price in re.findall(r"(\w+)=([\d.]+)", data)}
print(prices)
```

Результат:

```text
{'apple': 1.25, 'pear': 0.8, 'kiwi': 2.0}
```

### Вправа 3

```python
import re

text = "The cat saw the dog. There was the other cat. THE END."
count = len(re.findall(r"\bthe\b", text, flags=re.IGNORECASE))
print(count)
```

Результат:

```text
4
```

Межі слова `\b` не дають шаблону збігтися всередині "There" та "other". Прапорець дозволяє врахувати також "The" і "THE".

### Вправа 4

```python
import re

s = "bananarama"

print(re.findall(r"ana", s))
print(len(re.findall(r"(?=ana)", s)))

starts = [m.start() for m in re.finditer(r"(?=ana)", s)]
print(starts)
```

Результат:

```text
['ana']
2
[1, 3]
```

Перегляд уперед `(?=ana)` збігається з *порожнім* рядком у кожній позиції, де починається "ana", і нічого не поглинає, тому друге входження не пропускається. `findall()` повертає для нього `['', '']`, і для підрахунку цього досить. Щоб отримати позиції, перейдіть на `finditer()` і скористайтеся `start()`.
