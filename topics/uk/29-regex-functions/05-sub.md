# sub()

`re.sub()` — це інструмент «знайти й замінити» модуля `re`. Він знаходить усі збіги шаблону й будує **новий рядок**, у якому ці збіги замінено. Заміною може бути фіксований текст, текст, що повторно використовує частини збігу через зворотні посилання, або результат написаної вами функції. Тому `sub()` — основна функція для очищення даних, переформатування дат, маскування секретів і перетворення тексту з одного формату в інший.

## Що ви дізнаєтесь

- Сигнатуру `re.sub()` і чому `count` та `flags` слід передавати як іменовані аргументи
- Як працює заміна «крайніх лівих збігів, що не перекриваються»
- Як повторно використати захоплений текст через `\1`, `\g<1>`, `\g<name>` і `\g<0>`
- Як обчислювати заміну функцією
- Які escape-послідовності мають особливе значення в рядку заміни
- Як `re.subn()` повідомляє кількість замін

## Сигнатура

```python
re.sub(pattern, repl, string, count=0, flags=0)
```

- `pattern` — регулярний вираз (сирий рядок або скомпільований `Pattern`).
- `repl` — заміна: рядок або функція, що отримує об'єкт `Match` і повертає рядок.
- `string` — вхідний текст.
- `count` — максимальна кількість замін. Значення за замовчуванням `0` означає «замінити всі збіги».
- `flags` — один прапорець або кілька, об'єднаних через `|`.

`sub()` повертає новий рядок. Рядки в Python незмінювані, тож оригінал ніколи не змінюється. Якщо шаблон зовсім не збігся, ви отримаєте рядок, що дорівнює початковому.

> **Зверніть увагу:** починаючи з Python 3.13, передавання `count` і `flags` як позиційних аргументів застаріло й викликає `DeprecationWarning`. У майбутній версії вони стануть суто іменованими. Завжди пишіть `count=...` і `flags=...`. У розділі про типові помилки показано, від якої помилки рятує це правило.

## Видалення символів: номер телефону без форматування

Наступний приклад перетворює `(212)-456-7890` на `2124567890`:

```python
import re

phone_no = "(212)-456-7890"
result = re.sub(r"\D", "", phone_no)

print(result)
```

Результат:

```text
2124567890
```

`\D` збігається з будь-яким одним символом, що **не** є цифрою. Заміна кожного такого символу порожнім рядком `""` його видаляє.

## Крайні ліві збіги, що не перекриваються

`sub()` проходить рядок зліва направо. Після заміни збігу пошук продовжується *після* нього, тож збіги ніколи не перекриваються, а замінений текст повторно не проглядається:

```python
import re

print(repr(re.sub(r"00", "", "00000")))
print(repr(re.sub(r"00", "", "000000")))
```

Результат:

```text
'0'
''
```

У `"00000"` (п'ять нулів) перші два нулі утворюють збіг, потім наступні два, а п'ятий нуль лишається на місці, бо пари для нього немає. У `"000000"` (шість нулів) три збіги поглинають усе, і результатом стає порожній рядок.

## Обмеження кількості замін через `count`

```python
import re

print(re.sub(r"\s+", "-", "a b  c   d", count=2))
```

Результат:

```text
a-b-c   d
```

Замінено лише дві перші групи пробілів. Решта рядка скопійована без змін.

## Зворотні посилання: повторне використання знайденого тексту

У `repl` можна посилатися на текст, захоплений групами шаблону:

| У `repl` | Вставляє |
|---|---|
| `\1` ... `\99` | текст групи 1 ... 99 |
| `\g<1>` | текст групи 1 (однозначна форма) |
| `\g<name>` | текст іменованої групи `name` |
| `\g<0>` | увесь збіг |

### Жирний текст Markdown у HTML

Шаблон нижче знаходить текст, оточений зірочками, як у синтаксисі Markdown `*bold*`, і обгортає його тегами `<b>...</b>`:

```python
import re

s = "Make the World a *Better Place*"
html = re.sub(r"\*(.*?)\*", r"<b>\1</b>", s)

print(html)
```

Результат:

```text
Make the World a <b>Better Place</b>
```

- `\*` — буквальна зірочка (екранована, бо `*` — квантифікатор).
- `(.*?)` захоплює текст між зірочками як групу 1. `?` робить квантифікатор **лінивим** (lazy), тож він зупиняється на *найближчій* закривній зірочці.
- У заміні `\1` повертає захоплений текст між тегами.

Лінивий квантифікатор стає важливим, щойно жирних фрагментів більше одного:

```python
import re

s = "a *b* and *c*"

print(re.sub(r"\*(.*)\*", r"<b>\1</b>", s))
print(re.sub(r"\*(.*?)\*", r"<b>\1</b>", s))
```

Результат:

```text
a <b>b* and *c</b>
a <b>b</b> and <b>c</b>
```

Жадібний (greedy) `.*` біжить до **останньої** зірочки й заковтує ` and ` в одну велику групу.

### Іменовані групи: переформатування дат

З іменованими групами заміна сама себе документує. Приклад перетворює дати ISO `YYYY-MM-DD` на європейський формат `DD.MM.YYYY`:

```python
import re

text = "Released 2024-03-15, patched 2024-04-01."
pattern = r"(?P<year>\d{4})-(?P<month>\d{2})-(?P<day>\d{2})"

print(re.sub(pattern, r"\g<day>.\g<month>.\g<year>", text))
```

Результат:

```text
Released 15.03.2024, patched 01.04.2024.
```

### `\g<0>` і неоднозначність `\g<1>0` проти `\10`

`\g<0>` вставляє весь збіг, що зручно для обгортання збігів:

```python
import re

print(re.sub(r"\d+", r"[\g<0>]", "Room 101, floor 3"))
```

Результат:

```text
Room [101], floor [3]
```

Якщо після посилання на групу має йти цифра, використовуйте форму `\g<...>`. `\10` означає «група 10», а не «група 1, а потім 0»:

```python
import re

print(re.sub(r"(\d)", r"\g<1>0", "1 2 3"))

try:
    re.sub(r"(\d)", r"\10", "1 2 3")
except re.error as e:
    print("Error:", e)
```

Результат:

```text
10 20 30
Error: invalid group reference 10 at position 1
```

## Функція як заміна

Коли заміна залежить від знайденого значення, передайте як `repl` **функцію**. `sub()` викликає її один раз для кожного збігу, передаючи об'єкт `Match`, і вставляє рядок, який вона повертає.

Наприклад, піднесемо до квадрата число в кожному елементі списку:

```python
import re


def square(match):
    num = int(match.group())
    return str(num * num)


items = ["A1", "A2", "A3", "B12"]
pattern = r"\d+"
new_items = [re.sub(pattern, square, s) for s in items]

print(new_items)
```

Результат:

```text
['A1', 'A4', 'A9', 'B144']
```

Як це працює:

1. `\d+` збігається з однією чи більше цифрами в кожному рядку.
2. Для кожного збігу `sub()` викликає `square()` з об'єктом `Match`.
3. `square()` перетворює знайдений текст на `int`, підносить до квадрата й повертає результат як `str`. Якщо повернути щось інше, ніж рядок, буде `TypeError`.

Функції ідеально підходять для пошуку значень у словнику. Ось маленький шаблонізатор: він заповнює заповнювачі `{name}` значеннями зі словника, а невідомі заповнювачі лишає як є:

```python
import re

template = "Hello, {name}! Your order {order_id} ships on {date}. {unknown}"
values = {"name": "Olena", "order_id": "A-17", "date": "Monday"}

result = re.sub(r"\{(\w+)\}", lambda m: values.get(m[1], m[0]), template)
print(result)
```

Результат:

```text
Hello, Olena! Your order A-17 ships on Monday. {unknown}
```

`m[1]` — назва заповнювача. Якщо її немає в словнику, `values.get()` повертає `m[0]`, тобто початковий текст `{unknown}`.

## Escape-послідовності в рядку заміни

**Рядок** заміни не копіюється буквально. Послідовності зі зворотною скісною рискою в ньому обробляються:

- `\n`, `\t` та інші стандартні послідовності стають відповідними символами.
- `\1`, `\g<name>` тощо — зворотні посилання.
- Невідома послідовність з ASCII-літерою, наприклад `\d`, — помилка.

```python
import re

print(re.sub(r";\s*", r"\n", "one; two; three"))

try:
    re.sub(r"x", r"\d", "x")
except re.error as e:
    print(type(e).__name__, "-", e)
```

Результат:

```text
one
two
three
PatternError - bad escape \d at position 0
```

З Python 3.13 клас винятку називається `re.PatternError`. Стара назва `re.error` лишилася як псевдонім, тож `except re.error` годиться для коду, який має працювати й на старіших версіях.

Якщо заміна має містити зворотні скісні риски буквально, наприклад шлях Windows, подвоюйте їх (`r"C:\\new"`) або, простіше, використайте функцію: те, що вона повертає, вставляється **як є**, без обробки escape-послідовностей:

```python
import re

print(re.sub(r"DIR", lambda m: r"C:\new\docs", "Saved to DIR"))
```

Результат:

```text
Saved to C:\new\docs
```

## `re.subn()`: замінити й порахувати

`re.subn()` приймає ті самі аргументи, що й `sub()`, але повертає кортеж `(new_string, number_of_replacements)`:

```python
import re

text, n = re.subn(r"\s+", " ", "too    many \t\t spaces   here")
print(repr(text))
print(n)
```

Результат:

```text
'too many spaces here'
3
```

## Порожні збіги

Шаблон, що може збігатися з порожнім рядком, виконує заміни й у порожніх позиціях. З Python 3.7 замінюється також порожній збіг одразу після непорожнього:

```python
import re

print(re.sub(r"x*", "-", "abxd"))
```

Результат:

```text
-a-b--d-
```

Читаємо зліва направо: порожній збіг перед `a`, перед `b`, збіг `x`, порожній збіг одразу після нього (перед `d`) і останній порожній збіг у кінці. Якщо треба замінювати лише справжні входження, пишіть `x+`.

## Коли `sub()` не потрібна

Для **фіксованого** фрагмента тексту `str.replace()` простіший і швидший: `"a-b-c".replace("-", "+")`. Беріть `re.sub()`, коли потрібні шаблони, нечутливість до регістру, зворотні посилання чи функція заміни.

Якщо ви будуєте шаблон із даних, введених користувачем, екрануйте їх через `re.escape()`, щоб символи на кшталт `.` чи `+` шукалися буквально:

```python
import re

word = "C++"
text = "I like C++ and c++."

print(re.sub(re.escape(word), "Python", text, flags=re.IGNORECASE))
```

Результат:

```text
I like Python and Python.
```

## Типові помилки

- **Передавати `flags` на місці `count`.** `re.IGNORECASE` — це ціле число `2`, тож виклик нижче означає «замінити не більше 2 збігів з урахуванням регістру». Python 3.13+ попереджає про це:

  ```python
  import re

  text = "Cat cat CAT cat cat"
  print(re.sub(r"cat", "dog", text, re.IGNORECASE))
  print(re.sub(r"cat", "dog", text, flags=re.IGNORECASE))
  ```

  Результат (`example.py` — це шлях до вашого скрипта):

  ```text
  example.py:4: DeprecationWarning: 'count' is passed as positional argument
    print(re.sub(r"cat", "dog", text, re.IGNORECASE))
  Cat dog CAT dog cat
  dog dog dog dog dog
  ```

- **Забутий сирий рядок у `repl`.** У звичайному рядку `"\1"` — це символ із кодом 1, а не зворотне посилання:

  ```python
  import re

  print(repr(re.sub(r"(\w+)", "<\1>", "hi")))
  print(repr(re.sub(r"(\w+)", r"<\1>", "hi")))
  ```

  Результат:

  ```text
  '<\x01>'
  '<hi>'
  ```

- **Жадібний `.*` між роздільниками.** `\*(.*)\*` захоплює все від першої до останньої зірочки. Використовуйте `.*?` або заперечний набір на кшталт `[^*]*`.
- **Очікувати, що `sub()` змінить рядок на місці.** Вона повертає новий рядок. Присвойте результат: `s = re.sub(...)`.
- **Повертати не рядок із функції заміни.** Числа перетворюйте через `str()`.
- **Писати `\10`, маючи на увазі «група 1, потім 0».** Використовуйте `\g<1>0`.

## Підсумок

- `re.sub(pattern, repl, string, count=0, flags=0)` повертає новий рядок із заміненими збігами. Якщо збігів немає, текст повертається без змін.
- Передавайте `count` і `flags` як іменовані аргументи. Позиційне використання застаріло з Python 3.13 і легко призводить до того, що прапорець сприймається як кількість.
- Збіги шукаються зліва направо й ніколи не перекриваються.
- У рядку заміни `\1`, `\g<1>`, `\g<name>` і `\g<0>` вставляють захоплений текст, а стандартні послідовності на кшталт `\n` обробляються.
- Функція як `repl` отримує кожен `Match` і повертає рядок заміни, який вставляється як є.
- `re.subn()` повертає `(new_string, count)`.
- Для фіксованого тексту використовуйте `str.replace()`, а для шаблонів із даних користувача — `re.escape()`.

## Практика

### Вправа 1: Нормалізуйте пробіли

Напишіть `normalize(text)`, яка замінює кожну послідовність пробільних символів (пробілів, табуляцій, переведень рядка) одним пробілом і прибирає пробіли з обох кінців. `normalize("  Hello,\t\tworld!\n  How   are you? ")` має повернути `"Hello, world! How are you?"`.

### Вправа 2: Американські дати у формат ISO

Перетворіть кожну дату у форматі `MM/DD/YYYY` на `YYYY-MM-DD` за допомогою іменованих груп і рядка заміни. Перевірте на `"Due 03/15/2024, paid 04/01/2024."`.

### Вправа 3: Цензура слів

Напишіть `censor(text, banned)`, яка замінює кожне заборонене слово зірочками тієї самої довжини, не зважаючи на регістр і враховуючи лише цілі слова. `censor("Darn it, DARN this darned heck!", ["darn", "heck"])` має повернути `"**** it, **** this darned ****!"`. Як заміну використайте функцію.

### Вправа 4: З camelCase у snake_case

Напишіть `to_snake(name)`, яка перетворює `"getHttpResponseCode"` на `"get_http_response_code"`. Потім за допомогою `re.subn()` виведіть ще й кількість вставлених підкреслень.

## Розв'язки

### Вправа 1

```python
import re


def normalize(text):
    return re.sub(r"\s+", " ", text).strip()


print(repr(normalize("  Hello,\t\tworld!\n  How   are you? ")))
```

Результат:

```text
'Hello, world! How are you?'
```

`\s+` перетворює кожну послідовність пробільних символів, зокрема й на краях, на один пробіл, а `strip()` прибирає ці крайні пробіли.

### Вправа 2

```python
import re

text = "Due 03/15/2024, paid 04/01/2024."
pattern = r"(?P<month>\d{2})/(?P<day>\d{2})/(?P<year>\d{4})"

print(re.sub(pattern, r"\g<year>-\g<month>-\g<day>", text))
```

Результат:

```text
Due 2024-03-15, paid 2024-04-01.
```

### Вправа 3

```python
import re


def censor(text, banned):
    pattern = r"\b(?:" + "|".join(map(re.escape, banned)) + r")\b"
    return re.sub(pattern, lambda m: "*" * len(m[0]), text, flags=re.IGNORECASE)


print(censor("Darn it, DARN this darned heck!", ["darn", "heck"]))
```

Результат:

```text
**** it, **** this darned ****!
```

Межі слова `\b` не дають зачепити `darned`. `re.escape()` захищає шаблон на випадок, якщо заборонене слово містить спеціальні символи. Лямбда повертає стільки зірочок, скільки символів у знайденому слові.

### Вправа 4

```python
import re


def to_snake(name):
    return re.subn(r"(?<!^)(?=[A-Z])", "_", name)


snake, inserted = to_snake("getHttpResponseCode")
print(snake.lower())
print(inserted)
```

Результат:

```text
get_http_response_code
3
```

Шаблон збігається з **порожньою** позицією, за якою йде велика літера (перегляд уперед) і яка не є самим початком рядка (негативний перегляд назад). Вставлення `_` у кожну таку позицію з подальшим переведенням у нижній регістр дає snake_case. `subn()` рахує три вставлення.
