# match()

`re.match()` перевіряє, чи **починається** рядок із тексту, що відповідає шаблону. Далі в рядок вона ніколи не заглядає, тому швидко й точно відповідає на запитання на кшталт «чи починається цей рядок із дати?» або «чи є перший токен числом?». Водночас саме цю функцію найчастіше плутають із `search()` та `fullmatch()`, тож відмінностям тут приділено особливу увагу.

## Що ви дізнаєтесь

- Сигнатуру `re.match()` і те, що вона повертає
- Чому `match()` прив'язана до початку рядка, але не до кінця
- Чим `match()` відрізняється від `search()` і `fullmatch()`
- Чому `re.MULTILINE` не змушує `match()` перевіряти кожен рядок тексту
- Як працює `Pattern.match(string, pos)` і чому `^` там поводиться інакше
- Як за допомогою збігу розділити рядок на розібраний префікс і решту

## Сигнатура

```python
re.match(pattern, string, flags=0)
```

- `pattern` — регулярний вираз. Окрім сирого рядка, це може бути скомпільований об'єкт `Pattern`.
- `string` — вхідний рядок.
- `flags` — необов'язковий параметр: один прапорець або кілька, об'єднаних через `|`.

Якщо початок `string` відповідає `pattern`, функція повертає об'єкт `Match`. Інакше вона повертає `None`.

## Перший приклад

Наступний код перевіряє, чи починається рядок із цифри:

```python
import re

s = "3 pieces cost 5 USD"
match = re.match(r"\d", s)

if match is not None:
    print(f"The string starts with a digit {match.group()}")
```

Результат:

```text
The string starts with a digit 3
```

> **Зверніть увагу:** інколи цей шаблон записують як `\d{1}`. Квантифікатор `{1}` означає «рівно один раз», а саме це вже й означає звичайне `\d`, тож він лише додає шуму.

У рядку є ще й `5`, але це не має значення: `match()` дивиться лише на позицію 0. Якби рядок починався з літери, результатом було б `None`, навіть якщо цифри трапляються далі:

```python
import re

print(re.match(r"\d", "Price: 5 USD"))
```

Результат:

```text
None
```

## Прив'язка до початку, але не до кінця

`match()` вимагає, щоб збіг *починався* з першого символу, але закінчуватися він може будь-де. Усе, що йде далі, просто ігнорується:

```python
import re

m = re.match(r"\d+", "42 apples")
print(m)
print(m.group())
```

Результат:

```text
<re.Match object; span=(0, 2), match='42'>
42
```

Саме це потрібно, коли ви розбираєте префікс, і саме цього **не** потрібно, коли ви перевіряєте значення цілком. `re.match(r"\d+", "123abc")` теж спрацює. Щоб переконатися, що весь рядок є числом, використовуйте `re.fullmatch(r"\d+", s)`.

## Розбір початку рядка за допомогою збігу

Оскільки збіг починається з позиції 0, `m.end()` показує, де закінчується розібраний префікс. Решта рядка — це `s[m.end():]`:

```python
import re

line = "2024-03-15 Server started on port 8080"
m = re.match(r"(\d{4})-(\d{2})-(\d{2})\s+", line)

if m:
    year, month, day = map(int, m.groups())
    message = line[m.end():]
    print(year, month, day)
    print(message)
```

Результат:

```text
2024 3 15
Server started on port 8080
```

`\s+` наприкінці шаблону поглинає пробіли після дати, тож повідомлення починається без зайвих символів.

> **Порада:** з Python 3.8 оператор «морж» (walrus) дозволяє знайти збіг і перевірити його в одному рядку: `if m := re.match(pattern, line):`. Змінна `m` тоді доступна всередині блоку `if`.

## `match()`, `search()` і `fullmatch()`

Три функції приймають однакові аргументи й повертають `Match` або `None`. Відрізняються вони лише тим, де збіг може починатися й закінчуватися:

| Функція | Збіг має починатися | Збіг має закінчуватися | На яке запитання відповідає |
|---|---|---|---|
| `re.match()` | на початку рядка | будь-де | «Чи починається рядок із ...?» |
| `re.search()` | будь-де | будь-де | «Чи містить рядок ...?» |
| `re.fullmatch()` | на початку рядка | у кінці рядка | «Чи є рядок саме ...?» |

```python
import re

s = "Python 3.14"

print(re.match(r"\d+", s))
print(re.search(r"\d+", s))
print(re.match(r"Python", s))
print(re.fullmatch(r"Python", s))
print(re.fullmatch(r"Python \d+\.\d+", s))
```

Результат:

```text
None
<re.Match object; span=(7, 8), match='3'>
<re.Match object; span=(0, 6), match='Python'>
None
<re.Match object; span=(0, 11), match='Python 3.14'>
```

- `match(r"\d+", s)` не спрацьовує, бо рядок починається з `P`, а не з цифри.
- `search(r"\d+", s)` проглядає рядок далі й знаходить `3`.
- `match(r"Python", s)` спрацьовує на префіксі, а `fullmatch(r"Python", s)` — ні, бо лишається `" 3.14"`.

`re.match(p, s)` поводиться як `re.search(r"\A(?:" + p + ")", s)`: це пошук, якому дозволено починатися лише з початку рядка.

## `match()` не зважає на початки рядків навіть із `re.MULTILINE`

Прапорець `re.MULTILINE` змушує `^` збігатися на початку **кожного рядка** тексту. На `match()` він не впливає: вона завжди пробує лише початок усього рядка:

```python
import re

text = "first line\nX marks the spot"

print(re.match(r"X", text, re.MULTILINE))
print(re.search(r"^X", text, re.MULTILINE))
```

Результат:

```text
None
<re.Match object; span=(11, 12), match='X'>
```

Щоб знайти щось на початку будь-якого рядка тексту, використовуйте `search()` або `findall()` з `^` і `re.MULTILINE`.

## `Pattern.match()` і аргумент `pos`

Скомпільований шаблон має метод `match()` з необов'язковими аргументами `pos` і `endpos`. З `pos` збіг має починатися з указаного індексу, а не з 0:

```python
import re

number = re.compile(r"\d+")

print(number.match("ab12"))
print(number.match("ab12", 2))
```

Результат:

```text
None
<re.Match object; span=(2, 4), match='12'>
```

Тут є одна тонка пастка. `pos` — це **не** те саме, що зріз рядка. Якір `^` і далі означає «справжній початок рядка», тому шаблон, що починається з `^`, не може збігтися з `pos=2`:

```python
import re

anchored = re.compile(r"^\d+")

print(anchored.match("ab12", 2))
print(anchored.match("ab12"[2:]))
```

Результат:

```text
None
<re.Match object; span=(0, 2), match='12'>
```

Зріз `"ab12"[2:]` створює новий рядок `"12"`, у якому `^` стоїть на позиції 0. З `pos=2` рядок лишається `"ab12"`, і позиція 2 не є його початком.

## Типові помилки

- **Очікувати, що `match()` шукає по всьому рядку.** `re.match(r"\d+", "Price: 5")` повертає `None`. Щоб знайти шаблон будь-де, використовуйте `search()`.
- **Перевіряти введені дані через `match()`.** Вона приймає будь-який рядок, що лише *починається* з коректного значення: `re.match(r"\d+", "123abc")` спрацьовує. Використовуйте `fullmatch()`.
- **Викликати `.group()` на `None`.** Завжди спершу перевіряйте результат або використовуйте оператор «морж»:

  ```python
  import re

  for s in ["42 apples", "apples"]:
      if m := re.match(r"\d+", s):
          print(s, "->", int(m.group()))
      else:
          print(s, "-> no leading number")
  ```

  Результат:

  ```text
  42 apples -> 42
  apples -> no leading number
  ```

- **Очікувати, що `re.MULTILINE` змусить `match()` перевіряти кожен рядок тексту.** Не змусить. Використовуйте `search()`/`findall()` з `^`.
- **Сприймати `pos` як зріз.** `^` і далі стосується справжнього початку рядка.

## Підсумок

- `re.match(pattern, string, flags=0)` повертає `Match`, якщо шаблон збігається на **початку** рядка, інакше — `None`.
- Збіг має починатися з позиції 0, але закінчуватися може будь-де. Решта рядка ігнорується.
- `match()` — щоб перевірити чи розібрати префікс, `search()` — щоб знайти шаблон будь-де, `fullmatch()` — щоб перевірити весь рядок.
- `m.end()` показує, де закінчується розібраний префікс, тож `s[m.end():]` — це решта.
- `re.MULTILINE` впливає на `^` і `$`, але не на саму `match()`.
- `Pattern.match(string, pos)` починає з `pos`, але `^` і далі означає справжній початок рядка.

## Практика

### Вправа 1: Рядки-коментарі

Напишіть `is_comment(line)`, яка повертає `True`, якщо рядок коду Python є коментарем: необов'язкові пробіли чи табуляції, а потім `#`. Перевірте її на `"# note"`, `"    # indented note"`, `"x = 1  # trailing"` та `""`.

### Вправа 2: Рядок HTTP-запиту

Перший рядок HTTP-запиту виглядає як `"GET /index.html HTTP/1.1"`. За допомогою `re.match()` та іменованих груп витягніть метод (великі літери) і шлях (символи, що не є пробілами). Виведіть їх для `"GET /index.html HTTP/1.1"` і `"POST /api/users?id=7 HTTP/2"`, а для `"hello world"` виведіть `invalid`.

### Вправа 3: Префікси версій

Зі списку нижче залиште лише рядки, що **починаються** з версії на кшталт `v1.2` (`v`, число, крапка й число), і зберіть кортежі цілих чисел `(major, minor)`. Очікуваний результат: `[(1, 2), (10, 0), (3, 7)]`.

```python
items = ["v1.2 release", "v10.0.3 beta", "release v2.0", "v3", "v3.7-rc1"]
```

### Вправа 4: Передбачте результат

Передбачте, що виведе кожен рядок, потім запустіть код і поясніть результати.

```python
import re

p = re.compile(r"\d+")
q = re.compile(r"^\d+")
s = "abc 42"

print(p.match(s))
print(p.match(s, 4))
print(q.match(s, 4))
print(q.search(s))
print(re.search(r"\d+", s))
```

## Розв'язки

### Вправа 1

```python
import re


def is_comment(line):
    return re.match(r"[ \t]*#", line) is not None


for line in ["# note", "    # indented note", "x = 1  # trailing", ""]:
    print(repr(line), is_comment(line))
```

Результат:

```text
'# note' True
'    # indented note' True
'x = 1  # trailing' False
'' False
```

`[ \t]*` дозволяє будь-яку кількість початкових пробілів чи табуляцій, зокрема й нуль. Рядок із коментарем у кінці починається з `x`, тож рядком-коментарем він не є.

### Вправа 2

```python
import re

REQUEST_LINE = re.compile(r"(?P<method>[A-Z]+) (?P<path>\S+)")

for line in ["GET /index.html HTTP/1.1", "POST /api/users?id=7 HTTP/2", "hello world"]:
    if m := REQUEST_LINE.match(line):
        print(m["method"], m["path"])
    else:
        print("invalid")
```

Результат:

```text
GET /index.html
POST /api/users?id=7
invalid
```

`"hello world"` не проходить, бо `[A-Z]+` потребує щонайменше однієї великої літери на позиції 0.

### Вправа 3

```python
import re

items = ["v1.2 release", "v10.0.3 beta", "release v2.0", "v3", "v3.7-rc1"]

versions = []
for item in items:
    if m := re.match(r"v(\d+)\.(\d+)", item):
        versions.append((int(m[1]), int(m[2])))

print(versions)
```

Результат:

```text
[(1, 2), (10, 0), (3, 7)]
```

`"release v2.0"` містить версію, але не на початку. У `"v3"` немає частини `.minor`.

### Вправа 4

Результат:

```text
None
<re.Match object; span=(4, 6), match='42'>
None
None
<re.Match object; span=(4, 6), match='42'>
```

- `p.match(s)`: рядок починається з `a`, тож на позиції 0 збігу немає.
- `p.match(s, 4)`: збіг має починатися з індексу 4, де й починається `42`.
- `q.match(s, 4)`: `^` і далі означає справжній початок `"abc 42"`, а індекс 4 ним не є.
- `q.search(s)`: `search()` може пробувати кожну позицію, але `^` збігається лише на 0, де цифри немає.
- `re.search(r"\d+", s)`: без якоря пошук знаходить `42`.
