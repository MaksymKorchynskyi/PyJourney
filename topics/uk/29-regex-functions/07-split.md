# split()

`re.split()` розрізає рядок на частини в кожному місці, де збігається регулярний вираз. Вбудований `str.split()` уміє розбивати лише за одним фіксованим роздільником, але реальні дані складніші: коми *або* крапки з комою, довільна кількість пробілів, «and» у будь-якому регістрі. Коли роздільником є шаблон, усе це обробляється одним викликом.

## Що ви дізнаєтесь

- Сигнатуру `re.split()` і чому `maxsplit` та `flags` слід передавати як іменовані аргументи
- Як розбивати рядок за кількома різними роздільниками або роздільниками змінної довжини
- Як `maxsplit` обмежує кількість розбиттів
- Як групи захоплення додають роздільники в результат і як цього уникнути
- Звідки в результаті беруться порожні рядки і як їх прибрати
- Чим `re.split()` відрізняється від `str.split()`

## Сигнатура

```python
re.split(pattern, string, maxsplit=0, flags=0)
```

- `pattern` — регулярний вираз. Кожен його збіг вважається роздільником.
- `string` — текст, який розбиваємо.
- `maxsplit` — максимальна кількість розбиттів. Значення за замовчуванням `0` означає «розбивати на кожному збігу».
- `flags` — один прапорець або кілька, об'єднаних через `|`.

Функція повертає **список рядків** — частин тексту між роздільниками. Якщо шаблон зовсім не збігся, у списку буде єдиний елемент — увесь рядок.

> **Зверніть увагу:** з Python 3.13 передавання `maxsplit` і `flags` як позиційних аргументів застаріло й викликає `DeprecationWarning`. Пишіть `maxsplit=2` і `flags=re.IGNORECASE`.

## Розбиття за кількома роздільниками

`str.split()` приймає лише один буквальний роздільник. Символьний набір дозволяє `re.split()` приймати будь-який із кількох роздільників у будь-якій кількості:

```python
import re

print(re.split(r"[,;\s]+", "a, b;c  d"))
```

Результат:

```text
['a', 'b', 'c', 'd']
```

`[,;\s]+` означає «один або більше символів, кожен з яких — кома, крапка з комою або пробільний символ». Тож `", "`, `";"` і `"  "` однаково працюють як роздільники.

Поширений варіант — розбити речення на слова, вважаючи роздільником кожну послідовність символів, що не належать до слова:

```python
import re

s = "A! B. C D"
words = re.split(r"\W+", s)
print(words)
```

Результат:

```text
['A', 'B', 'C', 'D']
```

`\W` — протилежність `\w`: будь-який символ, що не є літерою, цифрою чи підкресленням. `\W+` збігається з `"! "`, `". "` і `" "`.

## Обмеження кількості розбиттів: `maxsplit`

```python
import re

s = "A! B. C D"
print(re.split(r"\W+", s, maxsplit=2))
```

Результат:

```text
['A', 'B', 'C D']
```

Після двох розбиттів `split()` зупиняється й повертає **решту рядка** без змін як останній елемент. Тому в результаті три елементи, і останній із них — `"C D"`.

`maxsplit` — це верхня межа. Якщо роздільників у рядку менше, частин теж буде менше. Типове застосування — відокремити «голову» від решти, наприклад команду від її аргументів:

```python
import re

command, rest = re.split(r"\s+", "copy   file.txt   backup/", maxsplit=1)
print(command)
print(rest)
```

Результат:

```text
copy
file.txt   backup/
```

## Групи захоплення зберігають роздільники

Якщо шаблон містить **групи захоплення**, текст кожної групи вставляється в результат між частинами. Це корисно, коли роздільники несуть інформацію:

```python
import re

s = "A! B. C D"
print(re.split(r"(\W+)", s, maxsplit=2))
```

Результат:

```text
['A', '! ', 'B', '. ', 'C D']
```

Практичний приклад — розбити формулу на токени, зберігши оператори:

```python
import re

print(re.split(r"\s*([+\-*/])\s*", "12 + 3*4 - 5"))
```

Результат:

```text
['12', '+', '3', '*', '4', '-', '5']
```

Пробіли навколо операторів лежать поза групою, тож відкидаються, а сам оператор зберігається.

### Кілька груп і групи, що не збіглися

Якщо груп більше однієї, після кожного роздільника вставляється текст **кожної** групи. Група, що не брала участі у збігу, додає `None`:

```python
import re

print(re.split(r"(,)|(;)", "a,b;c"))
```

Результат:

```text
['a', ',', None, 'b', None, ';', 'c']
```

### Коли дужки потрібні лише для групування

Якщо згрупувати альтернативи звичайними дужками, роздільники випадково потраплять у результат. Використовуйте незахоплювальну групу `(?:...)`:

```python
import re

s = "cats and dogs or birds"

print(re.split(r"\s+(and|or)\s+", s))
print(re.split(r"\s+(?:and|or)\s+", s))
```

Результат:

```text
['cats', 'and', 'dogs', 'or', 'birds']
['cats', 'dogs', 'birds']
```

## Порожні рядки на краях

Якщо роздільник збігається **на самому початку** рядка, першим елементом результату буде порожній рядок. Те саме відбувається в кінці. Групи захоплення тут ні до чого: просто перед першим роздільником (або після останнього) немає тексту.

```python
import re

print(re.split(r"\W+", "...A! B. C D"))
print(re.split(r"\W+", "A! B. C D..."))
```

Результат:

```text
['', 'A', 'B', 'C', 'D']
['A', 'B', 'C', 'D', '']
```

Так результат лишається передбачуваним: частини завжди чергуються як «текст, роздільник, текст, ...». З групою захоплення цю структуру видно безпосередньо:

```python
import re

print(re.split(r"(\W+)", "...words..."))
```

Результат:

```text
['', '...', 'words', '...', '']
```

Щоб прибрати порожні рядки, відфільтруйте список. `filter(None, ...)` залишає лише істинні елементи:

```python
import re

parts = re.split(r"\W+", "...A! B. C D...")
print(parts)
print([p for p in parts if p])
print(list(filter(None, parts)))
```

Результат:

```text
['', 'A', 'B', 'C', 'D', '']
['A', 'B', 'C', 'D']
['A', 'B', 'C', 'D']
```

## Розбиття за порожнім збігом

З Python 3.7 роздільником може бути шаблон, що збігається з порожнім рядком. Перегляд уперед збігається з *позицією* перед чимось, нічого не поглинаючи, тож ідеально підходить для розбиття імен у стилі camelCase:

```python
import re

print(re.split(r"(?=[A-Z])", "HelloWorldFoo"))
```

Результат:

```text
['', 'Hello', 'World', 'Foo']
```

Перший елемент порожній, бо саме на позиції 0, перед `H`, є порожній збіг. Аналогічно перегляд назад дозволяє розбити текст на речення після розділового знака, залишивши знак у своєму реченні:

```python
import re

print(re.split(r"(?<=[.!?])\s+", "Hi there. How are you? Fine!"))
```

Результат:

```text
['Hi there.', 'How are you?', 'Fine!']
```

## `re.split()` чи `str.split()`

Ці методи по-різному поводяться з пробілами на краях:

```python
import re

s = "  alpha   beta  "

print(s.split())
print(re.split(r"\s+", s))
```

Результат:

```text
['alpha', 'beta']
['', 'alpha', 'beta', '']
```

`str.split()` **без аргументів** має особливу логіку: ігнорує пробіли на початку й у кінці та ніколи не повертає порожніх рядків. У `re.split()` такого правила немає, тому краї дають `''`. Якщо треба просто розбити рядок за пробілами, простіше взяти `str.split()`. `re.split()` потрібен, коли роздільник — справжній шаблон.

## Прапорці

```python
import re

print(re.split(r"\s+and\s+", "salt AND pepper and oil", flags=re.IGNORECASE))
```

Результат:

```text
['salt', 'pepper', 'oil']
```

## Типові помилки

- **Передавати `flags` на місці `maxsplit`.** `re.IGNORECASE` дорівнює `2`, тож виклик нижче означає «не більше 2 розбиттів з урахуванням регістру», і розбиття не відбувається взагалі. Python 3.13+ попереджає про це:

  ```python
  import re

  print(re.split(r"x", "aXbXc", re.IGNORECASE))
  print(re.split(r"x", "aXbXc", flags=re.IGNORECASE))
  ```

  Результат (`example.py` — це шлях до вашого скрипта):

  ```text
  example.py:3: DeprecationWarning: 'maxsplit' is passed as positional argument
    print(re.split(r"x", "aXbXc", re.IGNORECASE))
  ['aXbXc']
  ['a', 'b', 'c']
  ```

- **Несподівані роздільники в результаті.** Будь-яка група захоплення додає свій текст до списку. Для простого групування використовуйте `(?:...)`.
- **Дивуватися порожнім рядкам.** Роздільники на початку чи в кінці або шаблон на кшталт `[,;]` (без `+`) між двома сусідніми роздільниками дають `''`. Додавайте `+` і фільтруйте результат.
- **Використовувати `re.split()` для простого фіксованого роздільника.** `"a,b,c".split(",")` зрозуміліший і швидший.
- **Вважати `maxsplit` кількістю частин.** Це кількість *розбиттів*. `maxsplit=2` дає до трьох частин (більше, якщо в шаблоні є групи).

## Підсумок

- `re.split(pattern, string, maxsplit=0, flags=0)` повертає список частин між збігами шаблону.
- Символьний набір із `+`, наприклад `[,;\s]+`, одразу обробляє кілька різних і повторюваних роздільників.
- `maxsplit` обмежує кількість розбиттів, а решта рядка стає останнім елементом. Передавайте його як іменований аргумент.
- Групи захоплення вставляють у результат текст роздільника, а групи без збігу — `None`. Щоб цього уникнути, використовуйте `(?:...)`.
- Роздільник на початку чи в кінці дає порожній рядок. Фільтруйте через `[p for p in parts if p]`.
- Перегляд уперед і назад дозволяє розбивати рядок у позиціях, не видаляючи жодного символу.
- `str.split()` без аргументів ігнорує пробіли на краях, а `re.split()` — ні.

### Вправа 2: Речення

Розбийте `"Regex is powerful. Is it hard? Not really! Practice helps."` на речення, залишивши розділовий знак у кінці кожного речення.

### Вправа 3: Токени формули

Напишіть `tokenize(expr)`, яка розбиває арифметичний вираз на числа, оператори й дужки, ігноруючи пробіли. `tokenize("(12 + 3) * 4-5")` має повернути `['(', '12', '+', '3', ')', '*', '4', '-', '5']`.

### Вправа 4: Налаштування у словник

Перетворіть `"host = localhost; port=8080 ;debug= true;"` на `{'host': 'localhost', 'port': '8080', 'debug': 'true'}`. Спершу розбийте рядок на записи, а потім кожен запис — на ключ і значення з `maxsplit=1`.

## Розв'язки

### Вправа 1

```python
import re

raw = " python, regex;  tips ,,  tutorial ;"
tags = [t for t in re.split(r"[,;\s]+", raw) if t]
print(tags)
```

Результат:

```text
['python', 'regex', 'tips', 'tutorial']
```

Роздільники на обох краях дають порожні рядки, які прибирає спискове включення.

### Вправа 2

```python
import re

text = "Regex is powerful. Is it hard? Not really! Practice helps."
print(re.split(r"(?<=[.!?])\s+", text))
```

Результат:

```text
['Regex is powerful.', 'Is it hard?', 'Not really!', 'Practice helps.']
```

Перегляд назад `(?<=[.!?])` вимагає розділового знака перед пробілом, але не поглинає його, тож знак лишається у своєму реченні. Після останньої `.` пробілу немає, тому порожнього рядка в кінці не з'являється.

### Вправа 3

```python
import re


def tokenize(expr):
    parts = re.split(r"\s*([-+*/()])\s*", expr)
    return [p for p in parts if p]


print(tokenize("(12 + 3) * 4-5"))
```

Результат:

```text
['(', '12', '+', '3', ')', '*', '4', '-', '5']
```

Група захоплення зберігає оператори й дужки. Сусідні роздільники, як-от `)` і одразу `*`, дають між собою порожні рядки, які відфільтровуються. У наборі `-` стоїть першим, щоб бути буквальним мінусом, а не діапазоном.

### Вправа 4

```python
import re

raw = "host = localhost; port=8080 ;debug= true;"

settings = {}
for entry in re.split(r"\s*;\s*", raw):
    if not entry:
        continue
    key, value = re.split(r"\s*=\s*", entry, maxsplit=1)
    settings[key.strip()] = value.strip()

print(settings)
```

Результат:

```text
{'host': 'localhost', 'port': '8080', 'debug': 'true'}
```

`maxsplit=1` гарантує рівно дві частини на запис, навіть якщо саме значення містить `=`.
