# Перетворення float на int

Перетворити float, наприклад `20.3`, на ціле число означає вирішити, що робити з дробовою частиною: має `20.3` стати `20` чи `21`, а що робити з `-20.3`? Python пропонує кілька способів перетворення, і **для від'ємних чисел вони дають різні відповіді**. Неправильний вибір — класичне джерело помилок «на одиницю».

## Що ви дізнаєтесь

- Як `int()` і `math.trunc()` відкидають дробову частину (у бік нуля)
- Як `math.floor()` округлює вниз, а `math.ceil()` — угору
- Чому вибір має значення для від'ємних чисел
- Чим цілочисельне ділення `//` відрізняється від `math.floor()` за типом результату
- Які перетворення неможливі (`inf`, `nan`, рядки з дробом) і як це обробити
- Як похибка рухомої коми разом із відкиданням дробової частини дає несподівані результати

## Що втрачається під час перетворення

`int` не має дробової частини, тому під час перетворення float на кшталт `20.3` на ціле число `.3` відкидається. Ви вирішуєте лише те, *яке* з сусідніх цілих чисел отримаєте. Якщо float не має дробової частини, нічого не втрачається взагалі. Метод `float.is_integer()` підкаже, який це випадок:

```python
price = 20.3
print(int(price))

whole = 20.0
print(whole.is_integer(), int(whole))
print(price.is_integer())
```

Результат:

```text
20
True 20
False
```

Python дає чотири способи вибрати ціле число:

- **відкидання дробової частини** (truncation): `int(x)` або `math.trunc(x)`, у бік нуля;
- **округлення вниз** (floor): `math.floor(x)`, найбільше ціле `<= x` (у бік мінус нескінченності);
- **округлення вгору** (ceiling): `math.ceil(x)`, найменше ціле `>= x` (у бік плюс нескінченності);
- **округлення до найближчого**: `round(x)` (докладно — в темі «Округлення»).

## Відкидання дробової частини: math.trunc() та int()

`math.trunc(x)` повертає цілу частину `x`. Функція просто ігнорує все, що стоїть після десяткової крапки:

```python
from math import trunc

print(trunc(12.2))
print(trunc(12.5))
print(trunc(12.7))
print(trunc(-12.7))
```

Результат:

```text
12
12
12
-12
```

Конструктор `int()` робить із float рівно те саме:

```python
print(int(12.2))
print(int(12.5))
print(int(12.7))
print(int(-12.7))
```

Результат:

```text
12
12
12
-12
```

Відкидання дробової частини завжди рухається **в бік нуля**: додатні числа зменшуються, від'ємні — збільшуються. Зверніть увагу: навіть `12.7` стає `12`. `int()` не округлює.

## Округлення вниз: math.floor()

`math.floor(x)` повертає найбільше ціле число, менше або рівне `x`. Інакше кажучи, вона завжди рухається числовою прямою **вниз**:

```python
from math import floor

print(floor(12.2))
print(floor(12.5))
print(floor(12.7))
print(type(floor(12.7)))
```

Результат:

```text
12
12
12
<class 'int'>
```

Для додатних чисел `floor()` і `trunc()` збігаються. Для від'ємних — ні:

```python
from math import floor, trunc

print(floor(-12.7))
print(trunc(-12.7))
```

Результат:

```text
-13
-12
```

На числовій прямій `floor()` рухається ліворуч, а `trunc()` — до нуля:

```text
          floor(-12.7)       trunc(-12.7)
               |                  |
     ---------(-13)------x-------(-12)---------------- 0
                       -12.7
                  <- floor    trunc ->
```

## Округлення вгору: math.ceil()

`math.ceil(x)` повертає найменше ціле число, більше або рівне `x`. Вона завжди рухається **вгору**:

```python
from math import ceil

print(ceil(12.2))
print(ceil(12.7))
print(ceil(12.0))
print(ceil(-12.7))
```

Результат:

```text
13
13
12
-12
```

`ceil(12.0)` дорівнює `12`, бо `12` уже є цілим числом, «більшим або рівним» значенню. Для `-12.7` рух угору означає рух до нуля, тож результат — `-12`.

```text
     0 ----------------(12)-------x-------(13)---------
                         |       12.7       |
                  floor(12.7) = 12     ceil(12.7) = 13
                  trunc(12.7) = 12
```

## Усі перетворення поруч

```python
import math

print(f"{'x':>6} {'int':>5} {'floor':>6} {'ceil':>5} {'round':>6}")
for x in [12.2, 12.5, 12.7, -12.2, -12.5, -12.7]:
    print(f"{x:>6} {int(x):>5} {math.floor(x):>6} {math.ceil(x):>5} {round(x):>6}")
```

Результат:

```text
     x   int  floor  ceil  round
  12.2    12     12    13     12
  12.5    12     12    13     12
  12.7    12     12    13     13
 -12.2   -12    -13   -12    -12
 -12.5   -12    -13   -12    -12
 -12.7   -12    -13   -12    -13
```

| Функція | Напрямок | Типове застосування |
|---|---|---|
| `int(x)`, `math.trunc(x)` | у бік нуля | «просто відкинути дріб», напр. цілі секунди тривалості |
| `math.floor(x)` | у бік мінус нескінченності | інтервали, клітинки сітки, «скільки повних одиниць уміщається» |
| `math.ceil(x)` | у бік плюс нескінченності | «скільки контейнерів потрібно»: сторінок, коробок, автобусів |
| `round(x)` | до найближчого цілого (половини — до парного) | відображення чи наближення виміряного значення |

Зверніть увагу: `round(12.5)` дорівнює `12`, а не `13`. Python округлює рівновіддалені значення до найближчого *парного* цілого. Чому так, пояснено в темі «Округлення».

## Цілочисельне ділення й тип результату

Оператор цілочисельного ділення `//` округлює вниз, як `math.floor()`, але **зберігає тип float**, якщо один з операндів — float. `math.floor()`, `math.ceil()` і `math.trunc()` завжди повертають `int`:

```python
import math

print(12.7 // 1)          # цілочисельне ділення зберігає тип float
print(math.floor(12.7))   # math.floor повертає int
print(int(-7 / 2))        # звичайне ділення, потім відкидання дробу
print(-7 // 2)            # ділення з округленням униз
```

Результат:

```text
12.0
12
-3
-4
```

Останні два рядки — поширена пастка під час перенесення коду з C чи Java, де цілочисельне ділення відкидає дробову частину. У Python `//` округлює вниз.

### Ділення з округленням угору без float

Типове завдання: «скільки сторінок потрібно для 101 елемента, якщо на сторінці 10?» `math.ceil(items / per_page)` працює, але проходить через float. Лише з цілими числами можна двічі змінити знак навколо цілочисельного ділення:

```python
import math

items, per_page = 101, 10
print(math.ceil(items / per_page))
print(-(-items // per_page))   # ділення з округленням угору лише на цілих
```

Результат:

```text
11
11
```

`-items // per_page` округлює вниз від'ємне число, а це те саме, що округлити вгору додатне. Цілочисельна версія лишається точною навіть для чисел, більших за `2**53`, де float втрачає точність (див. вправу 2).

## Значення, які неможливо перетворити

`inf` і `nan` не мають цілого відповідника, тому перетворення генерує виняток. `math.floor()`, `math.ceil()` і `math.trunc()` поводяться так само:

```python
for text in ["inf", "nan"]:
    try:
        int(float(text))
    except (OverflowError, ValueError) as error:
        print(type(error).__name__, "-", error)
```

Результат:

```text
OverflowError - cannot convert float infinity to integer
ValueError - cannot convert float NaN to integer
```

`int()` приймає рядок, лише якщо той містить цілочисельний літерал. Рядок із десятковою крапкою спершу перетворіть на `float`:

```python
print(int(float("12.5")))

print(int("12.5"))
```

Результат (другий виклик падає, показано останній рядок traceback):

```text
12
ValueError: invalid literal for int() with base 10: '12.5'
```

Великі float перетворюються **точно**, і це показує, яке значення float зберігає насправді:

```python
print(int(1e20))
print(int(1e23))
```

Результат:

```text
100000000000000000000
99999999999999991611392
```

`1e23` неможливо точно зберегти у float, і `int()` показує найближче значення, яке можна представити.

## Не лише float: інші числові типи

Функції з `math` працюють з будь-яким типом, що реалізує відповідний спеціальний метод: `math.trunc()` викликає `__trunc__()`, `math.floor()` — `__floor__()`, а `math.ceil()` — `__ceil__()`. `Fraction` і `Decimal` реалізують їх усі, тож ви отримуєте точний результат без проміжного `float`:

```python
import math
from decimal import Decimal
from fractions import Fraction

print(math.floor(Fraction(-7, 2)))
print(math.ceil(Decimal("2.1")))
print(math.trunc(Decimal("-2.9")))
print(int(Fraction(-7, 2)))
```

Результат:

```text
-4
3
-2
-3
```

Для власних класів `int(obj)` викликає `__int__()`, а за його відсутності — `__index__()`:

```python
class Money:
    def __init__(self, amount):
        self.amount = amount

    def __int__(self):
        return int(self.amount)


print(int(Money(19.99)))
```

Результат:

```text
19
```

> **Зверніть увагу:** у старіших версіях Python `int()` міг звертатися ще й до `__trunc__()`. Цю поведінку оголосили застарілою в Python 3.11 і прибрали в Python 3.14. Реалізуйте натомість `__int__()` або `__index__()`.

## Типові помилки

- **Використовувати `int()` там, де потрібен `floor()`.** Для від'ємних чисел `int(-0.5)` дорівнює `0`, а `math.floor(-0.5)` — `-1`. Це ламає розбиття на інтервали та обчислення клітинок сітки (див. вправу 3).
- **Очікувати, що `int()` округлює.** `int(12.7)` дорівнює `12`. Якщо потрібне найближче ціле, використовуйте `round()`.
- **Відкидати дробову частину результату з похибкою рухомої коми.** Значення, яке «мало б» бути цілим, може виявитися трохи меншим, і відкидання дробу «з'їдає» майже цілу одиницю:

  ```python
  percent = 0.29 * 100
  print(percent)
  print(int(percent))     # відкидання дробу «з'їдає» майже цілу одиницю
  print(round(percent))   # натомість округлюємо до найближчого
  ```

  Результат:

  ```text
  28.999999999999996
  28
  29
  ```

- **Очікувати, що `x // 1` поверне `int`.** З операндом float результат теж float, наприклад `12.0`. Використовуйте `math.floor(x)`.
- **Викликати `int()` для рядка з дробом.** `int("12.5")` генерує `ValueError`. Використовуйте `int(float(text))` або `Decimal(text)` для точних значень.
- **Забувати про `inf` і `nan`.** Дані з файлів чи обчислень можуть їх містити. Перед перетворенням перевіряйте `math.isfinite(x)`.

## Підсумок

- Перетворення float на int відкидає дробову частину. Якщо `x.is_integer()` дорівнює `True`, нічого не втрачається.
- `int(x)` і `math.trunc(x)` відкидають дробову частину, рухаючись у бік нуля.
- `math.floor(x)` округлює вниз (у бік мінус нескінченності), `math.ceil(x)` — вгору (у бік плюс нескінченності).
- Для додатних чисел `floor` і `trunc` збігаються. Для від'ємних вони відрізняються на одиницю.
- `math.floor/ceil/trunc` повертають `int`. `x // 1` повертає float, якщо `x` — float.
- `-(-a // b)` — точне ділення з округленням угору для цілих чисел.
- `inf` дає `OverflowError`, `nan` — `ValueError`, а `int("12.5")` — `ValueError`.

## Розв'язки

### Вправа 1

```python
import math

for x in [3.99, -3.99, 3.0, -0.5]:
    print(x, int(x), math.floor(x), math.ceil(x))
```

Результат:

```text
3.99 3 3 4
-3.99 -3 -4 -3
3.0 3 3 3
-0.5 0 -1 0
```

`3.0` уже ціле, тож усі три результати збігаються. Для від'ємних значень `int()` рухається вгору, до цілого, ближчого до нуля, а `floor()` — вниз.

### Вправа 2

```python
import math


def pages_needed(items, per_page):
    return -(-items // per_page)


for items in [0, 1, 10, 11, 101]:
    print(items, pages_needed(items, 10), math.ceil(items / 10))

huge = 10**20 + 1
print(pages_needed(huge, 1) == huge, math.ceil(huge / 1) == huge)
```

Результат:

```text
0 0 0
1 1 1
10 1 1
11 2 2
101 11 11
True False
```

Для звичайних розмірів обидва підходи збігаються. Для `10**20 + 1` ділення `huge / 1` дає float, який не може зберегти кінцеве `+ 1`, тож `math.ceil()` повертає неправильне число. Цілочисельне ділення точне для будь-якого розміру.

### Вправа 3

```python
import math

CELL_SIZE = 10


def cell_int(x):
    return int(x / CELL_SIZE)


def cell_floor(x):
    return math.floor(x / CELL_SIZE)


for x in [25.0, 5.0, -5.0, -15.0]:
    print(f"{x:>6}: int -> {cell_int(x):>2}, floor -> {cell_floor(x):>2}")
```

Результат:

```text
  25.0: int ->  2, floor ->  2
   5.0: int ->  0, floor ->  0
  -5.0: int ->  0, floor -> -1
 -15.0: int -> -1, floor -> -2
```

Правильна `math.floor()`. З `int()` і `5.0`, і `-5.0` потрапляють у клітинку `0`, тож вона мала б ширину 20 одиниць (`(-10, 10)`), а кожна від'ємна клітинка зсунулася б на одиницю.

### Вправа 4

```python
def to_cents_naive(price_text):
    return int(float(price_text) * 100)


def to_cents(price_text):
    return round(float(price_text) * 100)


for text in ["19.99", "0.29", "4.35", "10"]:
    print(text, to_cents_naive(text), to_cents(text))
```

Результат:

```text
19.99 1998 1999
0.29 28 29
4.35 434 435
10 1000 1000
```

`19.99 * 100` у float дорівнює `1998.9999999999998`, і `int()` відкидає дробову частину, отримуючи `1998`. `round()` вибирає найближче ціле, тобто саме ту кількість центів, яку мали на увазі. У фінансовому коді `Decimal(price_text) * 100` взагалі дає змогу обійтися без двійкових float (див. тему про Decimal).
