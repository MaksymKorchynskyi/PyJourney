# Цілочисельне ділення (floor division)

Оператор `//` ділить два числа й округлює результат **вниз** до цілого. Це природний інструмент, коли потрібно дізнатися, «скільки цілих разів одне вміщується в інше»: індекси списків, сторінки, групи значень, цифри числа. З від'ємними числами він поводиться інакше, ніж у C, Java чи JavaScript, тож варто точно розуміти, що означає «вниз».

## Що ви дізнаєтесь

- Чим `//` відрізняється від звичайного ділення `/` і як він працює в парі з `%`
- Що таке округлення числа вниз (floor), особливо для від'ємних чисел
- Чому `-10 // 3` дорівнює `-4`, а не `-3`, і чим цілочисельне ділення відрізняється від відкидання дробової частини
- Який тип повертає `//` для операндів `int`, `float`, `bool`, `Fraction` і `Decimal`
- Чому `a // b` надійніший за `math.floor(a / b)`
- Повсякденні застосування: середній індекс, цифри числа, сторінки, групування, округлення вниз до кратного

## Два види ділення

У Python є два оператори ділення:

- `/` — **звичайне ділення** (true division). Воно завжди повертає `float` разом із дробовою частиною.
- `//` — **цілочисельне ділення** (floor division). Воно повертає лише цілу частину частки, округлену вниз.

Остачу, що лишається, дає оператор `%`:

```python
print(101 / 4)
print(101 // 4)
print(101 % 4)
print(4 * (101 // 4) + 101 % 4 == 101)
```

Результат:

```text
25.25
25
1
True
```

Як у школі: 101 поділити на 4 — це 25 і 1 в остачі. Число, яке ділять (`101`), називається **діленим** (чисельником), а число, на яке ділять (`4`), — **дільником** (знаменником). У Python `//` і `%` завжди задовольняють таку тотожність для будь-якого діленого `N` і ненульового дільника `D`:

```text
N == D * (N // D) + (N % D)

101 == 4 * (101 // 4) + (101 % 4)
101 == 4 * 25         + 1
```

Оператор `//` іноді називають «div», а `%` — «mod». Ця тема присвячена `//`. Оператор `%` докладно розглянуто в темі «Остача від ділення (modulo)».

## Округлення вниз (floor)

Щоб зрозуміти `//`, спершу потрібне поняття **округлення вниз** (floor) дійсного числа: це найбільше ціле число, яке менше за дане число або дорівнює йому. Уявіть числову пряму: результат — найближче ціле число **ліворуч** (або саме число, якщо воно вже ціле).

```python
from math import floor

print(floor(3.4), floor(3.9), floor(3))
print(floor(-3.4), floor(-3.9), floor(-3))
```

Результат:

```text
3 3 3
-4 -4 -3
```

Для додатних чисел округлення вниз просто відкидає дробову частину. Для від'ємних — **ні**: `-3.4` лежить між `-4` і `-3`, а ціле число ліворуч від нього — це `-4`.

```text
   floor(-3.4)          floor(3.4)
       |                    |
  ----(-4)--x--(-3)----0----(3)--x--(4)----
          -3.4                  3.4
```

Цілочисельне ділення визначається через округлення вниз точної частки:

```text
N // D == floor(N / D)      (де N / D — точне математичне значення)
```

## Цілочисельне ділення з від'ємними числами

Доки частка додатна, `//` дає звичний зі школи результат. Якщо знаки різні, пам'ятайте, що результат округлюється **вниз**, тобто в бік мінус нескінченності:

```python
a = 10
b = 3
print(a // b)

a = -10
b = -3
print(a // b)

a = 10
b = -3
print(a // b)

a = -10
b = 3
print(a // b)
```

Результат:

```text
3
3
-4
-4
```

| a | b | a / b | a // b |
|---|---|---|---|
| 10 | 3 | 3.333... | 3 |
| -10 | -3 | 3.333... | 3 |
| 10 | -3 | -3.333... | -4 |
| -10 | 3 | -3.333... | -4 |

### Цілочисельне ділення — це не відкидання дробової частини

**Відкидання дробової частини** (truncation) зсуває значення **в бік нуля**. Цілочисельне ділення зсуває його **вниз**. Обидва способи збігаються, коли точна частка дорівнює нулю, додатна (або вже ціла), і відрізняються на одиницю, коли вона від'ємна й не ціла:

```python
import math

for a, b in [(10, 3), (-10, -3), (10, -3), (-10, 3)]:
    print(f"{a:>3} / {b:>2} = {a / b:>7.4f}   "
          f"// -> {a // b:>2}   trunc -> {math.trunc(a / b):>2}")
```

Результат:

```text
 10 /  3 =  3.3333   // ->  3   trunc ->  3
-10 / -3 =  3.3333   // ->  3   trunc ->  3
 10 / -3 = -3.3333   // -> -4   trunc -> -3
-10 /  3 = -3.3333   // -> -4   trunc -> -3
```

У C, C++, Java та C# цілочисельне ділення відкидає дробову частину (а в JavaScript його зазвичай імітують через `Math.trunc(a / b)`), тож у цих мовах `-10 / 3` дорівнює `-3`. Python свідомо обрав округлення вниз: разом із `%` це гарантує, що `n % d` ніколи не буває від'ємним для додатного `d`, і «циклічна» арифметика (години на циферблаті, кругові індекси) працює без особливих випадків. Пам'ятайте про це, коли переносите алгоритми з однієї мови на іншу.

### Пріоритет операторів

`//` має той самий пріоритет, що й `*`, `/` і `%`, а оператори цієї групи обчислюються зліва направо. Унарний мінус зв'язує операнд **сильніше**, тому `-7 // 2` означає `(-7) // 2`:

```python
print(-7 // 2)      # (-7) // 2
print(-(7 // 2))    # мінус застосовується після ділення
print(100 // 10 // 3)
print(2 + 7 // 2 * 3)
```

Результат:

```text
-4
-3
3
11
```

`100 // 10 // 3` — це `(100 // 10) // 3 = 10 // 3 = 3`, а `2 + 7 // 2 * 3` — це `2 + (3 * 3) = 11`.

## Тип результату

`//` округлює вниз **значення**, але не завжди повертає `int`. Тип визначається звичайними правилами для чисел:

```python
from decimal import Decimal
from fractions import Fraction

print(7 // 2, type(7 // 2))
print(7.0 // 2, type(7.0 // 2))
print(7 // 2.5)
print(-7.5 // 2)
print(True // 1)
print(10**30 // 7)
print(Fraction(7, 2) // 1, type(Fraction(7, 2) // 1))
print(Decimal("-7") // Decimal("2"))
```

Результат:

```text
3 <class 'int'>
3.0 <class 'float'>
2.0
-4.0
1
142857142857142857142857142857
3 <class 'int'>
-3
```

- Два цілі числа дають `int`, і результат **точний**, хоч якими великими були б числа.
- Якщо хоча б один операнд — `float`, результатом буде `float` із цілим значенням, наприклад `3.0`. Якщо потрібен саме `int`, використовуйте `math.floor(x)`.
- `bool` — підклас `int`, тому `True // 1` дорівнює `1`.
- `Fraction // Fraction` повертає `int`.
- `Decimal` — виняток із правила округлення вниз: `Decimal("-7") // Decimal("2")` **відкидає** дробову частину й дає `-3`. Чому так, пояснено в темі «Десяткові числа (Decimal)».

## `//`, `%` і `divmod()`

`//` і `%` — дві половини однієї операції. Коли потрібні обидва результати, вбудована функція `divmod()` повертає їх кортежем:

```python
print(divmod(101, 4))
print(divmod(-101, 4))

q, r = divmod(-101, 4)
print(4 * q + r)
```

Результат:

```text
(25, 1)
(-26, 3)
-101
```

Для від'ємного діленого частка округлюється вниз до `-26`, тому остача має бути додатною (`3`), щоб тотожність виконувалася. Правила знаків для `%` описано в темі «Остача від ділення (modulo)».

## `//` проти `math.floor(a / b)`

Округлити частку вниз можна й за допомогою `math.floor()`. Для невеликих цілих чисел обидва підходи дають однаковий результат, зокрема й для від'ємних чисел:

```python
from math import floor

a = 10
b = 3
print(a // b)
print(floor(a / b))

a = 10
b = -3
print(a // b)
print(floor(a / b))
```

Результат:

```text
3
3
-4
-4
```

Проте в загальному випадку вони **не** рівноцінні. `math.floor()` приймає одне число, тож `floor(a / b)` спершу виконує звичайне ділення, яке дає `float` і округлює частку до найближчого числа float. Лише після цього береться округлення вниз. Таке проміжне округлення спричиняє дві проблеми:

```python
import math

big = 10**17 + 1
print(big // 3)
print(math.floor(big / 3))

print(1 // 0.1)
print(1 / 0.1)
print(math.floor(1 / 0.1))
```

Результат:

```text
33333333333333333
33333333333333332
9.0
10.0
10
```

- **Великі цілі числа.** Float має лише 53 значущі біти (приблизно 15–17 десяткових цифр), тому `big / 3` не може зберегти точну частку, і остання цифра виходить неправильною. `big // 3` працює з точними цілими числами.
- **Неточні значення float.** Float `0.1` насправді трохи *більший* за одну десяту (див. тему «Дробові числа (float)»). Точна частка `1 / 0.1000000000000000055...` дорівнює `9.99999999999999944...`, тож округлення вниз дає `9`. Звичайне ділення округлює цю частку до `10.0`, і `math.floor()` уже бачить ціле число. `//` спирається на точні значення операндів і узгоджується з `%`: `1 % 0.1` дорівнює `0.09999999999999995`.

Практичне правило: для цілих чисел завжди використовуйте `//`. `math.floor()` потрібна, коли треба округлити вниз одне значення або отримати `int` із float.

## Граничні випадки: нуль і нескінченність

Цілочисельне ділення на нуль генерує виняток і для цілих чисел, і для float:

```python
print(5 // 0.0)
```

Результат (останній рядок трасування, Python 3.14):

```text
ZeroDivisionError: division by zero
```

Нескінченності підпорядковуються правилам IEEE 754 і можуть давати несподівані результати:

```python
inf = float("inf")
print(inf // 1)
print(1 // inf)
print(-1 // inf)
```

Результат:

```text
nan
0.0
-1.0
```

`-1 // inf` дорівнює `-1.0`: частка — від'ємне число, трохи менше за нуль, а будь-яке число між `-1` і `0` округлюється вниз до `-1`. Для `inf // 1` осмисленої цілої відповіді немає, тому результат — `nan`.

## Практичні приклади

### Середина списку та двійковий пошук

Індекс має бути цілим числом (`int`), тому середня позиція — це `len(items) // 2`. Двійковий пошук обчислює середину так само:

```python
def binary_search(items, target):
    lo, hi = 0, len(items) - 1
    while lo <= hi:
        mid = (lo + hi) // 2
        if items[mid] == target:
            return mid
        if items[mid] < target:
            lo = mid + 1
        else:
            hi = mid - 1
    return -1


scores = [12, 25, 31, 47, 58, 63, 79, 85]
print(scores[len(scores) // 2])
print(binary_search(scores, 63))
print(binary_search(scores, 50))
```

Результат:

```text
58
5
-1
```

Цілі числа в Python ніколи не переповнюються, тож `(lo + hi) // 2` безпечне. У C чи Java сума може переповнитися, тому там пишуть `lo + (hi - lo) / 2`.

### Розкладання числа на цифри

`n // 10` прибирає останню десяткову цифру, а `n % 10` повертає її:

```python
n = 2026
digits = []
while n > 0:
    digits.append(n % 10)
    n //= 10
print(digits)
print(sum(digits))
```

Результат:

```text
[6, 2, 0, 2]
10
```

`n //= 10` — це складене присвоєння: воно обчислює `n // 10` і перев'язує `n` на результат.

### На якій сторінці елемент?

Якщо індекси починаються з нуля, номер сторінки елемента — це його індекс, цілочисельно поділений на розмір сторінки:

```python
PER_PAGE = 10

for index in [0, 9, 10, 25, 99]:
    print(f"item {index:>2} -> page {index // PER_PAGE}")
```

Результат:

```text
item  0 -> page 0
item  9 -> page 0
item 10 -> page 1
item 25 -> page 2
item 99 -> page 9
```

Протилежне питання, «скільки сторінок потрібно?», вимагає округлення **вгору**. Як зробити це лише на цілих числах (`-(-items // per_page)`), показано в темі «Перетворення float на int».

### Округлення вниз до кратного

`x // step * step` округлює `x` вниз до найближчого кратного `step`. Так значення розкладають по групах (кошиках):

```python
for age in [7, 19, 30, 45, 99]:
    start = age // 10 * 10
    print(f"{age} -> {start}-{start + 9}")

for temp in [12.5, 3.0, -0.5, -7.2]:
    print(temp, "->", temp // 5 * 5)
```

Результат:

```text
7 -> 0-9
19 -> 10-19
30 -> 30-39
45 -> 40-49
99 -> 90-99
12.5 -> 10.0
3.0 -> 0.0
-0.5 -> -5.0
-7.2 -> -10.0
```

Завдяки округленню вниз від'ємні значення потрапляють у правильну групу: `-0.5` належить до `[-5, 0)`, а не до `[0, 5)`. Якби дробова частина просто відкидалася, групи навколо нуля стали б удвічі ширшими.

### Підтримка `//` у власних класах

`a // b` викликає `a.__floordiv__(b)`. Якщо той повертає `NotImplemented`, Python пробує `b.__rfloordiv__(a)`. `a //= b` викликає `__ifloordiv__()`, якщо такий метод є, а інакше використовує `__floordiv__()`:

```python
class Money:
    def __init__(self, cents):
        self.cents = cents

    def __floordiv__(self, other):
        if isinstance(other, int):
            return Money(self.cents // other)    # поділити на рівні частини
        if isinstance(other, Money):
            return self.cents // other.cents     # скільки разів вміщується
        return NotImplemented

    def __repr__(self):
        return f"Money({self.cents})"


budget = Money(1000)
print(budget // 3)
print(budget // Money(300))

budget //= 4          # використовує __floordiv__ і перев'язує ім'я
print(budget)
```

Результат:

```text
Money(333)
3
Money(250)
```

## Типові помилки

- **Очікувати відкидання дробової частини.** Код, перенесений із C, Java чи JavaScript, розраховує, що `-7 / 2` дасть `-3`. У Python `-7 // 2` дорівнює `-4`. Якщо для цілих чисел справді потрібне відкидання, див. вправу 3.
- **Очікувати, що `//` поверне `int`.** `7.0 // 2` дорівнює `3.0`. Обгорніть результат в `int()` або використайте `math.floor()`, коли потрібен саме `int`.
- **Використовувати `/` для індексів.** Звичайне ділення завжди повертає float, а списки не приймають дробових індексів:

  ```python
  scores = [12, 25, 31, 47, 58]
  print(scores[len(scores) / 2])
  ```

  Результат (останній рядок трасування):

  ```text
  TypeError: list indices must be integers or slices, not float
  ```

- **Використовувати `math.floor(a / b)` чи `int(a / b)` з великими цілими числами.** Проміжний float втрачає цифри. `a // b` точний.
- **Забувати про пріоритет.** `-a // b` округлює вниз від'ємне число. Якщо мається на увазі «спершу поділити, потім змінити знак», пишіть `-(a // b)`.
- **Цілочисельно ділити неточні float.** `1 // 0.1` дорівнює `9.0`, а не `10.0`. Коли важливі точні десяткові результати, працюйте з цілими числами (наприклад, у копійках) або з `Decimal`.

## Підсумок

- `/` — звичайне ділення, яке завжди повертає float. `//` — цілочисельне ділення: воно округлює частку вниз, у бік мінус нескінченності.
- Тотожність `N == D * (N // D) + (N % D)` виконується завжди, а `divmod(N, D)` повертає `(N // D, N % D)`.
- Для невід'ємної частки `//` збігається з відкиданням дробової частини. Для від'ємної — на одиницю менший: `-10 // 3` дорівнює `-4`.
- Два операнди `int` дають точний `int`. Будь-який операнд `float` дає `float` із цілим значенням. `Decimal` відкидає дробову частину замість округлення вниз.
- `a // b` точний для цілих чисел будь-якого розміру, а `math.floor(a / b)` проходить через float і може помилятися.
- Унарний мінус зв'язує сильніше за `//`: `-7 // 2 == (-7) // 2`.
- Типові застосування: середній індекс, виділення цифр, номери сторінок, групування через `x // step * step`.

## Розв'язки

### Вправа 1

Результат:

```text
3
-4
-4
-3
3.0
-1
7
```

- `17 / 5` дорівнює `3.4`, а округлення вниз дає `3`.
- `-17 / 5` дорівнює `-3.4`, після округлення вниз — `-4`.
- `17 / -5` теж дорівнює `-3.4`, тому результат також `-4`.
- Дужки спершу обчислюють `17 // 5 = 3`, а потім змінюють знак.
- Операнд float дає результат float: `3.0`.
- `-1 / 10` дорівнює `-0.1`, а найближче ціле число під ним — `-1`.
- `7 // 2 * 2 + 7 % 2` — це `3 * 2 + 1`, тобто знову `7`. Це та сама тотожність `D * (N // D) + N % D == N`.

### Вправа 2

```python
def reverse_number(n):
    result = 0
    while n > 0:
        n, digit = divmod(n, 10)
        result = result * 10 + digit
    return result


for n in [2026, 1200, 7, 0]:
    print(n, "->", reverse_number(n))
```

Результат:

```text
2026 -> 6202
1200 -> 21
7 -> 7
0 -> 0
```

Кожен крок забирає останню цифру з `n` і дописує її в кінець `result`. Кінцеві нулі `1200` стають початковими нулями оберненого числа, а ціле число їх не зберігає, тому результат — `21`.

### Вправа 3

```python
def trunc_div(a, b):
    q = abs(a) // abs(b)
    return q if (a < 0) == (b < 0) else -q


ok = all(
    trunc_div(a, b) == int(a / b)
    for a in range(-50, 51)
    for b in range(-7, 8)
    if b != 0
)
print(ok)

print(trunc_div(-7, 2), -7 // 2)

big = 10**20 + 1
print(trunc_div(-big, 3))
print(int(-big / 3))
```

Результат:

```text
True
-3 -4
-33333333333333333333
-33333333333333331968
```

Ділення абсолютних значень дає невід'ємну частку, а для неї округлення вниз і відкидання дробової частини збігаються. Потім відновлюється знак: результат від'ємний лише тоді, коли від'ємний рівно один з операндів. Для малих чисел `int(a / b)` дає ті самі відповіді, але для `10**20 + 1` проміжний float уже втратив останні цифри, тоді як `trunc_div()` лишається точною.

### Вправа 4

```python
def slot_start(minute_of_day, slot=15):
    start = minute_of_day // slot * slot
    hours, minutes = divmod(start, 60)
    return f"{hours:02}:{minutes:02}"


for minute in [0, 14, 15, 754, 1439]:
    print(minute, "->", slot_start(minute))
print(slot_start(754, slot=60))
```

Результат:

```text
0 -> 00:00
14 -> 00:00
15 -> 00:15
754 -> 12:30
1439 -> 23:45
12:00
```

`minute_of_day // slot * slot` округлює хвилину вниз до кратного довжини слота (`754 -> 750`), а `divmod(750, 60)` розкладає результат на `12` годин і `30` хвилин.
