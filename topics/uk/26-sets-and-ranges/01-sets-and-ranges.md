# Набори та діапазони

Вбудовані класи символів `\d`, `\w` і `\s` охоплюють поширені групи символів, але дуже часто потрібна власна група: «голосна», «шістнадцяткова цифра», «будь-що, крім лапки». Саме для цього є квадратні дужки. Набір на кшталт `[aeiou]`, `[0-9a-f]` чи `[^"]` відповідає **одному символу** з описаної групи, і це один із найуживаніших інструментів регулярних виразів.

## Що ви дізнаєтесь

- Як `[...]` створює власний набір, що відповідає рівно одному символу
- Як працюють діапазони `a-z` і `0-9` і чому вони спираються на кодові точки
- Як поєднувати в одному наборі діапазони, окремі символи та скорочені класи на кшталт `\d` і `\s`
- Як заперечити набір за допомогою `[^...]` і чим цей знак `^` відрізняється від якоря `^`
- Які символи мають особливе значення всередині дужок і як знайти їх буквально
- Чому `[а-я]` пропускає українські літери і як написати правильний набір для них

## Набори: один із кількох символів

Символи, перелічені у квадратних дужках, утворюють **набір** (set). Набір відповідає будь-якому **одному** з них. `[cs]` означає «або `c`, або `s`», тож шаблон `licen[cs]e` знаходить і британське, і американське написання:

```python
import re

s = 'A licence or license'

for match in re.finditer(r'licen[cs]e', s):
    print(match.group())
```

Результат:

```text
licence
license
```

Шаблон читається так: `licen`, потім один символ — `c` або `s`, потім `e`.

Набір завжди позначає **рівно один символ**, хоч скільки символів у ньому перелічено:

```python
import re

print(re.findall(r"gr[ae]y", "gray grey graey"))
```

Результат:

```text
['gray', 'grey']
```

`graey` не збігається: після `gr` набір забирає один символ (`a`), а далі шаблон потребує `y`, а не `e`. Щоб дозволити кілька символів із набору, додайте квантифікатор: `[ae]+`, `[0-9]{4}` (див. тему «Квантифікатори»).

Порядок і повторення всередині набору нічого не змінюють: `[cs]`, `[sc]` і `[ccs]` — той самий набір.

### Метасимволи всередині набору втрачають силу

Більшість символів, особливих у шаблоні, усередині дужок звичайні. `.`, `*`, `+`, `?`, `$`, `(`, `)` і `|` відповідають самим собі:

```python
import re

print(re.findall(r"[.?!]", "Hi! How are you? Fine."))
```

Результат:

```text
['!', '?', '.']
```

Тут `[.?!]` означає «крапка, знак питання або знак оклику». Писати `[\.\?!]` не потрібно, хоча екранування й не зашкодить. Лише чотири символи зберігають особливе значення всередині набору: `]`, `\`, `^` і `-` (див. розділ «Особливі символи всередині набору» нижче).

## Діапазони

Перелічувати всі літери від `a` до `z` було б виснажливо. Дефіс між двома символами створює **діапазон** (range):

| Набір | Відповідає одному... |
|---|---|
| `[0-9]` | ASCII-цифрі |
| `[a-z]` | малій латинській літері |
| `[A-Z]` | великій латинській літері |
| `[a-zA-Z]` | латинській літері будь-якого регістру (два діапазони в одному наборі) |
| `[0-9a-fA-F]` | шістнадцятковій цифрі (три діапазони) |
| `[a-z0-9_]` | малій літері, цифрі або підкресленню (діапазони плюс окремий символ) |

```python
import re

text = "Room B12, floor 3, code x9-Z"

print(re.findall(r"[0-9]", text))
print(re.findall(r"[A-Z]", text))
print(re.findall(r"[0-9]+", text))
print(re.findall(r"[a-zA-Z0-9]+", text))
```

Результат:

```text
['1', '2', '3', '9']
['R', 'B', 'Z']
['12', '3', '9']
['Room', 'B12', 'floor', '3', 'code', 'x9', 'Z']
```

### Діапазони — це діапазони кодових точок

Діапазон нічого не знає про «літери» чи «цифри». `x-y` означає просто «кожен символ, чия кодова точка Unicode (code point) лежить між `x` і `y`». Для `0-9`, `a-z` і `A-Z` це дає очікуваний результат, але діапазон між різними групами може приховувати сюрпризи. Між `Z` (90) і `a` (97) розташовано шість розділових символів:

```text
code point:  65 ... 90  91  92  93  94  95  96  97 ... 122
character:    A ...  Z   [   \   ]   ^   _   `   a ...   z
```

Тож `[A-z]` — **не** «будь-яка латинська літера»:

```python
import re

print(re.findall(r"[A-z]", "Az_^["))
```

Результат:

```text
['A', 'z', '_', '^', '[']
```

Завжди пишіть `[A-Za-z]`.

Діапазон має йти від меншої кодової точки до більшої. Перевернутий діапазон — синтаксична помилка:

```python
import re

try:
    re.compile(r"[z-a]")
except re.PatternError as error:
    print(error)
```

Результат:

```text
bad character range z-a at position 1
```

(`re.PatternError` — назва цього винятку починаючи з Python 3.13. Стара назва `re.error` працює як псевдонім.)

### Діапазони стосуються символів, а не чисел

`[1-31]` **не** означає «число від 1 до 31». Це діапазон `1-3` плюс окремий символ `1`, тож він відповідає одному символу: `1`, `2` або `3`:

```python
import re

print(re.findall(r"[1-31]", "0 1 2 3 10 31 4"))
```

Результат:

```text
['1', '2', '3', '1', '3', '1']
```

Числові діапазони доводиться будувати цифра за цифрою. Наприклад, хвилини від `00` до `59` — це `[0-5][0-9]`: перша цифра від `0` до `5`, друга від `0` до `9`. Діапазони, де цифри залежать одна від одної, як-от години від `00` до `23`, потребують ще й альтернації, про яку йдеться в темі «Альтернація».

### Діапазони й Unicode: українська абетка

У Python 3 рядкові шаблони працюють з Unicode, тож дозволені діапазони будь-якої писемності. Але правило кодових точок діє й тут. Діапазон `а-я` охоплює U+0430–U+044F, тобто базовий блок кириличних літер. Українські літери `є`, `і`, `ї` і `ґ` лежать **поза** ним:

```text
U+0430 а ... U+044F я      the range а-я
U+0454 є   U+0456 і   U+0457 ї   U+0491 ґ   outside the range
```

Через це `[а-яА-Я]+` розрізає українські слова на шматки:

```python
import re

text = "Київ, Львів, Запоріжжя"

print(re.findall(r"[а-яА-Я]+", text))
```

Результат:

```text
['Ки', 'в', 'Льв', 'в', 'Запор', 'жжя']
```

Правильний набір перелічує українську абетку явно. `а-щ` охоплює літери від `а` до `щ`, далі по одній додано `ь`, `ю`, `я` і чотири особливі літери. Апостроф (і `'`, і `ʼ`) теж належить до українських слів:

```python
import re

text = "Київ, Львів, Запоріжжя, м'ята, пʼять"
uk_word = r"[а-щьюяґєіїА-ЩЬЮЯҐЄІЇ'ʼ]+"

print(re.findall(uk_word, text))
```

Результат:

```text
['Київ', 'Львів', 'Запоріжжя', "м'ята", 'пʼять']
```

Цей набір до того ж не пропускає кириличних літер, яких немає в українській абетці (як-от `ы` і `ё`), і це зручно для валідації.

Коли потрібна «літера будь-якої абетки», а не конкретної, скористайтеся прийомом `[^\W\d_]`: «не символ поза словом, не цифра, не підкреслення» — залишаються саме літери:

```python
import re

print(re.findall(r"[^\W\d_]+", "Київ_2024 café 42 naïve"))
```

Результат:

```text
['Київ', 'café', 'naïve']
```

## Скорочені класи всередині набору

Скорочені класи `\d`, `\w`, `\s` та їхні обернені класи можна ставити всередину дужок і поєднувати з іншими символами й діапазонами:

| Набір | Відповідає одному... |
|---|---|
| `[\d\s]` | цифрі або пробільному символу |
| `[\d_]` | цифрі або підкресленню |
| `[\w.-]` | символу слова, крапці або дефісу |
| `[\s,;]` | пробільному символу, комі або крапці з комою |

```python
import re

print(re.findall(r"[\d\s]", "a1 b2\tc"))
print(re.findall(r"[\d_]", "a_1-b2"))
print(re.findall(r"[\w.-]+", "Files: report-v2.pdf, data_2024.csv"))
```

Результат:

```text
['1', ' ', '2', '\t']
['_', '1', '2']
['Files', 'report-v2.pdf', 'data_2024.csv']
```

Усередині дужок скорочені класи зберігають своє Unicode-значення (див. тему «Класи символів»): `[\d_]` приймає й арабсько-індійські цифри, а `[0-9_]` — ні.

## Заперечні набори: `[^...]`

Знак `^` **одразу після відкривної дужки** заперечує набір: `[^...]` відповідає одному символу, якого **немає** в переліку. Приклад із джерела знаходить літери слова `Python`, які не є голосними:

```python
import re

for match in re.finditer(r'[^aeiou]', 'Python'):
    print(match.group())
```

Результат:

```text
P
y
t
h
n
```

«Не голосна» — це не те саме, що «приголосна». Заперечний набір відповідає **всьому** іншому: великим голосним, цифрам, пробілам, розділовим знакам і навіть символу нового рядка:

```python
import re

print(re.findall(r"[^aeiou]", "Hello World!"))
print(re.findall(r"[^a]", "a\nb"))
```

Результат:

```text
['H', 'l', 'l', ' ', 'W', 'r', 'l', 'd', '!']
['\n', 'b']
```

Тут заперечний набір поводиться інакше, ніж крапка. `.` без `re.DOTALL` ніколи не відповідає `\n`, а `[^"]` відповідає, бо символ нового рядка — це «не лапка». Для тексту в лапках, що займає кілька рядків, саме це зазвичай і потрібно:

```python
import re

text = 'a "multi\nline" b'

print(re.findall(r'"[^"]*"', text))
print(re.findall(r'".*"', text))
```

Результат:

```text
['"multi\nline"']
[]
```

`"[^"]*"` («лапка, будь-яка кількість не-лапок, лапка») — класичний шаблон для тексту між роздільниками. Тема «Жадібні квантифікатори» пояснює, чому він точніший за `".*"` і `".*?"`.

### `[^0-9]` і `\D` — не завжди одне й те саме

У джерелі сказано, що `[^0-9]` — те саме, що `\D`. Це правда лише для ASCII-тексту. У режимі Unicode `\D` виключає **всі** цифри Unicode, а `[^0-9]` — лише десять ASCII-цифр:

```python
import re

text = "٣4"  # арабсько-індійська трійка, потім ASCII-четвірка

print(re.findall(r"[^0-9]", text))
print(re.findall(r"\D", text))
print(re.findall(r"\D", text, re.ASCII))
```

Результат:

```text
['٣']
[]
['٣']
```

### Знак `^` усередині й поза дужками

Знак `^` має дві не пов'язані між собою ролі:

- **Поза** дужками `^` — це якір: «початок рядка» (або початок кожного рядка з `re.MULTILINE`). Див. тему «Якорі».
- **Одразу після `[`** він заперечує набір.
- **Будь-де інде всередині дужок** це звичайний символ: `[a^b]` відповідає `a`, `^` або `b`.

Обидва значення можуть траплятися в одному шаблоні. `^[^#]` означає «на початку рядка символ, що не є `#`». Ось так можна залишити рядки конфігураційного файлу, які не є коментарями:

```python
import re

config = """# comment
host = example.com
#port = 80
user = admin"""

print(re.findall(r"^[^#].*", config, re.MULTILINE))
```

Результат:

```text
['host = example.com', 'user = admin']
```

## Особливі символи всередині набору

Усередині дужок увагу потребують лише чотири символи:

| Символ | Значення всередині `[...]` | Як знайти його буквально |
|---|---|---|
| `]` | закриває набір | `\]` або поставити першим: `[]a]` |
| `\` | починає екранування | `\\` |
| `^` | заперечення, якщо стоїть першим | поставити будь-де, крім першої позиції, або `\^` |
| `-` | діапазон між двома символами | поставити першим чи останнім або `\-` |

```python
import re

print(re.findall(r"[-+*/]", "3+4-2*5/1"))
print(re.findall(r"[\[\]]", "a[1] b[2]"))
print(re.findall(r"[]a]", "a]b"))
print(re.findall(r"[\^a]", "^a"))
```

Результат:

```text
['+', '-', '*', '/']
['[', ']', '[', ']']
['a', ']']
['^', 'a']
```

У `[-+*/]` дефіс стоїть першим, тож це буквальний дефіс, а не діапазон. Екранування (`\]`, `\-`) працює будь-де, і це найзрозуміліший варіант. Прийоми «поставити першим» варто впізнавати, коли читаєте чужі шаблони.

Дефіс між скороченим класом і іншим символом — помилка, бо на кінцях діапазону мають бути два окремі символи:

```python
import re

try:
    re.compile(r"[\w-.]")
except re.PatternError as error:
    print(error)
```

Результат:

```text
bad character range \w-. at position 1
```

Пишіть `[\w.-]` або `[\w\-.]`.

> **Зверніть увагу:** Python резервує деякі комбінації символів усередині наборів для можливих майбутніх можливостей (вкладених наборів і операцій над наборами). Буквальна `[` усередині набору, а також подвоєні символи `&&`, `||`, `~~` і `--` спричиняють `FutureWarning`, наприклад `Possible nested set at position 1`. Екрануйте їх (`[\[a]`), щоб не ризикувати. З тієї ж причини POSIX-класи на кшталт `[[:digit:]]` з інших рушіїв регулярних виразів у Python **не** працюють: вони видають попередження, а потім знаходять зовсім не цифри. Використовуйте `\d` або `[0-9]`.

## Набори та `re.IGNORECASE`

З прапорцем `re.IGNORECASE` (скорочено `re.I`) діапазони теж ігнорують регістр, тож `[a-z]` відповідає й великим літерам:

```python
import re

print(re.findall(r"[a-z]+", "Hello WORLD"))
print(re.findall(r"[a-z]+", "Hello WORLD", re.IGNORECASE))
```

Результат:

```text
['ello']
['Hello', 'WORLD']
```

Докладно про цей та інші прапорці — у темі «Прапорці регулярних виразів».

## Типові помилки

- **Писати `[A-z]` замість «будь-яка латинська літера».** Такий діапазон відповідає й `[`, `\`, `]`, `^`, `_` та `` ` ``. Використовуйте `[A-Za-z]`.
- **Сприймати діапазони як числа.** `[1-31]` — це набір `{1, 2, 3}`, а `[0-255]` — `{0, 1, 2, 5}`. Числові діапазони будуйте цифра за цифрою.
- **Використовувати `[а-я]` для українського тексту.** Він пропускає `є`, `і`, `ї` і `ґ`. Перелічіть абетку явно або візьміть `[^\W\d_]` для будь-якої літери.
- **Писати слова у квадратних дужках.** `[cat|dog]` — це набір окремих символів `c`, `a`, `t`, `|`, `d`, `o`, `g`, тож `[cat|dog]+` охоче знаходить `"cat|dog"` і `co` у `"cow"`. Для цілих слів потрібна альтернація: `cat|dog`.
- **Забувати, що заперечний набір відповідає символам нового рядка й розділовим знакам.** `[^aeiou]` — це «будь-який символ, крім цих п'яти», а не «приголосна».
- **Випадково ставити `-` посередині.** `[\w-.]` — помилка, а `[a-z-0]` важко читати. Буквальний дефіс ставте першим чи останнім або екрануйте.
- **Очікувати, що `[^abc]` означає «не рядок abc».** Набір — це завжди один символ. `[^abc]` — один символ, відмінний від `a`, `b` і `c`.

## Підсумок

- `[...]` відповідає рівно одному символу з переліченої групи. Щоб знайти кілька, додайте квантифікатор.
- `x-y` у дужках — це діапазон кодових точок. Кілька діапазонів, окремі символи й скорочені класи можна поєднувати: `[a-zA-Z0-9_]`, `[\d\s]`, `[\w.-]`.
- Більшість метасимволів усередині набору буквальні. Увагу потребують лише `]`, `\`, `^` і `-`.
- `[^...]` відповідає будь-якому одному символу поза набором, зокрема символам нового рядка й розділовим знакам. `^` заперечує лише одразу після `[`.
- `[^0-9]` і `\D` по-різному поводяться з не-ASCII цифрами.
- `[а-я]` не охоплює чотирьох українських літер. Для українських слів перелічуйте абетку явно (разом з апострофами), а для літер будь-якої абетки використовуйте `[^\W\d_]`.

## Практика

### Вправа 1: Шістнадцяткові кольори

Знайдіть у тексті всі правильні шестицифрові шістнадцяткові кольори. Шістнадцяткові цифри можуть бути великими або малими. `#fff` (три цифри), `#12345G` (не шістнадцяткове число) і `#1234567` (сім цифр) не мають збігатися.

```python
text = "color: #1A2b3C; bg: #fff; bad: #12345G; ok: #00ff00; long: #1234567"
```

### Вправа 2: Українські слова

Виберіть усі слова з тексту нижче. Спершу спробуйте `[а-яА-Я]+` і подивіться, що піде не так, а потім напишіть набір, який повертає цілі українські слова, зокрема й з апострофом.

```python
text = "Їжак і ґава п'ють чай у Євпаторії"
```

### Вправа 3: Безпечна назва файлу

Замініть на `_` кожен символ, який не є літерою, цифрою, крапкою, дефісом чи підкресленням. `"my report (final) v2.pdf"` має стати `"my_report__final__v2.pdf"`.

### Вправа 4: Передбачте набори

Передбачте результат кожного рядка, перш ніж запускати код:

```python
import re

print(re.findall(r"[1-31]", "0 1 2 3 10 31 4"))
print(re.findall(r"[A-z]", "Az_^["))
print(re.findall(r"[^a]", "a\nb"))
print(re.findall(r"[.+]", "1.5+2"))
print(re.findall(r"[a-]", "a-b"))
```

## Розв'язки

### Вправа 1

```python
import re

text = "color: #1A2b3C; bg: #fff; bad: #12345G; ok: #00ff00; long: #1234567"

print(re.findall(r"#[0-9a-fA-F]{6}\b", text))
```

Результат:

```text
['#1A2b3C', '#00ff00']
```

`[0-9a-fA-F]` — одна шістнадцяткова цифра, а `{6}` вимагає рівно шести таких цифр. Межа слова `\b` відкидає `#1234567`: після шести цифр іде `7`, символ слова, тож межі там немає. `#12345G` не підходить, бо `G` немає в наборі.

### Вправа 2

```python
import re

text = "Їжак і ґава п'ють чай у Євпаторії"

print(re.findall(r"[а-яА-Я]+", text))
print(re.findall(r"[а-щьюяґєіїА-ЩЬЮЯҐЄІЇ'ʼ]+", text))
```

Результат:

```text
['жак', 'ава', 'п', 'ють', 'чай', 'у', 'впатор']
['Їжак', 'і', 'ґава', "п'ють", 'чай', 'у', 'Євпаторії']
```

Базовий діапазон губить усі літери, що лежать поза ним (в обох регістрах), а апостроф розриває слово надвоє. Повний набір перелічує українські літери поза `а-я` і обидва символи апострофа.

### Вправа 3

```python
import re

print(re.sub(r"[^\w.-]", "_", "my report (final) v2.pdf"))
```

Результат:

```text
my_report__final__v2.pdf
```

Заперечний набір `[^\w.-]` відповідає одному символу, який не є символом слова, крапкою чи дефісом. Дефіс стоїть останнім, тож він буквальний. Кожен пробіл і кожна дужка замінюються окремо, тому подекуди виходить два підкреслення поспіль. Щоб стиснути такі послідовності в одне `_`, використайте `[^\w.-]+`.

### Вправа 4

Результат:

```text
['1', '2', '3', '1', '3', '1']
['A', 'z', '_', '^', '[']
['\n', 'b']
['.', '+']
['a', '-']
```

- `[1-31]` — це набір `{1, 2, 3}`. Він знаходить окремі цифри, зокрема `1` у `10` і обидві цифри `31`.
- `[A-z]` містить розділові символи між `Z` і `a`, тож `_`, `^` і `[` збігаються.
- `[^a]` відповідає й символу нового рядка.
- `.` і `+` усередині набору буквальні.
- Дефіс у кінці набору буквальний.
